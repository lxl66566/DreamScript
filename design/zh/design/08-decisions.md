## A. 定位

**A1 — (c)。** 性能章程要求一个自带分层优化能力的真正独立运行时；嵌入随后以「导出效应处理器的平台包」（H5b）形式叠加在同一运行时上，不需要第二个产品就能覆盖 Lua 的嵌入定位。

**A2 — (a) 为主，(c) 为次。** 两类工作负载都由解释器优先的管线、mmap 启动与双槽热重载运行时支撑；数值/AI 工作负载始终可经 tier-3 的 Cranelift 路径到达，不必反过来塑造 v1。

**A3 — (a) 之后 (b)。** 1.0 之前快速破坏（Roc/MoonBit 姿态），之后转入 semver 纪律。内容寻址被否决作为源码级身份模型，同时被采纳为包一级的存储（H6b）——它的收益在那里是真实的，文化代价在那里是不存在的。

## B. 类型

**B1 — (c) 混合。** 名义标签给出身份、封装与以标签为键的穷尽检查；在其上做集合运算（`|`、`&`、`-`）让 README 的集合指令以类型表达式的形式兑现，错误集合的算术与收窄也随之而来，而检查器停留在枚举覆盖的难度，VM 停留在拆箱的标签+载荷成本。README 的 `any` 回退被否决：它把推断失败转成动态类型，违反编译期错误规则。已记录的回退：若不相交检查器进度失控，B1(b) 是可逆的退路，代价是并集表层（E4b 随之退化为基于 match 的处理）。

**B2 — (c) 叠加在 (a) 上。** 模块边界上的必需签名把集合代数锚定在「被检查」的位置；局部绑定、lambda 与 match 分支由双向推断得出；`is` 测试与 match 分支单调收窄，这正是精化能与交集、取反组合而不爆炸的结构性原因。带完整代数的完整 HM 仍是本项目拒绝下注的研究赌注。

**B3 — (d)。** 名义 structs 与 enums 承担具名数据；匿名元组承担临时聚合；匿名 record 字面量作为编译器合成的名义 record 语法糖——该语法糖延后增量，直到推断方案定型（F7 账本第 25 行）。行被否决用于数据：它是目录中单位语法糖对应机制最重的选项，而它唯一无可回避的用途（效应行）反正已延后（E1d）。

**B4 — (c)。** `T?` 恰好就是 `T | none`。可选、错误并集与 enum 共用一套机制——`is`、`or`、match——因此 `none`、错误成员与 enum case 是同一构造。v1 无 `?.`；若真实代码确有需求，后续可加一层薄薄的 `x?.f` 反糖。

**B5 — (d)。** 错误是返回类型的并集成员：可存储的数据（供 nursery 收集与监督）、VM 中一次被预测的分支、与效应行完全相同的信息。`throws(...)` 写法保留为后续语法糖，反糖到同一个并集。

**B6 — (a)。** trait 可带关联类型；实例为类型头声明；一致性规则是同一 trait 的实例头两两不相交（`H1 & H2 = Empty`，可判定的集合空性），在声明时与链接期对最终实例环境各检查一遍；任何模块都可以为任何类型定义实例，包括外来类型；任何优先级机制都不存在——作者的反特化立场由此成为结构事实。带作用域的具名实例 (b) 留作后续增量逃生口，歧义永远是错误。

**B7 — (a)，decimal 作为库类型。** Int/Float 默认 i64/f64，裸放在拆箱槽位中；溢出确定性陷入；`+% -% *%`（及 `-%a`）显式回绕；后缀选择宽度（`42u8`、`2.0f32`）；`1_000_000` / `0x` / `0b` / `0o` 字面量形式；无隐式收窄；除零与移位溢出陷入。decimal（`Dec`）与计量单位是名义库类型加 derive。

**B8 — (a)。** 不可变 UTF-8，一根裸指针加字节长度；检查后的切片返回 `String | none`；`chars` 迭代；字素在标准库；rope 是未来的库类型；编码转换发生在 FFI 边界。

**B9 — (a)。** 对全部数据只有一个结构化 `==`，由构造保证全体性：函数比较被静态拒绝；float 按位比较结构（自反，作字典键安全），旁边配上具名的 `is_float_eq` / `is_approx_eq`；可变单元与 `~Copyable` 资源按身份比较；操作数只借用、绝不消耗；哈希与相等配套要求。`Ord` / `Hash` / `Show` 以 derive 到达（G1）；不存在 `===`。

## C/D. 线性性、所有权、内存、数据

**C1 — (b)。** 日常规则只有一句话：仿射值的赋值即移动，被移动过的绑定已死。普通可复制值从不会可观察地触发该规则。`~Copyable` 减去默认的可复制性约束，与 B1(c) 代数组合（`File[Open] | File[Closed]` 幻影状态），`deinit` 就住在这一层。这是对章程要求 2（「静态线性或仿射类型」）以最低学习成本给出的如实解读，也直接回答了所有权的开放问题：所有权机制 = 可选的资源类型 + 参数模式（C2d），在其余所有地方不可见。分期按研究的组合 6：先交付运行时 `rc==1` 唯一性检查与 Inko 式借用计数作为诊断层；借用推断、完整复用配对与 TRMC 后续作为纯优化落地，语言零变更。

**C2 — (d)。** 三种二等参数模式在定义处固定——默认借用、`mut`（排他）、消耗——调用点不携带任何模式语法；UFCS 链保持干净。借用绝不逃逸出调用，因此检查是过程内的，不存在生命周期标注。一等引用被永久排除，这是有意为之：四个耦合特性（moves/borrows/lifetimes/drop）收敛为两个。

**C3 — (b)。** `const`/`var` 绑定；`var` 是可重绑定的局部；被调方的修改走 `mut` 窗口——与 C2(d) 同一机制，一条规则覆盖参数、窗口与收敛三个用途。FBIP 复用垫在底下，让函数式更新在值唯一时原地执行；共享可变性按设计不可表示。用户表层没有内部可变性单元类型。

**C4 — (a)+(d)。** 精确非原子引用计数加 Perceus 块复用，服务于装箱/共享值；逐帧 bump arena 服务于临时值，其可靠性正来自线性性把逃逸变成编译期事实。无追踪式 GC。v0 在类型级拒绝环，以双钩子收集器接口（H4d）作为声明的增长路径。

**C5 — (c)。** `deinit` 只能在 `~Copyable` 类型上声明，在唯一实例死亡时恰好执行一次，覆盖包括 panic 与取消在内的所有路径——这一 RAII 层同时供给 E5 的收尾清理。确定初始化检查是一切选项共用的基础设施。显式 `drop` 作为调试/FFI 工具存在；用户从不书写例行 drop。

**D1 — (b)。** `mut` 窗口是唯一的可变通道：排他、在调用点词法可见、静态证明、窗口内零运行时检查。

**D2 — (b)。** 集合暴露函数式 API，当且仅当唯一持有时原地修改（COW，复用保证且可观察）；持久化 HAMT 类结构是同一运行时上的普通库类型；`Bytes`/`Vec` 是同一模型中拆箱的唯一端。

**D3 — (d)。** 组合子加 `for` 是迭代表层；隐藏协议是线性游标；编译器融合链式调用；下标把原地元素访问扩展进来。1.0 无公开生成器语法；隐藏降级后续可改用纤程设施，表层零变更。

## E. 错误、效应、异步、并行

**E1 — (d)，以 (c) 为惯用法。** v1 无效应语法。运行时从第一天起就是处理器形态：证据传递在 nursery 边界服务两个内部效应（`cancel`、`discontinue`），因此用户自定义处理器仍是增量逃生口（v2，`with handler`），永远不需要迁移。触及世界的标准库 API 遵循能力参数惯用法：`ds` CLI 为脚本装入环境默认处理器，而测试、嵌入与调度选择用显式能力参数——同一份代码跑在阻塞、事件循环或自定义调度器上。世界访问审计 = 约定 + 能力，默认隐式；这是显式参数姿态能多得一分的那唯一一个轴，需要时可以刻意取用能力参数来补上。

**E2 — (b)。** VM 池上的堆纤程；`spawn` 只存在于 `nursery` 块内；作用域退出汇合子任务、首个失败取消兄弟任务、子任务错误在边界以并集导出。阻塞式代码、无染色、无 `await`、O(1) 切换、每纤程 TCO 完好。裸 detach 需要显式根 nursery 或监督器。

**E3 — (b) 建在 (a) 上。** 竞态自由与可发送性已经是线性/不可变数据的静态推论（线性值按构造即可发送；不可变值按构造即可共享）；缺的只是调度器。`par_map` / `par_reduce` fork-join 组合子作用于不可变或线性划分的输入，确定且可重放；actor 与监督层后续可作为库叠加（监督器 = 带重启策略的 nursery）。

**E4 — (b) 配 (a) 的陷入。** 预期失败是并集成员，由 `?` / `or` / `.err` 处理，差集类型保证穷尽覆盖；程序缺陷 `panic` 且不可捕获——纤程中止，栈帧遍历执行线性 deinit，陷入在 nursery 边界浮出。let-it-crash 监督（E4d）是其上的库模式。

**E5 — (a)+(b)。** 取消是 nursery 作用域内且协作式的，只在 await/抢占点被观察到，因此进行中的线性消耗绝不会被中断；收尾清理遍历栈帧执行 deinit。资源以消耗关闭；`defer` 作为作用域退出语法糖存在（非规范）；超时、`firstof`、`interleave` 是定时器能力之上的库组合子。

## F. 语法

**F1 — (a)。** TS 系花括号：历史 README 自身的形态、作者的日常表层、四种形态中语法增量最小的一个。若解析器原型阶段发现箭头赋值文法与解释器解析器冲突，F1(b) 是已记录的回退；F1(c) 与 F1(d) 落选。

**F2 — 按所述。** `const`/`var` 绑定；具名函数写作 `const name = (params) -> T { body }`，定义名在自身函数体内可见；`name: T` 参数与 `-> T` 返回；匿名 lambda `(x) => e`；末表达式返回，配合 `or return` / `or break` / `or continue` 提前退出；换行终结语句、无分号；允许尾逗号。`?` 保留给传播；README 的前缀 `?` 返回标记退役。

**F3 — (a)。** 完整 UFCS：`x.f(a)` 反糖为 `f(x, a)`，适用于任何首参函数。解析顺序固定且简单：先自由函数，再 trait 方法，`Trait::f(x)` 限定是逃生口；真歧义是编译错误，绝不是优先级搜索。能力参数具名、排除在点调用位置之外，显式传递或经作用域形式传递。`|>` 延后增量（Roc 以「与链式调用加 `?` 冗余」为由删掉了自己的管道）。

**F4 — (a)。** Rust 形态分支：`pat if guard`、或模式 `a | b`、解构、穷尽匹配配集合差集诊断（「missing: NotFound | Locked」）。`@` 绑定器排除出 v1：`is` 精化让被检变量保持可用，解构覆盖字段提取，绑定器剩下的用途是被移出整体的仿射再绑定——若真实代码需要，该问题值得单独设计。延后增量。

**F5 — (a)。** 固定的运算符 token 集映射到固定的 trait（Add、Sub、Mul、……、Index），一张冻结的 C 系优先级表在教程里发布一次，永远不允许用户自定义运算符。`==` 是 B9 的结构化相等，永不接受用户重载；排序走 `Ord` derive。溢出写法按 B7：默认陷入，`+% -% *%` / `-%a` 回绕，除法与移位陷入。

**F6 — (a)。** `$x` 裸标识符与 `${expr}` 表达式插值，在非字符串边界要求显式 `str()` 调用（无隐藏字符串化）。`r"..."` 与带哈希计数的 `r#"..."#` 原始字符串以一种构造覆盖原始、多行与 heredoc 需求；`'x'` 是一个 Unicode 标量 Char，`b'x'` 是一个字节。

**F7 — Balanced。** 22 账本行 / 35 成本单位：约为 Kotlin 特性数的一半、加权表层的四成出头，留出 16 项特性 / 40-42 单位余量。余量的首选候选按可能性排序：`|>`、匿名 record 语法糖、`@` 绑定器、vararg/展开。

## G. 多态、元编程、模块、生态

**G1 — (b)。** 普通代码的 comptime 求值加静态类型反射；各级宏全部否决——卫生性问题被构造性删除，元语言即语言本身。分期交付：内建 derive（`Hash`、`Show`、`Ord`、`Clone`、`ToJson`/`FromJson`、`Default`；`==` 通用、永不 derive）先行；comptime 求值器与反射 API 在 1.0 前落地。

**G2 — (b)+(d)。** 反射只在 comptime 存在；运行时类型问题由数据本就携带的标签回答（`is`、match）；任何地方都不存在类型对象与运行时元数据表。

**H3 — (a)。** 每个泛型函数一份函数体；证据词作为额外寄存器参数传递——实例静态可解时是常量操作数，动态路径上是按标签键控的 1-2 项内联缓存；JIT 层惰性地物化按类型的特化，缓存在其中没有正确性角色。这满足反特化立场：运行哪些代码在任何缓存之前就由集合代数定死，运行时可以缓存本已唯一的分派。变异性由集合包含关系自然得出；1.0 无 HKT、无 GAT。

**G3 — (b)。** 四层：定义 < 文件 < 包 < 模块。同包文件共享一个命名空间，包内零导入语句；包内循环合法（整包不动点解析）；跨包循环是链接错误，其诊断建议把共享抽象移入基础包。生成的 `.dsi` 接口文件是可评审的 API 面；模块体是纯编译期声明——导入时不执行，句号。`///|` 是可选的显式块分隔符，为工具提供文件内的更细粒度；无论有无分隔符，顶层定义都顺序无关，无分隔符的文件就是一个块。G3.5 dsmod 契约（可 mmap、依赖表驱动的惰性加载、blake3 检查哈希校验、内嵌字节码单体二进制）生效。

**G4 — (b)。** 默认私有；`pub(pkg)` 对全包开放；`pub` 对依赖方开放并写入 `.dsi`；导入支持按符号选择、别名、按目标条件化，经 `pub import` 再导出。接口文件就是可见性门与 API 评审工件。

**H5 — (a)+(b)。** FFI 基底：不透明的外部资源是线性句柄（`~Copyable`），双重释放是编译错误，extern 借用是调用作用域的，回调跑在 VM 管理的栈上，`ds bind` 从头文件生成带类型的 extern。嵌入 API：Lua 形态的句柄表（`ds_push`/`ds_ref`），值是 VM 对象表的索引，两个嵌入者是两个独立 VM。叠加其上：平台是导出效应处理器的普通包，可按构建目标选择；wasm/WIT 是 tier-3 的部署目标。裸 `extern` 声明保留为句柄纪律内有文档记录的逃生口。

**H6 — (b)+(c)。** blake3 哈希级联清单（清单即锁；身份传递性流动）、MVS 解析、以输出哈希内容寻址的存储兼任字节码缓存、按三元组的 bin-first 构件、可选的 FHS profile 链接器、注册表延后为存储之上的静态 JSON 索引。叠加脚本模式：`ds run script.ds` 零配置、裸说明符导入 std、`ds save` 冻结出清单。五项必须兑现的工具承诺从第一天起生效：编译器兼作查询库、零选项的 `ds fmt`、结构化双定位线性诊断、线性感知 REPL、双槽热重载。

## H. 运行时

**H1 — (a)。** Tier 1 带类型寄存器 VM（C 的 3-10 倍）→ tier 2 copy-and-patch 模板（1.5-3 倍，每单元微秒级）→ tier 3 Cranelift 或 wasm（1-2 倍 / 1.5-2.5 倍），全部架在同一 uop 集（BL-5）与一套尽早构建的字节码到 SSA 降级上。层间转移是原位的 J 变体操作码改写；OSR 收敛为编译循环体；没有去优化悬崖。BL-1 至 BL-7 基线作为固定输入生效。若按架构的模板工具链不可接受，H1(b) 是已记录的回退。

**H2 — (a)。** 规范级保证的真尾调用，覆盖自身与互递归，第一天起生效：tier 1 中栈帧复用加参数滑动（配尾调用链元数据让回溯保持诚实），JIT 层中标签循环与槽位叠加 `jmp`，wasm 上 `return_call`。被调方参数槽位叠加在调用方参数槽位上，在栈帧布局时锁定——这个 ABI 与 BL-7 是要先于一切锁定的两个决策。保证范围限定在同一效应上下文内的尾调用；处理器入口会物化一个栈帧。

**H4 — (a)。** Perceus 精确 RC 加复用穿线，加逐帧 bump arena：零停顿、零屏障、任何层都不需要安全点或 GC 栈图，确定性释放喂给确定性 deinit。H4(d) 的双钩子收集器接口（环候选注册、弱引用）现在就写入头部格式，作为共享环状工作负载的有文档增长路径。

## 已解决的开放问题

1. **不可复制数据跨 C 边界的 FFI pinning 策略。** RC/arena 堆从不移动对象（H4a），因此 pinning 是生存期问题。规则：借用模式的 extern 参数是调用作用域的裸指针，类型层禁止其逃逸出调用；持有的外部资源是 `~Copyable` 句柄，其 deinit 恰好释放一次；外部回调在 VM 管理的栈上执行；阻塞的外部调用钉住其纤程，当阻塞 C 调用必须与调度器并行时，载体线程是逃生口；取消只在 VM 重入点被观察到，因此进行中的线性消耗绝不会被中断。
2. **nursery 块形态与提取 token 集。** 块形态：`nursery { ... }` 内含 `spawn { ... }` 子表达式。token 按研究结论定稿：后缀 `?`（传播，带检查的包含规则，无隐式转换）、`or`（取首个想要成员，右操作数惰性求值，配 `or return` / `or break` / `or continue` 提前退出形式）、`is`（精化）、`.err(h)` / `.ok(h)`（集合差集类型处理器）。v1 无 `?.`。
3. **`.err` 差集类型的回退。** 已无必要：采纳 B1(c)，差集类型按设计生效。
4. **纤程与隐式生成器：一套还是两套设施。** v0 的隐藏迭代协议是不涉及纤程的线性游标；E2(b) 纤程就位后，隐藏降级可改用同一纤程设施。允许共享一套 VM 机制并分期实施；无论哪种，用户表层完全一致。
5. **生成器箭头 `-*>'（历史 README）。** 退役；1.0 无公开生成器语法（D3d）。作为「箭头编码类别」思想的先例记录在案。
6. **带作用域的具名实例（B6b 精简版）。** 延后增量，1.0 之后——除非不相交实例头解析被证明确实难为库作者；在任何未来语法糖中歧义永远是错误。
7. **不相交检查算法与递归实例终止性。** 实现自定义，但需求固定：检查在链接期对最终实例环境执行；重叠错误必须同时点名两个头与交集中的一个见证值类型；满足自身所需的条件实例被解析步骤上的结构环检查拒绝。
8. **`==` 之下的 float 相等。** 按位结构比较（自反、全体、字典安全）；IEEE 语义经具名的 `is_float_eq` / `is_approx_eq`。
9. **v1 中的 comptime 反射。** 分期：内建 derive 先行，comptime 求值器加反射在 1.0 前补齐。
10. **match 中的 `@` 绑定器。** 排除出 v1；若确有需求，作为增量补充，附带另行设计的仿射再绑定语义。

## 定稿的语言

DreamScript 是一门独立的通用解释型语言（可经平台包嵌入），采用混合集合论类型——名义标签在并、交、差下组合，`is` 精化，`T?` 作为 `T | none` 的别名——以带必需边界签名的双向检查加流精化校验，相等为带五处例外的通用结构化比较。值默认仿射，叠加可选的 `~Copyable` 线性资源层（`deinit`、幻影状态）、二等参数模式（借用 / `mut` / 消耗）、排他窗口可变与线性可变 COW 集合；内存是 Perceus 引用计数加块复用、垫在逐帧 arena 上，没有 GC。多态是实例头两两不相交的一致集合论 trait，一份泛型函数体携带证据词与内联缓存；元编程是不做宏的 comptime 反射。错误是并集成员，由 `?` / `or` / `.err` 处理，旁边是不可捕获的陷入；并发是强制 nursery 中的 VM 纤程，在线性/不可变可发送性基底上做 fork-join 并行；效应留在表层之下，垫在传递证据的处理器运行时与能力参数 IO 上。表层是 TS 系花括号配完整 UFCS、const 箭头函数、Rust 形态匹配与集合差集诊断、Kotlin 插值，语法糖预算为 22 项特性 / 35 单位。模块是定义 < 文件 < 包 < 模块，配生成接口与导入时不执行；包是 blake3 哈希级联清单，架在内容寻址存储与零配置脚本模式上；FFI 是线性 C 句柄。执行是三层管线——带类型寄存器 VM、copy-and-patch JIT、Cranelift/wasm——尾调用由规范保证，覆盖自身与互递归。

## 分期（v0 → 1.0）

按序执行；每一步落在上一步之上，不产生语言层面的返工。

1. 先锁定两个承重契约：槽位叠加调用 ABI（H2a）与定宽可 mmap 的 dsmod 格式（BL-7、G3.5）。下游一切都对它们编译。
2. 检查器内核：B1(c) 名义标签上的集合代数、B2 双向加精化、B3(d) 积/和、B4(c)、B7(a)、B8(a)、B9(a)；仿射检查器加 DI（C1b、C5c）。
3. Tier-1 解释器：computed-goto 或尾调用线程化的 uop 循环、拆箱槽位、标签+载荷 ADT、CALLT 栈帧复用 TCO。
4. 内存：Perceus dup/drop 插入、复用穿线、逐帧 arena；运行时 `rc==1` 检查与借用计数作为诊断层。
5. 并发：纤程、nursery、内部 `cancel`/`discontinue` 证据分派、fork-join 组合子。
6. derive；随后 comptime 求值器与反射 API（1.0 前）。
7. 工具承诺从第一天起生效，与其消费的查询编译器同步排序：`ds fmt`、结构化诊断、REPL、双槽热重载。
8. Tier 2 copy-and-patch（先 x86-64，后 aarch64；其余平台仅 tier 1）、尽早构建字节码到 SSA 降级、按需上 tier 3。
9. 内核稳定后的延后增量清单：`|>`、匿名 record 语法糖、`@` 绑定器、vararg/展开、`?.` 反糖、`throws(...)` 语法糖、用户自定义处理器、带作用域的具名实例；借用推断、TRMC 与融合作为纯优化落地，语言零变更。
