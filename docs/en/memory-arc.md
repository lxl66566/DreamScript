# Memory endgame arc

Execution contract: the author rulings that still constrain the runtime, the gates that stay green, the silent-breakage register, STOP conditions, and cost baselines. Author ruling 2026-11-12: adopt ds-rt (headered blocks, per-fiber heaps, arena temporaries), rework multi-word values to inline spans, and keep boxing rejected (per-field indirection the JIT cannot remove; BL-2's unboxed ADT story the terminus). Amended 2026-11-27: implicit boxing stays rejected; the explicit `box[t]` pointer is the one sanctioned indirection, spelled by the author at a recursive field.

## Binding register

- Per-fiber heaps: one `Objects` store per `Fiber` pool slot beside `segment` and `callinfo`, swapped by `Vm::switch_in`/`Vm::host_release`/`run`; a reused slot keeps its store, so a foreign-held object outlives its recycling; counts live in block headers.
- Ref word, AUTHOR-RULED 2026-11-12: payload `(fiber u32, id u32)` at zero frame-word growth (`Value` 16 B, no dsmod impact), held as `RefId`'s two fields so every read answers the owner and the id together; `RcHeader` keeps `flags` reserved for the dormant collector.
- Claim ledger and bands, AUTHOR-RULED 2026-11-12: the establishment band is the teardown witness — one dedicated frame word per claim, SET at registration and CLEAR at every death path and consuming move, so Ref-free spans fire once, dead claims on borrow copies refuse, and moved claims stay silent; the claim directory decodes the band's slot from the drop's own clear op and derives each site from the body's contiguous staging run plus its `$deinit` call (one hook per base slot and per consumed `Ref` word, innermost-first) (`crates/ds-vm/src/claims.rs`). The ledger gates counts alone: a per-fiber `ClaimTable` per pool slot, where a foreign word's count releases only through the dec'ing fiber's claim row (a never-claimed cross-heap dec releases nothing while still refusing a freed id; same-heap decs keep the gift-count discipline). Each door fires the kept-frame deinit hooks through the hosted live drive before releasing counts.
- Executor principle (C4 amendment), AUTHOR-RULED 2026-11-12: count mutations run only through the owning heap's funnels, a foreign heap posting requests drained to quiescence (`crates/ds-vm/src/object/heaps.rs`).
- Map row keys, 2026-11-21: a fresh row's key must be a scalar or a word of the map's own heap — `Objects::set_map` refuses a foreign key word before any count moves (`Trap::ForeignMapKey`, a foreign-keyed row would be content-unfindable); a content-equal foreign probe overwriting an existing row and foreign value words stay legal.
- Counts-stay transfer rule, AUTHOR-RULED 2026-11-12: cross-heap decs are admitted only at the teardown drain walk (also the E5 deinit pass) and the joiner's dec of a delivered word; host deliveries release, fiber deliveries transfer, the claim landing on the resumer or joiner at `die_current` and the nursery marking; the spawn seam acquires one count per `Ref` capture, a pooled child's scalar-only entry span keeping the in-flight foreign-dec class empty; host faces staging borrowed words keep the host's claims. A fork pool worker (2026-11-15, E3) takes the whole fiber (store, arena, ledger) by ownership transfer, returning it before any count crosses.
- Teardown drive rule: the walk decs each taken claim against the word's own heap, ignoring bogus words, at the cancel-cut preemption, the interrupt marking, the pool-slot reuse safety net, and `run`'s root reset. A hook must return to its driver: parking, dying (`HALT`), trapping, a raised cancel flag, or a nursery control seam refuses with `Trap::ReentrancyRefused`; teardown surfaces no user-hook failure.
- Closure capture counts, AUTHOR-RULED 2026-11-25: CLOSURE_NEW's per-Ref-capture acquire stays inside the op permanently — count adoption (a forward/dup at the staging replacing the kind-based acquire) makes the object's edge count reachable from any frame-word `RcOp::Dec`, and the fuzz mirror's noise decs steal holder counts to a dead id (seed 626), so the object's count keeps its own identity beside the frame's claim, the op acquiring one edge count per Ref capture at creation.
- Intern tables, AUTHOR-RULED 2026-11-12: each heap interns its own KSTR copy with counts local, the VM-global `kstr_cache` gaining a fiber axis, rows reclaimed at the version-retiring swap and the slot reuse; a pin-counted global pool stays rejected.
- KSTR borrow seam: `produced_kstr` marks a string-literal load with no count transit between birth and death, `finalize` rewriting it to `KSTR_BORROW` (uop 0x03, no claim row) with its paired terminal RCDECs deleted, a transiting slot keeping the acquiring spelling; `intern_borrow` pins the canonical copy until fiber death and heap drain.
- Capture-store window, 2026-11-25 (item 118's mut window): CAPTURE_STORE (0xD.5) replaces one word of the running closure object's own capture block — one edge acquire for the incoming word ahead of the swap, one edge release for the displaced word after, both routed by owner through the edge funnels (no frame claim, the frame's own copy untouched, a self-store over the same object safe because the acquire precedes the swap); the object is the frame's own running closure named by the Ref word CALLS writes past the capture block, so the lowerer's exclusivity proof is compile-time and the op runs no runtime check. Both words name the closure's own captures, so the counts-stay rule holds — no foreign dec ever rides the window.
- STRCAT arena seam: `produced_strcat` (the same disqualification plus a `loop_exit` drop for words owned at the loop's depth) rewrites a produced result to `STRCAT_ARENA` (Ref major 0xD minor 4), arena-served behind the frame's entry mark, popped at every RET and CALLT, released at the death and drain doors; the read funnels refuse it with `ArenaHandoff`, EQSTR/NEQSTR comparing across domains. A marked loop (body holding a designated serving): `ARENA_MARK` (Ctl 0x9 minor 3) at the head, `ARENA_RESTORE` (0x9 minor 4) at the back edge, one I64 cursor word; a word crossing a back edge alive keeps its counted spelling through the `loop_exit` prune; a frame that cannot host the mark words (the u8 slot ceiling) keeps the counted spelling.
- Packed handle, author-ruled 2026-11-12: `chunk:16 | offset:24 | len:24` in the u64 payload of `Value::Arena(ArenaStr)`, `Value` at 16 bytes; every field limit is a named refusal (`ArenaExhausted { field }`, the length trap before the allocation, `ArenaHandle { class }` for a hand-packed restore cursor).
- Dispatch layout: the hot dispatch keys on the raw opcode byte with every other byte falling to one slow arm through the decoders, keeping the cross-crate `Uop::decode` call out of the hot loop; threaded side-table dispatch stays rejected.
- Span shapes and channels: `union_shape` claims each field the lowest free contiguous region span (contiguity, per-word kind stability, disjoint fields, zeroed dead words); `slide_plan` moves flat word ranges pairwise, so a multi-word parameter is consecutive slots with the u8 staging/nargs and RETSPAN width staying the ceilings; `NativeResult::Span` writes the tag at overlay word 0 and its payload at `1..=payload.len()`, so the span is `1 + payload.len()` words against the caller's argument area and refuses `RetSpanTooWide` past it, `NativeResult::Total` answering N words with no discriminant; `Staging` names the staged-span discipline (fixed, one leading span, one interior span) that folds and combinators stage through, the hosted result channel answering inline words with the heap buffer only past four.
- Arena domain and element spans: an arena payload is a third `Value` domain beside counted blocks, the escape proof compile-time (`crates/ds-rt/src/arena.rs`); a temporary is a produced count with no RCINC, staging forward, closure capture, exit transfer, or loop carry (`crates/ds-lower/src/place.rs`); collection elements ride whole word spans at a per-list element stride, a disagreeing append or ragged width trapping `ElementStride`.
- Refusals, audit verdict, pinned residual: reboxing, union and deinit-carrying elements, a tuple arm in a member-test position, multi-word tuple elements, an unproven callable word entering a heap position (the element's Ref slot takes the closure Ref only; the scalar-provenance refusal retired 2026-11-27), a deinit-carrying channel payload (the buffer's edge retention owns counts, never claims — the same per-span deinit-claim seam the element refusals wait on), and the five deinit refusals pinned in `crates/ds-lower/tests/deinit_e2e.rs`. Opened by ruling (2026-11-27): the per-span deinit-claim seam over collection elements and channel payloads is the ownership round's design item, the refusals standing until it lands. The terminal-RCDEC placement audit closed 2026-11-12: designated temporaries are exhausted, the residual the count-mandatory population (native-answer copy-outs, callee-object answers, checked-read hand-outs, loop-carried rollovers, capture copy-ins), any deletion removing the callee's answer construction and the caller's terminal dec together, re-opened only by an author ruling over a hot population. Every body-produced word dies in-body; every count-bearing word's classification stays visible to its uses and binder; a `resume_fiber`-interrupted detached child's claims are kept for the VM's life.

## Gates that stay green

- Fibers and nurseries: the fiber/nursery suites, effects_nursery.ds, and nursery_surface.ds green unchanged; each child-death path (completed, cancel-cut, trapped-interrupted) drains its heap to zero; the spawn copy-in balances under the `diag` rc tripwires; KSTR loads serve across switches; no arena action at any switch; the diag-armed release build runs both corpora to clean exits.
- Teardown deinit: exactly one fire per established claim under cancellation and interruption, band-gated (`teardown_deinit` corpus and `crates/ds-vm/tests/teardown_deinit.rs`).
- Arena temporaries: strcat_arena (across-domain servings and drains, the counted funnel's refusal, the length trap, the cursor misuse class, the back-edge restore footprint); the placement pins (a marked loop taking one mark/restore pair and no terminal dec, the native-staged link keeping its count); the zero-RcOps and escape pins; kstr_borrow (claimant churn, first-borrow, release semantics, pool-kind refusal); native_frame_balance and value_match_e2e.
- Spans: the shape pins (member span disjointness within a union, exact zero-init coverage), the width-flip e2e (span_fields_e2e: flow, Ref-word balance, refusal names), the fold's struct-element e2e, the tuple-element e2e (span_channel's read-back, Ref-word balance, iteration), and the corpus byte-identical under the diag-armed release binary.

## Silent-breakage register

- A half-done stage two frees an object early and the freed id reuses for another object (wrong values, no trap); a half-done span rework lets two members' payload words overlap (kind checks pass, foreign values read); a half-done stage three deletes the dec of a word that escapes (premature free). The gates above are the tripwires.

## STOP conditions

- Escalate to the author when any dsmod format change becomes unavoidable (none is identified, the flat slot list carries spans), when the committed `RcHeader` layout needs a new field, when cross-fiber references force count mutation outside the owning heap, or when the KSTR ruling needs cross-heap counted constants.

## Measured cost baselines

- Gungraun pins (nine kernels, authority `PINS` in `crates/ds-pins/tests/pin_bake.rs`): string_temp's 5M-iteration kernel measures 4,800,897,010 Ir borrowing against 16,910,895,225 Ir acquiring (2,422 Ir per iteration, 3.52x); strcat_temp measures 9,000,901,854 Ir serving against 15,850,902,295 Ir claiming; the back-edge restore holds one iteration's footprint where the restore-less spelling grows with the iteration count (`crates/ds-vm/tests/strcat_arena.rs`). The harness re-measures every pin on each bench-profile gate run and fails outside ±0.1% (debug profiles and valgrind-less hosts skip), so `PINS` is the only baseline a reader trusts.
- `scalar_loop` (`crates/ds-pins/benches/scalar_loop.rs`) is the absolute-Ir pin against threaded side-table dispatch; the wall-time regression gates sit at ±2%.
