# DreamScript error codes

Generated by `ds doc --errors` from the diagnostic registry; do not edit by hand. A code's meaning is pinned at its registry entry, so the table regenerates whenever the registry moves.

## Parse and syntax (DS1xxx)

| Code | Description |
|---|---|
| `DS1001` | Token not valid at this position. |
| `DS1002` | Input ended while a construct was still open. |
| `DS1003` | Literal does not fit its declared form. |
| `DS1004` | String or raw string left unterminated. |
| `DS1005` | Invalid escape sequence in a string literal. |
| `DS1006` | Character not valid in any token. |
| `DS1007` | String interpolation hole malformed: `$` not followed by a name or `{`. |
| `DS1008` | Bracketing delimiter unclosed, closed by the wrong partner, or stray. |
| `DS1009` | Source nests deeper than the parser's fixed limit. |
| `DS1010` | A trait or impl member is not a `fn` declaration. |
| `DS1011` | One call passes two values for the same named argument. |
| `DS1012` | A default argument value is not a literal. |
| `DS1013` | A top-level named const-arrow lambda; `fn` is the only named-function declaration. |
| `DS1014` | A top-level statement outside the entry file's script mode. |
| `DS1015` | Script statements synthesize `main`; the entry file already declares `main`. |
| `DS1016` | A match guard's bare identifier directly before `=>` is read as a bare-parameter lambda; parenthesize the guard expression. |
| `DS1017` | A lambda arrow chain deeper than the parser's unbracketed recursion budget. |
| `DS1018` | An `else if` chain deeper than the parser's unbracketed recursion budget. |
| `DS1019` | Two comparison operators over one operand list (`a < b < c`); each comparison binds one pair, so parenthesize the grouping or join the separate tests with `&&`. |

## Type system (DS2xxx)

| Code | Description |
|---|---|
| `DS2001` | Value's type is not contained in the expected type. |
| `DS2002` | Inference could not pin a type; there is no `any` fallback. |
| `DS2003` | Match does not cover the scrutinee type; the message names the missing members as a set. |
| `DS2004` | Name not found in scope. |
| `DS2005` | Two definitions claim one name. |
| `DS2006` | Two trait instance heads intersect; the message names both heads and a witness value type. |
| `DS2007` | Wrong number of arguments at a call. |
| `DS2008` | `?` propagates a member the enclosing return union does not contain. |
| `DS2009` | A conditional instance's condition resolution reaches back to itself, directly or transitively. |
| `DS2010` | Instance lookup found multiple containing heads; the message names the competing heads. |
| `DS2011` | An instance head denotes the empty type. |
| `DS2012` | A tuple distribution would mint more atom combinations than the solver's cap. |
| `DS2013` | A trait constraint has no instance for the type; the message names the trait and the type. |
| `DS2014` | Several trait instances match one dot-call; the message names the competing heads. |
| `DS2015` | `self` used as a type name; the receiver type is spelled `Self`. |
| `DS2016` | The receiver parameter carries an annotation; spell it `self` or `mut self`. |
| `DS2017` | `in` right-hand side is not a range; membership is range-only, the list spelling the member call `xs.contains(x)`. |
| `DS2018` | An impl member's signature disagrees with its trait member's arity, parameter modes, parameter types, or return. |
| `DS2019` | An impl member re-declares a parameter default its trait member owns; the trait declaration is the default's single authority. |
| `DS2020` | An impl member declares a parameter default its trait member does not have; there is no trait default to override and the literal never stages at a call site. |
| `DS2021` | A trait or impl member's signature declares no receiver; the first parameter is `self` or `mut self`, typed `Self`. |
| `DS2022` | An enum case named `none` carries a payload; `none` is the predeclared unit atom, so the case claims no atom of its own and its construction refuses. |
| `DS2023` | A trait impl provides no body for a trait member that declares no default body; dispatch would have no body to plan. |
| `DS2024` | A derive family in the vocabulary with no expansion; the message names the family. |
| `DS2025` | A derive name outside the vocabulary; the message names the vocabulary. |
| `DS2026` | A derive part refuses structural derivation (a function-typed or ~Copyable part); the message names the part. |
| `DS2027` | `==` in a derive list; equality is a universal structural operator and is never derived. |
| `DS2028` | A derive attribute on a declaration that is not a struct, enum, or tag. |
| `DS2029` | A derive on a declaration carrying its own type parameters; the synthesized member reads its parts through those variables, which the one-body-per-impl runtime seam cannot carry (per-instantiation frames are the JIT tier's). |
| `DS2030` | A parameter annotated `type` without the `comptime` mode; type values exist only inside comptime evaluation. |
| `DS2031` | A `comptime` parameter outside the round-one shape: every parameter comptime and `type`-annotated, on a free fn (the message names the broken clause). |
| `DS2032` | A type name used as a value, or a reflection builtin called, outside a comptime evaluation context. |
| `DS2033` | A world-touching call inside a comptime function: the evaluation's fence refuses it as a compile error. |
| `DS2034` | The comptime evaluator's honest refusals: an argument shape it does not stage, a result it cannot embed, or a trap the fenced run raised. |
| `DS2035` | A pooled fork-join child's body reaches a sibling-addressing fiber control native. |
| `DS2036` | A pooled fork-join child's body reaches the world surface. |
| `DS2037` | The comptime fence's callee admission refuses a runtime callee: an impure effect row, a generic body's evidence seam, or a member call with no planned body. |
| `DS2038` | The `#[default]` union-member annotation's refusals: a second annotated member of one union, an annotation no default derivation reads, or one outside an enum case. |
| `DS2039` | A `return` in a value-consumed position: an early exit is a statement, so a block whose value feeds a binding, an argument, or a join arm refuses it. |
| `DS2040` | A written type application disagrees with its head declaration: a generic applied with the wrong number of type arguments, or a head that takes none (a tag, a case, a value-namespace name, a non-generic declaration). |
| `DS2041` | A tag declared with a tuple payload; a tag's payload spells named fields. |
| `DS2042` | A struct field whose type solves to `none` alone; `none` is the optional's absent member, a member of `t?` spellings, never a standalone field type. |
| `DS2043` | A linked package's exported `const` whose initializer the producer-side evaluation cannot answer: a reach the fence refuses, a trap or runaway the fenced run raised, or an answer outside the const fact's vocabulary. |
| `DS2044` | A linked package's exported trait member whose declared default body cannot cross the link seam: the body did not plan, demands runtime evidence, or carries an effect row the consumer cannot replay. |
| `DS2045` | A bare tag label matches no member of the expected type: the directed positions (match arms, `is` tests, annotated bindings, parameters, fields, returns) resolve a label against the expected union's members, and no member carries it. |
| `DS2046` | A bare tag label matches several members of one expected union: two declarations sharing a label both sit in the expected set, and the qualified spelling `type::label` is the escape hatch. |
| `DS2047` | A linked impl shadows another impl of one trait over one head, or is shadowed: the link resolved the pair by package identity (the root package's own impls over every dependency's, an origin impl over a third party's), and the warning names the winner, the loser, and the action. |
| `DS2048` | Two linked impls of one trait over one head sit in the same resolution layer (two third parties, or two origins), so no layer of the link identity separates them; the link refuses naming both packages. |
| `DS2049` | A shadowed impl's declaring package statically exercises its own head (its linked artifact baked a statically-resolved instance word naming it), so the link cannot shadow it without one value answering two behaviors; the link refuses naming the loser. |
| `DS2050` | A call site's `as` selection on a call that dispatches through no trait instance: a free function, an inherent member, a constructor, or an indirect callee has no instance vocabulary to select. |
| `DS2051` | A call site's `as` selection names no impl of the dispatched trait for the receiver: no impl of the trait carries the name, or the named impl's head does not serve the receiver. The message names the trait, the receiver, and the selection. |
| `DS2052` | A root package's inherent impl member shadows a linked member of the same owner type (the root package's own impls over every dependency's, the link layering's root-over-deps rule), and the warning names the winner, the loser, and the action. |
| `DS2053` | A position typed `never` (the empty type): a binding annotation, a parameter, a struct field, or an enum case payload. No value inhabits the type, so the position cannot hold one. |
| `DS2054` | A fn declaration's return type names a type variable no parameter mentions; the variable never solves from a call's arguments, and a diverging declaration answers `never`. |
| `DS2055` | An impl of a trait carrying the `#[sealed]` origin attribute, from outside the trait's declaring file: the seal admits only the origin's own impls, so a third-party package's impl (a linked trait's consumers included, the root package's own over a dep's sealed trait) and a foreign-file impl of the same package both refuse. The message names the trait and the seal. |

## Linearity and ownership (DS3xxx)

| Code | Description |
|---|---|
| `DS3001` | Binding used after being moved. |
| `DS3002` | Binding read on a path where it may not be initialized yet. |
| `DS3003` | Copy attempted on a `~Copyable` value. |
| `DS3004` | `deinit` well-formedness broken: not exactly once on all paths. |
| `DS3005` | Call-scoped borrow escaped its call. |
| `DS3006` | A `mut` window parameter receives a `const` binding; spell the binder `var`. |
| `DS3007` | A for-in body opens a `mut` window over its own iterated binding; the loop's element count froze at entry, so the mutation never joins this loop's walk. |
| `DS3008` | A spawned body opens a `mut` window over a binding outliving its nursery block; the refusal is permanent and drive-independent. |
