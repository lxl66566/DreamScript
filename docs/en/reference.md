## Language (ambient)

### Traits

#### `Copyable`

The copy marker: a type whose words copy carries it; `~Copyable`
on a struct declaration opts out.

```ds
pub trait Copyable { }
```

#### `clone`

The duplication face: one member answering the shallow
duplicate; `#[derive(clone)]` synthesizes the impl.

```ds
pub trait clone { fn clone(self) -> Self }
```

#### `hash`

The hashing face: one member answering the content hash,
consistent with structural equality; `#[derive(hash)]`
synthesizes the impl.

```ds
pub trait hash { fn hash(self) -> int }
```

#### `ord`

The ordering face: one member answering the lexicographic
comparison; `#[derive(ord)]` synthesizes the impl.

```ds
pub trait ord { fn compare(self, other: Self) -> int }
```

#### `show`

The text face: one member answering the value's rendered text;
`#[derive(show)]` synthesizes the impl.

```ds
pub trait show { fn show(self) -> string }
```
