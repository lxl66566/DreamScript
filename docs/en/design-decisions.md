## 0. Author supplements — binding

## 1. The decided language

Set-theoretic types over nominal tags with boundary signatures and flow refinement; affine values with an opt-in linear layer; Perceus RC with block reuse and no GC; coherent traits over per-shape instantiated generic bodies; comptime reflection without macros; errors as union members; VM fibers in mandatory nurseries with fork-join parallelism; an evidence-passing handler runtime with capability IO; three tiers with guaranteed TCO.

## 2. Identity and compatibility

- **A1 — standalone core, embedding via platform packages.** The standalone runtime is the only architecture; embedding arrives as ordinary packages exporting effect handlers over it, the default platform the `ds` CLI.
- **A2 — workloads.** CLI/tools/scripts primary, games/simulation secondary (interpreter-first startup, script mode, two-slot hot reload); numeric/AI reaches the Cranelift tier without shaping v1.
- **A3 — compatibility.** Rapid-break until 1.0, semver after; content addressing applies at package level (H6), never to source identity.

## 3. Type system

### B1 — hybrid set-theoretic types over nominal tags

Nominal declarations carry identity; unions, intersections and differences of nominal atoms are ordinary type expressions. Exhaustiveness checks by tag identity, differences erase at compile time, a union is its unboxed tag+payload layout, an intersection keeps the most precise member's layout, inference failure a compile error with no `any` fallback. Fallback B1b: a nominal-only core if the disjointness checker slips schedule. Bottom (2026-11-27): `never` is the empty set, declared once as an ambient zero-case enum, a member of every union and the return type of a call that yields no value, so a diverging call sits in any value position.

### B2 — bidirectional checking with boundary signatures, plus flow refinement

Boundary signatures required at top level and on public items; locals, lambdas and arms infer bidirectionally. Refinement narrows through `is`/none tests and arms, reset at assignment; `?` is containment in the written union; no narrowing through mutable union fields. Rulings: a value-level arm subtracts nothing (2026-11-12), so later arms check the full scrutinee and arm ordering is refused; per-element refinement is out (2026-11-15) for reintroducing arm-order dependence. Ruling (2026-11-25), two inference completions: a `.err`/`.ok` handler lambda's parameters receive the handled members' types as the expected type (the site threads it; the disjoint `empty`-handler refusal class retires), and a fn-typed parameter's return type unifies against a written signature by first-order pattern match — strip one application, bind variables directly — when the argument is a lambda literal or a named fn with its return written. Amended 2026-11-26: the fn-value refusal covers fn values carrying their own unsolved variables alone (a generic named fn passed bare or through a const), general higher-order unification staying permanently out, while a monomorphic indirect fn value (a fn-typed const or parameter) solves through the parameter's existing containment arm — sanctioned working behavior, never refused. `.ok` on a `t | none` receiver defaults the handler parameter's expected type to the receiver minus `none` when the body walk derives no set (`.ok` reads as the present-value arm; the difference rule keeps governing `.err`), landing as its own small round. Inferred error members on non-`pub` functions stay behind a quantified trigger (a real signature-widening pain measured on corpus or library code, the C4b discipline); `pub` signatures keep the explicit-full requirement.

### B3 — nominal structs/enums plus anonymous tuples

Named data is nominal structs and enums (declared layouts, tuple-enums, punning); ad-hoc aggregates are anonymous tuples with destructuring. Enum blocks the only payload-case form; `tag x;` declares unit tags; type aliases never declare cases (2026-11-10). Construction fixed per declaration, a cross-spelling a checker error. The list literal is in v1; map and anonymous record literals stay deferred additive; row types rejected. Indirection (2026-11-27): `box[t]` is the explicit owning pointer to one heap-held `t`, a one-word value under the collection counting rules; a recursive declaration spells its recursion through `box`, a cyclic field type without it staying refused and every other type staying inline.

### B4 — `T?` is exactly `T | none`

Optionals, error unions and enums share one mechanism (`is`, match, `?` with E4's extraction family), `none` a unit type among several. No `?.` in v1; `??` on `t | none` is the single recorded operator valve, rejected by default and reopenable only through the M9 backlog triage on corpus evidence that `t | none` fallback dominates (2026-11-17). Limit: `V | none` where `V` may itself be `none` is ambiguous — wrap explicitly.

### B7 — numerics: i64/f64 defaults, trapping overflow

`int` is i64, `float` f64, raw in unboxed slots; conversions always explicit calls. Integer overflow, `1 / 0` and `int_min / -1` trap; `+%`/`-%`/`*%`/`-%a` wrap for hash and PRNG use; floats follow IEEE and never trap; error-union arithmetic variants are library functions; `Dec` and units-of-measure are nominal library types plus derives. Ruling (2026-11-15): a shift amount outside `0..64` traps, `>>` sign-propagating, `&`/`^`/`|` never trap. Width construction (2026-11-19): the u32 trapping conversion is an ambient member over the checked `u32_of` and the bare `trap` primitive, `u32_of` the fallible form, spelled `u32.of(x)` — the bare `u32(x)` is unlandable (DS2002: an ambient value named `u32` makes every call form DS2014-ambiguous under F9) and permanently refused (closed 2026-11-21); `u32.of(x)` is the final spelling.

### B8 — strings: immutable UTF-8, checked slices

Immutable UTF-8 bytes behind one raw pointer plus byte length. Slices are non-owning borrows kept alive by the parent's RC, landing on char boundaries through a checked API returning `string | none`; equality is O(n) with length fast-reject. Ruling (2026-11-12): string-operand `+` spells the concat native, `+=` the same operation; mixed operands refuse at both layers. Cleanup (2026-11-17): `substring` and `char_at` answer the checked forms (`string | none`, `char | none`); `head` retires, `first` the one list-front spelling. `char` (2026-11-27): an unboxed scalar, one Unicode code point in the integer slot, compared and hashed as that code point and encoded to UTF-8 by `show` and interpolation; a `char | string` operand is an ordinary tagged union.

### B9 — universal structural `==` with five carve-outs

One structural `==` over all data, total by construction, never user-overloadable. Carve-outs: function comparison rejected statically; floats compare bit-structurally (`nan == nan` true) with named `is_float_eq`/`is_approx_eq`; mutable cells and `~Copyable` resources compare by identity; operands borrowed; `hash` stays consistent. `Ord`/`hash`/`show` are derives, ordering never structural. Ruling (2026-11-14): `fn hash(self) -> int` over a borrowed receiver with ambient primitive impls, float normalizing `-0.0` and every NaN payload, one seed folded per part. Ruling (2026-11-21): collection content equality and map key matching ride the same bit-structural word equality as scalar `==`; `scalar_hash` hashes bits; `-0.0` and `0.0` are distinct keys; NaN keys are reflexive and overwritable. Closes the 2026-11-20 review B10 question (todo item 84).

## 4. Linearity, ownership, memory, data

### C1 — affine core, opt-in `~Copyable` linear layer

Assigning an affine value moves it; a moved binding is dead. `~Copyable` subtracts the default copyability constraint, carries `deinit` and admits phantom-state unions; affine checking is an intraprocedural last-use/DI pass. The `rc==1` uniqueness checks plus a borrow counter ship as the diagnostic layer. Ruled 2026-11-17: this is the ownership endgame; no lifetime-annotation or GC escape hatch is reserved.

### C2 — second-class parameter-passing modes

Three modes fixed at the definition site — default borrow, `mut` (exclusive), consume — no mode syntax at call sites. Borrows never escape a call, so checking is intraprocedural and no lifetime annotations exist; first-class references permanently out. Subscripts extend the modes to element access.

### C3 — `const`/`var` bindings, mutation through `mut` windows

`var` is a rebindable local; callee-side mutation goes through `mut` parameter windows — one mechanism serving parameters, windows and confinement (D1) — with zero runtime checks inside (alias-freeness proven; a copyable collection's mutating native reads its count, amended 2026-11-27).

### C4 — Perceus precise RC + block reuse over per-frame bump arenas

Precise non-atomic RC (bump per clone, dec per unique death, each drop a reuse candidate) over per-frame bump arenas holding non-escaping temporaries; linearity makes escape a compile-time fact. Ruling (2026-11-12): every count mutation runs through the owning heap's count funnels; a foreign heap only posts requests drained to quiescence. Clone-family (2026-11-15): `fn clone(self) -> Self` over a borrowed receiver; the derive constructs from one dispatch per part, so the duplicate is shallow (a Ref dups by a count bump), adding no uop and no native. Unit-word ruling (2026-11-15): a part-less struct occupies one reserved word in every value position, never read. Fallback C4b: generational references wait on a quantified trigger — the moved-after-use rate crossing a threshold that tutorial feedback confirms is ownership-specific. Sequencing (2026-11-27): C4b's shape stands as recorded, its round waiting on `box[t]` and the collection value-semantics landing, the timing set by the arena pattern's frequency in real programs — the fixture prices the hand-rolled bypass against @std's `arena[t]`, C4b's own gain over the arena unmeasured. Vocabulary (2026-11-27): a counted path to an object is an owning share, an uncounted one a borrow, `alias` naming the relation alone.

### C5 — `deinit` restricted to `~Copyable` types

`deinit` runs exactly once at the unique instance's death on every path (early return, panic, cancellation teardown), dispatching statically. `drop` is a debug/FFI tool only. Opened (2026-11-27): a deinit-claim fact riding a collection element or a channel payload is the ownership round's design item, the hook firing once at whichever door ends the element's wait, beside the optional-over-linear union.

### D1 — exclusion-window mutation is the only channel

Mutation is always a named call on an owned receiver with a `mut` mode: statically exclusive, lexically visible, zero runtime checks; shared mutation unrepresentable. Amended 2026-11-27: the zero-check claim covers `~Copyable` windows; a copyable collection's mutating native reads its count (D2).

### D2 — linear-mutable COW collections

Collections expose a functional API and mutate in place iff uniquely owned (guaranteed, observable reuse); aliasing means copying — a perf note, never an error. Ruling (2026-11-10): a `mut` window parameter takes a `var` binding at the call site whenever its argument copies, a `const`-binding receiver being DS3006; COW-on-alias is rejected (the hidden copy keeps mutation invisible at the call site). Ruling (2026-11-27, provisional): a collection is a value — its mutating native copies before writing at a shared count and reuses in place at a unique one, the copied word re-stored through the receiver's window — the 2026-11-10 refusal of COW-on-alias superseded while a `const` receiver keeps DS3006. The roster: `list`, `map` and `box` are values; `chan` and a closure with mutable captured state are shared objects. Measured on the mutation kernel (`crates/ds-pins/benches/mutation_kernel.rs`, 40,000 member pushes plus 40,000 member sets plus one read pass, medians of three Callgrind runs per side, 2026-11-27): 287,304,565 Ir before the landing against 326,394,832 Ir after it, a 1.136x instruction tax on the mutation path — the per-call count read plus the answer word's re-store accounting the door adds at a unique count. The landing still owes the count read's static elision and the JIT's elision revisited with the JIT tier; the recorded fallback is reference semantics plus an explicit copy-on-write collection type.

### D3 — combinators over a hidden linear cursor

User surface: combinators (`map`/`filter`/`reduce`) plus `for`; the hidden protocol is a linear cursor fused into loops by the compiler; no public generator syntax in 1.0. Iteration-count ruling (2026-11-20): a `for` over a list takes the element count once at loop entry, so a body appending to its own iterable never visits the appended elements this loop. Refinement (2026-11-21, DS3007): the checker refuses the body's `mut` window over the very iterable; the frozen count stays the runtime guarantee.

## 5. Errors, effects, async, parallelism

### B5 — errors are union members of return types

Errors are storable data, one predicted branch in the VM, carrying an effect row's information; a `throws(...)` spelling stays later sugar. Propagation requires the enclosing return union to contain the member (checked containment, no implicit conversions).

### E1 — no effect syntax in v1; handler-shaped runtime, capability idiom

The runtime is handler-shaped from day one: evidence passing serves `cancel`/`discontinue` at nursery boundaries, tail-resumptive with zero allocation. World-touching stdlib APIs follow the capability idiom — an ambient handler installed by the `ds` CLI, an explicit capability parameter for tests, embedding and scheduler choice. User-defined handlers stay a v2 additive escape hatch under a recorded trigger (2026-11-17): only a real use case a capability parameter cannot cover cleanly (test injection, mid-tree policy switch); resumptions affine, the multi-shot valve closed; FFI calls pin the fiber (H5).

### E2 — VM fibers with a mandatory nursery

Stackful heap fibers on the VM pool. `spawn` exists only inside `nursery` blocks; scope exit joins children, first failure cancels siblings, child errors union out at the boundary. Blocking-style code, no colors, no `await`; preemption is a flag check on backward jumps; bare detach requires an explicit root nursery. Amendment (2026-11-12): re-entry of a parked child by the join/teardown driver is preemption-shaped, so a parked child of a cancelled nursery dies with the cancel sentinel to its resumer; a payloaded cancel rides the native channel's flat span. Lowering refuses bare `spawn` outside a nursery, a member outside the enclosing return union, and a payloaded member whose payload is a union or non-heap application.

Scheduler and reactor rulings (2026-11-21): the VM gains a run queue and a park-on-world-op discipline — net and time ops park the calling fiber with a resume point after the op, FIFO fairness over backward-branch preemption points; single-thread executor first, the multi-thread fiber executor landing in 0.x (amended 2026-11-27, no longer post-1.0 and never the earliest round). `platform "std"`'s net face implements over a reactor (epoll/kqueue/IOCP, io_uring a later swap) installed through the E1 capability seam, zero syntax or type-system change; blocking semantics stay an embedder's platform choice, never a language fact; TLS rides rustls over non-blocking sockets. A parked fiber observes nursery cancellation by reactor deregistration delivering the cancel sentinel at the resume point (extends 2026-11-12). Spawn-order determinism holds within the pure fork-join drive alone — once a child can park on a world op the relative order of sibling observables is unspecified — and a spawn body may never hold a `mut` window over a binding outliving the nursery block (permanent, drive-independent); nursery results flow through the children's answer spans collected in spawn order.

Executor eager-start (2026-11-22, item 79): a parked joiner's own Ready nursery children start under the executor loop instead of waiting for its join drive, driven contained exactly like a sweep (a child's trap reported by the boundary, never the host drive); the host-supervised root nursery's children stay the host's own drive to join.

Server half (2026-11-22): `net_listen` answers the linear `net_listener` over the `net_handle`/`file_handle` discipline (deinit over idempotent `net_listener_close`; an accepted stream owns the full `net_handle` face); `net_accept` parks on the listener's readability, the blocking twin polling to the same configured bound; bind and non-blocking accept are std's own, the socket2-or-raw question staying the non-blocking connect's alone (item 79 residual). Both spellings keep the total shape the deinit-carrying handles force (C5), a failed bind or accept halting on the net error line like `net_connect`'s printing halt. Server TLS and signal handling stay pending (item 76 residuals). `local_addr(l)` (2026-11-24): over the raw `net_local_addr` seam, the bound "host:port", total over the live handle, the inert empty string the unknown-handle answer.

Connection half (2026-11-23): the parked non-blocking connect rides the raw OS socket (libc's own `socket`/`fcntl(O_NONBLOCK)`/`connect`, no socket library), the completion probe a second `connect` reading the socket's own state (0 or EISCONN connected, EALREADY pending, the errno otherwise), not `getsockopt(SO_ERROR)` — its errno queue a security-brokered host can leave polluted. `http_get` parks through the same staged machine (connect, request drain, response reads to the close, one step per wake, the per-op bound re-armed each step); non-Linux hosts keep the blocking twin until the kqueue/IOCP rounds own the raw seam. https parks the same way (2026-11-23): the rustls session is a synchronous state machine driven one step per readiness wake, the peer's TCP EOF answering the close-tolerant finish exactly the blocking twin's UnexpectedEof mapping.

DNS twin (2026-11-24, item 79): step 0 of the staged connect machine is host-name resolution — std's `to_socket_addrs` is a blocking getaddrinfo with no epoll-integrable twin (getaddrinfo_a does not exist on musl), so under the reactor an IP-literal host resolves inline while a name resolves on the connection table's dedicated helper thread, completion posting an eventfd the reactor watches. A failed lookup answers its own `net_err`; the resolve wait keeps the configured net-timeout bound as its deadline-wheel wake; a canceled wait's late posting never writes a closed fd; the helper thread never outlives the VM. Reactor-less embedders and non-Linux hosts keep the inline blocking resolution; no new script syntax, op-table row or resolver library entered.

Server TLS (2026-11-23): the accepted connection's upgrade rides the same tls capability — a host-pinned rustls ServerConfig (`set_tls_server_config`; no default identity exists, a server certificate being the host's own to pin, the unprovisioned call answering its own refusal) — with `net_accept_tls` (raw seam behind the ambient's total `accept_tls`) taking one pending connection off the bound listener and answering the connection's `net_handle` word, the stream owning the full face over the tls records (`net_send` draining owed records before any plaintext stages; `net_recv` draining buffered plaintext first, the close-tolerant EOF kept). The staged handshake is the client round's own shape (accept on the readable door, then wants-write/wants-read naming the interest each wake); non-Linux hosts or reactor-less embedders keep the blocking twins (bounded accept, bounded handshake, session-backed rows); the total spelling over C5 means a failed accept or handshake halts on the net error line, the optional-over-linear union seam staying queued; the accept keeps the configured net-timeout bound per step.

Process face parked waits (2026-11-23): under an installed reactor the blocking rows park the net face's own staged shape — `proc_read`/`proc_read_err` flip the pipe non-blocking over fcntl and park on readability; `proc_wait` rides a pidfd (`pidfd_open`, Linux 5.3+), the wake reaping the status over the idempotent reaped word. The kernel reports a drained, write-end-closed pipe as HUP alone (no IN bit), so the readable wake takes the HUP as the orderly-end answer. No-reactor, non-Linux and old-kernel (EINVAL/ENOSYS) hosts keep the blocking twins (the blocking `proc_wait` twin polls on a bounded sleep loop, a flipped stop flag cutting a blocked wait within one interval); the parked rows' default bound is the far backstop (a wait sees any child out) over the configured process timeout.

Signal and shutdown (2026-11-24): the CLI host translates SIGINT/SIGTERM into a shutdown event — Linux through a signalfd registered as reactor interest (the blocked mask installed before any thread spawns, the wake's signalfd_siginfo naming the signum the exit code carries), non-Linux Unix through a sigwait helper thread, Windows through a console-control handler, all flipping the blocking drive's stop flag — and the language exposes no Unix signal concept: the shutdown wake raises every open nursery's cancel flag so every parked fiber dies with the cancel sentinel exactly a cancel's (the root drive's cut included, deinit hooks firing), the engine deciding nothing, the exit code the host's own per the die split (Unix 128+signum). The signal is the quiet accept's backstop: `net_accept`'s parked wait defaults to unbounded, every other op's deadline discipline unchanged, reactor-less or non-Linux embedders keeping the bounded poll twin (the blocking `proc_wait` twin the same discipline, landed 2026-11-24, item 96); a non-halting accept stays the ownership round's optional-over-linear union seam (2026-11-24, no accept-specific patch).

### E3 — fork-join parallelism on the sendability substrate

Race-freedom and sendability are static consequences of linear/immutable data: `par_map`/`par_reduce` over immutable or partitioned inputs are deterministic, replayable, lock-free by theorem, RC counts thread-confined through the fork-side transfer. The join parks the call site through the interlock drive; nested calls correct at any depth; a fork at a tail dispatch site refuses with a structured trap (2026-11-13). `par_reduce` is a sequential fold with byte-identical answers; the `associative` marker trait is rejected, the members migrating to @std. A worker owns whole fibers (ownership transferring at spawn and back at join, keeping non-atomic RC sound), immutable code shared as a per-drive version-table snapshot, the world surface refused on workers; a pooled drive's children read foreign immutable `Ref` entry words without touching counts, the join adopting on the host with one inc per surviving reference (2026-11-15). Pooled legality (2026-11-17): the refusal is permanent language legality, independent of every runtime flag (`Vm::enable_fork_pool` included) — the child contract is deterministic data parallelism, no sibling-fiber control, no world touch. The pooled gate is dynamic: only `par_map` frames whose children hold exclusively scalar entry words go to workers; the pool a host opt-in. Queued M-tier behind 0.1. Sequencing (2026-11-21): the fork-join residuals (immutable-borrow admission, ClaimWindow chunking, the `par_reduce` associativity story) land as contract-completing rounds; pool performance investment waits on tier 2 — pooling multiplies the interpreter penalty, so the JIT tier outranks pool widening for numeric users. Surface (2026-11-27): `par_map`/`par_reduce` retire from the user surface until the pooled admission round lands, the names returning with it. Foreign calls (2026-11-27): a foreign call inside a pooled child stays refused.

### E4 — union errors with `?`, `.err`/`.ok`, extraction family; `or` retired 2026-11-10

Expected failures are union members handled by tokens and methods stated once over unions: `?` (propagation with checked containment), `.err(h)`/`.ok(h)` (difference-typed handlers whose remainder type shows what is left), and the @std extraction family `unwrap_or(y)`, `unwrap_or_else(fn)`, `ok_or(e)`, `map_err(fn)`. Bugs `panic` unhandleably: the fiber aborts, linear deinits run, let-it-crash supervision a library pattern. Ruling (2026-11-25): the application boundary's catch-all is an @std open error box — one tag over a boxed payload and a message — entered by an explicit conversion spelling, `?`'s checked containment unchanged (no implicit widening valve opens). The exported-alias idiom is the sanctioned API-boundary convention: a library exports one alias (`pub type http_err = ...`) as its whole error surface, callers write their own wider unions around it, and `?` containment absorbs the alias's growth — an exhaustive `match` the only caller surface a new member breaks, the same blast radius an enum variant carries anywhere. The tutorial records the idiom. Box landing (2026-11-26, item 144): the box lands as the @std error-box face (std/error.ds, riding as the bundle's own member and composing last in both ambient readings) — `any_err` the payload set over the taxonomy's own aliases (the open half: the set grows and every box site follows), `box_err { payload: any_err, msg: string }` the one tag, and `box_err.of(e, msg)` the explicit conversion riding the box type's own static tier (the `u32.of` spelling), `?`'s containment check byte-identical (DS2008 refusing the unchecked propagation, the e2e pinning the three concrete members entering through `map_err`, the box routing through `?`, and the payload field read and member arms extracting); the linked reading waits on the payloaded-tag layout fact: `TypeFact` mints unit atoms alone, so over a std-declaring graph the box's payloaded tag and the `any_err` alias chain over the payloaded floor tags refuse the linked selection (DS4021) — the inherent-member seam landed (item 58, 2026-11-26), so the entering call rides it once the type crosses.

### E5 — nursery-scoped cooperative cancellation; consume-to-close

Cancellation is nursery-scoped and cooperative, observed only at await/preemption points (backward branches plus parked-child re-entry), so a linear consume is never interrupted mid-flight; teardown walks frames running deinits, resources close by consumption. `defer` is non-normative scope-exit sugar; timeouts, `firstof` and `interleave` are library combinators over the timer capability. Release door (2026-11-18): an open nursery dies with its dead owner — the trapped-drive release tears down every open nursery whose owner fiber is dead, releasing live children cold; the first-entry-lands rule governs live teardown drives alone. Timer ruling (2026-11-21): the time face gains a monotonic clock and a parking sleep op, so the promised combinators land as ordinary @std library code. Timer landing (2026-11-22): `time()` the wall clock, `mono()` monotonic nanoseconds since a process-fixed origin, `sleep(nanos)` parking the caller (a negative span answers at once; no-reactor hosts keep the blocking twin); the combinators queue behind the bounded channel (first-answer-wins needs its parking receive). Combinator round (2026-11-22): `firstof`/`interleave` cannot compose into the ambient — the dsmod splice byte-pins only the plan-time prefix while `spawn` mints a lowering-time child record — and `timeout` cannot spell its deadline union from a generic body, its name colliding with the net_err tag; all three queue at item 74 behind author-ruled seam rounds. Combinator landing (2026-11-23): the plan-time mint seam (G3.5) unblocks the composition; `firstof`/`interleave` land as @std bodied members (non-capturing scalar thunks racing into a bounded answers channel, answers in arrival order — `firstof` the first arrival, `interleave` the arrival-order collection); the empty race answers the stall guard's honest deadlock since the 2026-11-24 rendezvous landing (previously the zero-bound refusal), a wider-than-one-word answer refusing at the one-word instantiation. `timeout` stays queued on the union-over-variable and reflection seams. Timeout landing (2026-11-26, F9.5 phase 3 over the recorded CALL interception seam): `timeout(nanos, thunk)` is a native-backed CALL-only seam (a bare tail call to the race refusing, DS4009 — the CALLT transfer leaves no position for the two-word re-span) answering `t | timed_out` over the classed fallible native span, the deadline the io taxonomy's own `timed_out` member so `?`/`.err`/`match` extract it and the program exits 0 — the fatal `Trap::TimedOut` arm never existed outside the worktree; a past deadline answers at once with no racer spawned; a live deadline opens a private race nursery (the racer fiber raced against the deadline wheel, the winner's one answer word re-spanned into the call's union, the losing racer cut at its park or the teardown drain with its kept deinits firing, its own `cancel` kept as the NurseryCancelled member riding the enclosing block boundary); a wider-than-one-word answer refuses at the call's lowering (DS4009, riding item 140) and the comptime fence refuses the call (the builtin table truncated at the race row); a never-parking looping racer was the shutdown guard's own limit (the wheel fires only when no fiber is runnable). Fuel-quanta ruling (2026-11-26, item 153): the dispatch charges every taken backward branch a deadline countdown — one decrement, and at zero a poll of the running fiber's own race, the quanta N = 16384 chosen so the amortized poll cost (an Option check, the clock read only where a race stands, one read per 16384 edges) is noise while one quanta of tight-loop edges bounds the cut latency at tens of microseconds; a due deadline raises the race's own expired flag plus the nursery cancel flag, so the racer dies the ordinary cancel death at that same edge and the parked owner takes `timed_out` through the racer-death resolution unchanged — a never-parking racer answers the deadline deterministically. ## 6. Syntax surface and sugar budget

### F2 — bindings, functions, annotations, returns

Boundary: a closure word never widens into a var span, never gets lambda-captured, never enters a collection element or field without proven scalar provenance. ### F3 — full UFCS

### F4 — Rust-shaped pattern matching

### H3 — one generic body, evidence words, inline caches, lazy JIT specialization

## 9. Runtime

### Fixed baseline (BL-1..BL-7, binding on every tier)

- **BL-1 Typed register bytecode.** 32-bit fixed-format instructions with register-index operands and typed opcodes, no dynamic variants since every operand's type is a compile-time fact; biased jump offsets and XOR-negated comparison pairs.
- **BL-2 Unboxed slots.** No NaN-boxing, no per-slot tags, no boxed scalars: scalars raw in frame slots, references raw pointers, ADTs/unions unboxed tag+payload pairs.
- **BL-3 Dispatch.** Computed goto or C tail-call threading, a build-portability choice.
- **BL-4 Superinstructions on profile data.** The assembler composes fusions from measured opcode frequencies.
- **BL-5 Uop decomposition from day one.** The instruction set is micro-ops with explicit slot effects and `pure` annotations, so the copy-and-patch stencils are these uops one-to-one.
- **BL-6 Frames inline in a typed value stack.** A contiguous span of statically-typed slots plus a metadata word per frame, so TCO is a pointer shuffle.
- **BL-7 Position-independent, mmap-able dsmod.** Fixed-width, index-based, relocation-free bytecode with a module header and an IR-version checksum, contracted in G3.5.

### H1 — three tiers over one shared lowering

Tier 1: typed register VM, computed-goto uop loop, unboxed frames, target 3-10x of C. Tier 2: copy-and-patch stencils, one fragment per uop emitted at build time, ~14% faster than LLVM -O0 at ~100x its compile speed, target 1.5-3x. Tier 3: bytecode -> typed SSA -> Cranelift CLIF, or wasm 3.0 (`return_call` carries TCO), target 1-2x native. One uop set and one bytecode-to-SSA lowering shared by all tiers, built early. No guards exist on any data path — only debugger breakpoints, the per-entry stack-limit compare, effect-handler entry and B7's cold overflow edge — so no deopt cliffs, hidden classes, type guards, deopt frames or side traces. Short scripts (<0.2s) never pay tiering; platforms without verified stencil builds ship tier-1 only. Fallback H1b: a single method-JIT tier if the per-arch stencil toolchain proves unacceptable. The span-answer seam's whole-interpreter cost stays accepted and baked in `PINS` (a one-word `Died` payload plus a `DiedSpan` side slot was refused); the seam reopens only behind the JIT specialization tier's own dispatch.

### H2 — guaranteed TCO from day one, self and mutual

Frame reuse plus argument slide in tier 1, label loops and slot-overlay `jmp` in JIT tiers, `return_call` on wasm. This ABI and BL-7 lock before anything else. Guarantee closure (2026-11-12): no callee-class exception — the tag-dispatched tail call transfers through the same slide, the tag-keyed inline cache keying it identically; a count-free closure callee word transfers through the plain tail call by maybe-Ref tracking. Cross-module (2026-11-20): a tail call into a linked package's function transfers through the same CALLT slide, the module boundary riding the pool FuncRef alone; the local shapes keep their rules across it (a closure word staged into a callable-defaulted parameter keeps the in-place tail, a deinit-carrying argument into a non-consuming parameter keeping the refusal). Queue-closure rulings (2026-11-12): destructured `const` binders alias the source `var`'s words, so reassignment through the var is observable through them; native fn values never mint a callable word in 1.0; the future fetch native answers both ambient `net_err` cases by error class.

### H4 — Perceus RC + reuse + per-frame arenas, collector interface as growth path

Precise non-atomic RC with reuse threading for boxed/shared values, over per-frame bump arenas for non-escaping temporaries: zero pauses, no barriers, no safepoints or GC maps in any tier, deterministic frees feeding deterministic deinits, per-fiber arena marks making fiber switching free. All non-moved temporaries are register/arena-resident; the boxed/shared residue keeps paying RC; the reuse pass is budgeted as optimizer work. The two-hook collector interface (cycle candidates, weak refs) is committed as the growth path.

## 10. Staging (v0 -> 1.0)

Ordered; each step lands on the previous one with no language-change rewrites.

Sequencing ruling (2026-11-27): the language surface expands to real usability first, then the JIT tiers, then ecosystem; surface rounds do not wait on the JIT.

1. Lock the two load-bearing contracts: the slot-overlay call ABI (H2) and the fixed-width mmap-able dsmod format (BL-7, G3.5).
2. Checker core: the B1 set algebra, B2 bidirectional checking plus refinement, B3 products/sums, B4, B7, B8, B9, and the affine checker plus DI (C1, C5).
3. Tier-1 interpreter: uop loop, unboxed slots, tag+payload ADTs, frame-reuse TCO.
4. Memory: Perceus dup/drop placement, reuse threading, per-frame arenas; `rc==1` checks and the borrow counter as the diagnostic layer.
5. Concurrency: fibers, nursery, `cancel`/`discontinue` evidence dispatch, fork-join combinators.
6. Derives; then the comptime evaluator and reflection API (before 1.0).
7. Tooling commitments from day one, sequenced with the query compiler they consume.
8. Tier 2 copy-and-patch (x86-64, then aarch64; tier-1-only elsewhere), bytecode-to-SSA lowering early, tier 3 on demand.
9. Deferred-additive backlog after the core is stable (the backlog and recorded fallbacks below); borrow inference, TRMC and fusion upgrades land as pure optimization.

## 11. Deferred-additive backlog and recorded fallbacks

Deferred additive (in headroom order of likelihood): `|>`, anonymous record literals (the map literal rides this reservation per B3), `@` binders, `??` on `t | none` (B4, F8); then `?.` desugar, `throws(...)` sugar, user-defined handlers, labeled break/continue, `it` shorthand — the named instances landed (item 147, the B6 escape). Retired: vararg/spread (F8); `or` (E4, F8); bare `return` adopted 2026-11-10 (F2). Pure-optimization items: borrow inference, full reuse pairing, TRMC, fusion upgrades, `T | none` niche packing, rope. Recorded fallbacks (triaged 2026-11-17): B1b nominal-core and F1b brace headlines retired, both triggers unreachable (B6, the M1 parser); H1b single method-JIT tier stays until the x86-64 stencil build lands (M8); C4b generational references stays with its quantified trigger (C4); inferred error members on non-`pub` functions (B2, 2026-11-25) stays behind its own quantified trigger the same way.
