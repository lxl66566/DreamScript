## 0. Author supplements — binding

1. The main direction follows the Phase 3 record and its rationale.
2. Casing carries no grammatical meaning; types are spelled lowercase.

## 1. The decided language

Set-theoretic types over nominal tags with boundary signatures and flow refinement; affine values with an opt-in linear layer; Perceus RC with block reuse and no GC; coherent traits over one generic body; comptime reflection without macros; errors as union members; VM fibers in mandatory nurseries with fork-join parallelism; an evidence-passing handler runtime with capability IO; three tiers with guaranteed TCO.

## 2. Identity and compatibility

- **A1 — standalone core, embedding via platform packages.** The standalone runtime is the only architecture; embedding arrives as ordinary packages exporting effect handlers over it, the default platform being the `ds` CLI.
- **A2 — workloads.** CLI/tools/scripts primary, games/simulation secondary (interpreter-first startup, script mode, two-slot hot reload); numeric/AI reaches the Cranelift tier without shaping v1.
- **A3 — compatibility.** Rapid-break until 1.0, semver after; content addressing applies at package level (H6), never to source identity.

## 3. Type system

### B1 — hybrid set-theoretic types over nominal tags

Nominal declarations carry identity; unions, intersections and differences of nominal atoms are ordinary type expressions. Exhaustiveness checks by tag identity, differences erase at compile time, a union is its unboxed tag+payload layout, an intersection keeps the most precise member's layout, and inference failure is a compile error with no `any` fallback. Fallback B1b: a nominal-only core if the disjointness checker slips schedule.

### B2 — bidirectional checking with boundary signatures, plus flow refinement

Boundary signatures are required at top level and on public items; locals, lambdas and arms infer bidirectionally. Refinement narrows through `is`/none tests and arms, reset at assignment; `?` is containment in the written union. Limit: no narrowing through mutable union fields. Rulings: a value-level arm subtracts nothing (2026-11-12), so later arms check the full scrutinee — sound, since a superset-checked branch may be dead, never wrong — rejecting arm ordering; per-element refinement is out (2026-11-15) because singleton subtraction reintroduces arm-order dependence and partial subtraction is a confusing half-feature.

### B3 — nominal structs/enums plus anonymous tuples

Named data is nominal structs and enums (declared layouts, tuple-enums, punning); ad-hoc aggregates are anonymous tuples with destructuring. Enum blocks are the only payload-case form, `tag x;` declares unit tags, type aliases never declaring cases (2026-11-10). Construction is fixed per declaration, a cross-spelling being a checker error. v1 has the list literal; map and anonymous record literals stay deferred additive; row types rejected.

### B4 — `T?` is exactly `T | none`

Optionals, error unions and enums share one mechanism (`is`, match, `?` with E4's extraction family), `none` being a unit type among several. No `?.` in v1; `??` on `t | none` is the single recorded operator valve and is rejected by default — the M9 backlog triage may reopen it only on corpus evidence that `t | none` fallback dominates (ruled 2026-11-17; F8). Limit: `V | none` where `V` may itself be `none` is ambiguous, so wrap explicitly.

### B7 — numerics: i64/f64 defaults, trapping overflow

`int` is i64, `float` f64, raw in unboxed slots; conversions are always explicit calls. Integer overflow, `1 / 0` and `int_min / -1` trap; `+%`/`-%`/`*%`/`-%a` wrap for hash and PRNG use; floats follow IEEE and never trap; error-union arithmetic variants are library functions; `Dec` and units-of-measure are nominal library types plus derives. Ruling (2026-11-15): a shift amount outside `0..64` traps, `>>` is sign-propagating, `&`/`^`/`|` never trap. Width construction ruling (2026-11-19): the u32 trapping conversion is an ambient library member over the checked `u32_of` and the bare `trap` primitive, `u32_of` staying the fallible form. Landing note (2026-11-19, awaiting the author's confirmation): the ruled bare `u32(x)` spelling is unlandable with the compiler untouched — the call form resolves the `u32` type atom (DS2002), and an ambient value named `u32` makes every call form DS2014-ambiguous (F9's namespace priority) — so the member rides the width's own static tier as `u32.of(x)` (the `int.default()` precedent); whether the bare spelling warrants a checker round amending F9's priority is the open question.

### B8 — strings: immutable UTF-8, checked slices

Immutable UTF-8 bytes behind one raw pointer plus byte length. Slices are non-owning borrows kept alive by the parent's RC and land on char boundaries through a checked API returning `string | none`; equality is O(n) with length fast-reject. Ruling (2026-11-12): string-operand `+` spells the concat native, `+=` the same operation, mixed operands refusing at both layers. Known seam pinned red in the ds-lower string_add suite: a native borrow staged as a word dies before the call reads it. Surface cleanup (2026-11-17): `substring` and `char_at` answer the checked forms — `string | none` and `char | none` — and the clamping totals retire; `head` retires, `first` being the one list-front spelling.

### B9 — universal structural `==` with five carve-outs

One structural `==` over all data, total by construction, never user-overloadable. Carve-outs: function comparison rejected statically; floats compare bit-structurally (`nan == nan` true) with named `is_float_eq`/`is_approx_eq`; mutable cells and `~Copyable` resources compare by identity; operands are borrowed; `hash` stays consistent. `Ord`/`hash`/`show` are derives, ordering never structural. Ruling (2026-11-14): `fn hash(self) -> int` over a borrowed receiver with ambient primitive impls, float normalizing `-0.0` and every NaN payload so bit-structurally equal floats hash equal, the derive folding one seed through per-part dispatch.

## 4. Linearity, ownership, memory, data

### C1 — affine core, opt-in `~Copyable` linear layer

Assigning an affine value moves it, and a moved binding is dead. `~Copyable` subtracts the default copyability constraint, carries `deinit` and admits phantom-state unions; affine checking is an intraprocedural last-use/DI pass. Staging with no language change: `rc==1` uniqueness checks plus a borrow counter ship as the diagnostic layer, inference and reuse upgrades following as pure optimization. Ruled 2026-11-17: this model is the ownership endgame — no lifetime-annotation or GC escape hatch is reserved.

### C2 — second-class parameter-passing modes

Three modes fixed at the definition site — default borrow, `mut` (exclusive), consume — with no mode syntax at call sites. Borrows never escape a call, so checking is intraprocedural and no lifetime annotations exist; first-class references are permanently out. Subscripts extend the modes to element access.

### C3 — `const`/`var` bindings, mutation through `mut` windows

`var` is a rebindable local; callee-side mutation goes through `mut` parameter windows — one mechanism serving parameters, windows and confinement (D1) — with zero runtime checks inside (alias-freeness proven).

### C4 — Perceus precise RC + block reuse over per-frame bump arenas

Precise non-atomic RC (bump per clone, dec per unique death, each drop a reuse candidate) over per-frame bump arenas holding non-escaping temporaries, sound because linearity makes escape a compile-time fact. Ruling (2026-11-12): every count mutation runs through the owning heap's count funnels, a foreign heap only posting requests drained to quiescence. Clone-family amendment (2026-11-15): `fn clone(self) -> Self` over a borrowed receiver, the derive constructing from one dispatch per part so the duplicate is shallow (a Ref dups by a count bump), the family adding no uop and no native. Unit-word ruling (2026-11-15): a part-less struct occupies one reserved word in every value position — never read — so the one-word minimum holds and the empty-return-span refusal retires.

### C5 — `deinit` restricted to `~Copyable` types

`deinit` runs exactly once at the unique instance's death on every path, including early return, panic and cancellation teardown, and dispatches statically. `drop` is a debug/FFI tool only.

### D1 — exclusion-window mutation is the only channel

Mutation is always a named call on an owned receiver with a `mut` mode: statically exclusive, lexically visible as the call, zero runtime checks; shared mutation is unrepresentable by construction.

### D2 — linear-mutable COW collections

Collections expose a functional API and mutate in place iff uniquely owned (guaranteed, observable reuse); aliasing means copying, a perf note and never an error. Ruling (2026-11-10): a `mut` window parameter takes a `var` binding at the call site whenever its argument copies, a `const`-binding receiver being DS3006; COW-on-alias is rejected because the hidden copy keeps mutation invisible at the call site and withdraws guaranteed in-place reuse.

### D3 — combinators over a hidden linear cursor

The user surface is combinators (`map`/`filter`/`reduce`) plus `for`, the hidden protocol a linear cursor fused into loops by the compiler; no public generator syntax in 1.0.

## 5. Errors, effects, async, parallelism

### B5 — errors are union members of return types

Errors are storable data, one predicted branch in the VM, carrying an effect row's information; a `throws(...)` spelling stays later sugar. Propagation requires the enclosing return union to contain the member (checked containment, no implicit conversions).

### E1 — no effect syntax in v1; handler-shaped runtime, capability idiom

The runtime is handler-shaped from day one: evidence passing serves `cancel` and `discontinue` at nursery boundaries, tail-resumptive with zero allocation. World-touching stdlib APIs follow the capability idiom — an ambient handler installed by the `ds` CLI, an explicit capability parameter for tests, embedding and scheduler choice. User-defined handlers stay a v2 additive escape hatch with a recorded adoption trigger (ruled 2026-11-17): the valve opens only on a real use case a capability parameter cannot cover cleanly (test injection or mid-tree policy switch the predicted shapes), resumptions affine with the marked multi-shot valve closed — a resumed continuation captures its linear values, so multi-shot resumption breaks affine discipline — and FFI calls pinning the fiber (H5).

### E2 — VM fibers with a mandatory nursery

Stackful heap fibers on the VM pool. `spawn` exists only inside `nursery` blocks; scope exit joins children, first failure cancels siblings, child errors union out at the boundary. Blocking-style code, no colors, no `await`; preemption is a flag check on backward jumps; bare detach requires an explicit root nursery. Amendments (2026-11-12): re-entry of a parked child by the join/teardown driver is preemption-shaped, so a parked child of a cancelled nursery dies with the cancel sentinel to its resumer; a payloaded cancel rides the native channel's flat span. Lowering refuses bare `spawn` outside a nursery, a member outside the enclosing return union, and a payloaded member whose payload is a union or non-heap application.

### E3 — fork-join parallelism on the sendability substrate

Race-freedom and sendability are static consequences of linear/immutable data: `par_map`/`par_reduce` over immutable or partitioned inputs are deterministic, replayable and lock-free by theorem, RC counts thread-confined through the fork-side transfer. Amendment (2026-11-13): the join parks the call site through the interlock drive, so nested calls run correct at any depth while a fork at a tail dispatch site refuses with a structured trap. par_reduce ruling (2026-11-15): the fold stays sequential because byte-identical answers are the combinator contract and a parallel fold reorders float sums, an `associative` marker trait spending the budget on an unproven demand. Form ruling (2026-11-15): the two are library members, not compiler-special-cased natives, migrating to @std over the spawn/join seams.

Per-fiber state sendability amendment (2026-11-15): a worker owns whole fibers and never shares them — the parent transfers ownership of the child fiber at spawn and receives it back at join, an ownership transfer only, which keeps precise non-atomic RC sound; the immutable code is shared instead as a per-drive `Send + Sync` snapshot of the version table. Inline caches and hook directories become per-worker while the fiber pool, nurseries and interlock stack stay host-side. The world surface is refused on workers this round (the snapshot strips the platform tables) until the checker's effect attribution refuses such bodies statically. Pooled-legality ruling (2026-11-17): the refusal is language legality, permanent and independent of every runtime flag (`Vm::enable_fork_pool` included) — the `par_*` child contract is deterministic data parallelism, no sibling-fiber control and no world touch inside the child, the sequential drive never a second semantics; IO concurrency is nursery + spawn's domain, and an effect-attributed world-tolerant combinator may later join @std as a separate contract. The pooled gate is dynamic: only `par_map` frames whose children hold exclusively scalar entry words go to workers, so both combinators keep the sequential interlock as their drive, the pool a host opt-in. Measured record (2026-11-15): heavy bodies ~27.0 ms sequential against ~2.56 ms pooled over 64 elements (~10.5x), trivial bodies ~76 us against ~236 us — the ownership transfer costing ~3.7 us per child, so the pool pays only past that bar.

Immutable foreign-word borrow amendment (2026-11-15): a pooled drive freezes the parent heap, so a child whose entry span carries foreign immutable `Ref` words reads them without touching counts, the join adopting on the host with one inc per surviving reference in a walk over the fresh answer graph alone. Queued M-tier behind 0.1.

### E4 — union errors with `?`, `.err`/`.ok`, extraction family; `or` retired 2026-11-10

Expected failures are union members handled by tokens and methods stated once over unions: `?` (propagation with checked containment), `.err(h)`/`.ok(h)` (difference-typed handlers whose remainder type shows what is left), and the @std extraction family `unwrap_or(y)`, `unwrap_or_else(fn)`, `ok_or(e)`, `map_err(fn)`. `or` is retired (2026-11-10) for overloading one word across fallback, early exit, loop control and coalescing under wanted-member inference (F8). Bugs `panic` unhandleably: the fiber aborts, linear deinits run, let-it-crash supervision being a library pattern.

### E5 — nursery-scoped cooperative cancellation; consume-to-close

Cancellation is nursery-scoped and cooperative, observed only at await/preemption points (taken backward branches, plus the parked-child re-entry), so a linear consume is never interrupted mid-flight; teardown walks frames running deinits. Resources close by consumption. `defer` is non-normative scope-exit sugar running at teardown under cancellation; timeouts, `firstof` and `interleave` are library combinators over the timer capability. Release-door amendment (2026-11-18): an open nursery dies with its dead owner — the owner link is set at open, and the trapped-drive release tears down every open nursery whose owner fiber is dead, releasing live children cold (deinit hooks through the owning frames' version rows, claims drained, staged words dying with the segment, the retiring-frame semantics) without ever entering one, so a never-entered child's staged callable words stop gating swaps once released; the first-entry-lands rule governs live teardown drives alone, never a release door. Rollback-door amendment (2026-11-18): a trapping REPL line's root survives its own rollback, so the rollback reads the pre-step nursery pool itself (beside the ledger reading) and tears down every root-owned open nursery the line opened the same way — never-entered children release cold, the nursery slot recycles, and the host-supervised root nursery stays untouched.

## 6. Syntax surface and sugar budget

### F1 — TS-family braces

Every block opens with a visible token; line-oriented grammar with no layout state; newline-terminated statements without semicolons; trailing commas; `if` and `match` are expressions. Fallback F1b: Gleam/Roc-style brace headlines if the arrow-assignment grammar fights the parser.

### F2 — bindings, functions, annotations, returns

`const`/`var` bindings, `var` the rebindable local. `fn name(p) -> t { }` is the only named-function declaration — top level, trait/impl members, bodiless in traits — with the name in scope in its own body; const-arrow is only the anonymous lambda form. Parameters `name: t`, returns `-> t`, union returns, `T?` anywhere; final-expression returns, early exits via bare `return` (2026-11-10), `break`/`continue`, `?` postfix only. Callable-word ruling (2026-11-10): a fn-typed value is a one-word slot classification, never boxed — a non-capturing function a copyable scalar `FuncRef`, a capturing lambda a heap closure holding its capture block — captures under the ordinary binding rules, no mutable upvalue channel in v1. Callable-defaulting amendment (2026-11-11): a fn-typed parameter keeps the classification while the arriving word may be a `FuncRef` or a closure Ref, resolved by runtime kind, staging a borrow window (C2) so the callee never owns the count. Boundary: a closure word never widens into a var span, is never lambda-captured, and never enters a collection element or field without proven scalar provenance.

### F3 — full UFCS

`x.f(a)` desugars to `f(x, a)` for any first-argument function, at zero runtime cost and with no candidate search. Resolution is free functions first, then trait methods, `Trait::f(x)` the escape hatch and true ambiguity a compile error. Capability parameters are excluded from the dot position. `|>` is deferred additive.

### F4 — Rust-shaped pattern matching

Arms `pat => expr`, guards `pat if cond`, or-patterns `a | b`, destructuring, `_`, and exhaustive matching with set-difference diagnostics naming the missing members; `@` binders excluded from v1. Struct patterns (2026-11-12) test each literal field in place over a non-union scrutinee and compose into the or vocabulary and under guards. Tag-dispatch tests (2026-11-12): a member arm may carry value-level tests over its own payload, a failed test sliding to the next arm's dispatch entry (B2's tag-dispatch form), so a tested arm needs a later no-test arm or catchall. Nested struct sub-patterns (2026-11-12) compose at any depth, nested tuple and member sub-patterns staying refused. Guards (2026-11-12) run after the member tests; a guard must not take a count the base state holds, a can-fail arm needs a later settling arm or catchall, a guarded catchall refuses, and the first catchall wins.

### F5 — fixed trait-driven operator set, frozen precedence

A fixed token set maps to fixed traits (Add, Sub, Mul, ..., Index), so an operator call is an inline-cacheable trait-method call. One frozen C-family precedence table is published once in the tutorial and never extended; no user-defined operators; the word forms are exactly `in` and `is`; boolean contexts are bool-typed; `Deref` coercions excluded. `==` is B9's, ordering from the `Ord` derive, trap/wrap behavior B7's.

### F6 — strings and literals

Interpolation `$x` (bare identifier) and `${expr}`, the hole an explicit string context legal for a primitive or a `show` carrier, a union or optional operand being an error (extract first per B4/E4); every other position stays strictly explicit. Escape set (2026-11-10): `\n \t \r \\ \" \' \0 \u{...}`; raw strings and hash-counted raw strings nest to any depth and carry no escapes. `'x'` is a Unicode scalar char, `b'x'` a byte; `byte` is its own atom outside the int conversion family, declared by the stdlib ambient (2026-11-10). The byte sequence's collection atom `bytes` (2026-11-17): one immutable byte string per value behind one Ref word — the string face's shape over raw bytes, a counted block never a produced arena temporary — constructed through `bytes_of(list[byte])`, bridging back through `byte_list`, measured by `len` (the `Bytes` evidence instance), and read through the checked `byte_at` answering `byte | none` (B8's convention); `read_raw`/`read_exact` answer `bytes | io_err`, and the file face keeps no `list[byte]` success member. Bytes representation ruling (2026-11-18): `show` renders the payload as a byte list (`bytes[1, 2, 255]`, empty printing `bytes[]`); `ord` orders and `hash` hashes over the payload lexicographically, a shorter prefix ordering first; the string<->bytes bridge faces decode through a dedicated `utf8_err` tag (decode answering `string | utf8_err`, never reusing `parse_err`, which names document shape failures alone), the encode face taking the string's own bytes and the decode face validating UTF-8 on the way back.

### F7 — sugar budget: Balanced tier (22 features / 34 units)

Against Kotlin's 38 features / 74-76 cost-unit ceiling, with 16 features / 40-42 units reserved as headroom. Included rows at S1: newline-terminated statements, interpolation, raw strings, list literals (adopted 2026-11-10), match guards, or-patterns, type aliases, ranges plus `in`, numeric suffixes plus separators, the `const`/`var` split; at S2: postfix `?`, `is` narrowing, `.err(h)`/`.ok(h)`, match/if expressions with exhaustive-union diagnostics, destructuring, named plus literal-only defaults, trailing lambda, UFCS, sum-type declaration, derive attribute, operator-overload traits, `T?` alias. Kotlin features deleted wholesale by set typing and UFCS; excluded permanently: custom operators, Deref coercions, convention-based privacy, truthiness coercion, chained comparisons, comprehension syntax, subscript slicing, vararg/spread packing (F8).

### F8 — extraction methods, no prose operators or implicit coercions (2026-11-10)

`or` is retired (2026-11-10): it carried six behaviors — option and error-union fallback, early exit, fallback onto a diverging callee, union coalescing, loop control — under contextual wanted-member inference and collided with boolean `||`. Replacements use existing tokens plus one @std family: `unwrap_or`, `unwrap_or_else`, `ok_or(e)?`, `map_err(fn)?`, `err(h)`, `match` with a catchall, `if x is none { break }`; bare `return` enters with the retirement, `??` on `t | none` being the single recorded deferred additive, rejected by default since 2026-11-17 with the M9 corpus triage as its only reopening gate — no English word ever re-enters the operator set. Prose-syntax audit, binding at review: C-family symbols with `in` and `is` the only word forms; boolean contexts bool-typed; chained comparisons, comprehension syntax, subscript slicing and vararg/spread packing excluded permanently (D3 covers comprehension, B8 owns string slices); mutable defaults impossible because defaults are literal-only, mixed numeric arithmetic an error naming the conversion (B7). Ruling (2026-11-10): `in` is range-wired in v1, the checker refusing a non-range right side and collection membership is permanently a @std method call (`xs.contains(x)`), ruled 2026-11-17: one word one meaning, the cost model visible at the call site. Guard-tail quirk (2026-11-12): a guard ending in a bare identifier before `=>` reads as a bare-parameter lambda, so it needs parentheses.

### F9 — two namespaces: types and values (2026-11-10)

Constructors (brace construction, bare tags, generic application) resolve in the type namespace and functions in the value namespace, a call-form name present in both being an ambiguity error. The `map` struct and `map` function coexist; an enum case colliding with a function is the residual error class.

### 6.1 Implementation-normalized surface spellings (corpus-adopted; to be locked at M2)

Surface spellings where the record under-specifies the corpus surface, locked or revised at M2: trait receivers `self` (borrow) or `mut self` (window, C2), `#[derive(...)]` attributes, `struct stack[t]`, `list[page]()`. Receiverless-member ruling (2026-11-15): an impl member may omit the receiver, callable as `mytype.make()` — a type-keyed static entry resolved at check time with no instance or evidence words — while trait members keep the receiver requirement; a dot-receiver bare name names that type's own impl members, a tag or case name naming no member of its own type keeping its constructor reading, any other type naming no member reporting the missing-member diagnostic. Instantiated-receiver amendment (2026-11-17): the type-keyed entry accepts an applied receiver — `list[int].make()` — spelled where the expression grammar reaches (the one-argument bracket, the two-argument `map` bracket) or carried by the fn-type node (the synthesized spelling for applications the brackets cannot express, the `default` derive's own); the applied type solves as the call's `Self`, a generic impl's head pattern binds its variables from the application so the member's written signature reads through the site's substitution, and a bounded body's evidence stages at the call like a value-receiver entry — the bare name keeps refusing a generic impl's members, the spelling carrying no type arguments. Union-default annotation (ruled 2026-11-15 after Rust's `#[default]`, landed the same round): `#[default]` on one enum case names the member the family synthesizes the union's default over — the annotated enum's own `default` answering it, a defaulting field typing the union answering the same construction with the enum deriving nothing, a foreign union answering through its own member; no annotation keeping the ambiguity refusal, a second annotation refusing as a duplicate.

Parser rulings: block bodies, match arms and fields newline-separated with trailing commas; `mut self` shorthand with `move` and `comptime` contextual keywords; top-level `fn` the only named declaration; `none`, `self` and `Self` not reserved; named arguments after positional ones with literal-only defaults.

Comptime fence rulings (2026-11-15, the pure-fn admission landing 2026-11-16): the world guarantee is structural — a world call the rows cannot attribute refuses at the slice's install in the fenced registry. Admission is by the callee's own solved effect row: a pure row admits, any impure row refusing at the fence naming the comptime fn, the callee and the call, the rows being the effects pass's solved fixpoint. Fence-predicate amendment (2026-11-17): a row of `trap` alone admits — trap is deterministic and never the fence's business, a trap the evaluator hits reporting as the comptime call's own compile error — so the unsolved-type over-approximation fences nothing (string concat included) while world rows keep refusing. The admitted subgraph lowers into the slice beside the comptime fns, a deinit-carrying construction refusing because the slice plans no deinit hooks. Honest residuals: the rows stay an over-approximation (the effects pass rows every trapping operator as `trap` without solved operand types, B7), which the trap-only admission absorbs so it fences nothing; a generic callee refuses at the fence (the one-body evidence seam being the runtime module's); a member call inside an admitted body refuses (no impl bodies in the slice).

## 7. Polymorphism and metaprogramming

Trait-member default authority (2026-11-12): the trait declaration is the single authority for a defaulted member parameter, so an impl re-declaring one is a checker error and a dispatch call stages the trait's default; an impl-only default refuses because the registered signature carries none.

### B6 — coherent set-theoretic traits with pairwise-disjoint instance heads

Traits may carry associated types; instances are declared for type heads; the only coherence rule is pairwise disjointness of heads of one trait — for every pair prove `H1 & H2 = Empty` (decidable set emptiness), checked at declaration and again over the final instance environment at link time. Any module may define an instance for any type, foreign included: no orphan rule, no newtype wrappers. Resolution is intersection subtyping via modus ponens with no priority machinery, an overlap error naming both heads and a witness type. Instantiation (landed 2026-11-12): a declaration probes whether some grounding of either head is served by both and rejects with that instantiation as witness, a pair no probe could prove falling to the closure pass over the final environment, and a conditional instance requiring itself being rejected as a structural cycle. Union heads decompose into per-branch instances; scoped named instances stay deferred additive. Call-site resolution (landed 2026-11-11): a query unifies against a generic head with each receiver member covered under its own substitution and each bound proven recursively; several serving impls are true ambiguity, a failed bound being diagnosed as the unsatisfied bound. An impl member must agree with its trait member's registered signature, that signature being the call-site contract, and a trait member with no default body must arrive with a bodied impl member.

Union-receiver amendment (2026-11-14): a member's `Self` binds to the solved instance's written head when that head is closed and contains the refined receiver, while a generic head keeps the receiver carrying the call's substitution. A union receiver no single instance serves is covered branch-wise by sibling instances of one written head: exactly one covering group serves the union, several staying true ambiguity, and uncovered members still refusing, so aggregation never hides a missing proof. The inline cache must key on the written head, never the branch id, and the synthesized compare evaluates every part eagerly, so member compare bodies are required pure. Per-branch condition solving (2026-11-14): each decomposed branch carries only the conditions naming variables its own head mentions, the impl's requirement set being the union over branches.

### G1 — comptime evaluation + static reflection, no macros

The meta-language is the language: comptime evaluation of ordinary code plus static type reflection; macros of every level are rejected, so hygiene is deleted structurally. Derive-extension ruling (2026-11-14): the attribute vocabulary stays closed to third parties, the builtin families remaining the checker-synthesized ruled set and unknown names refusing; the one sanctioned comptime seam is field traversal, `comptime fields(t: type)` answering field records over declared data, so libraries write ordinary comptime functions without code synthesis, hygiene surface or identifier minting.

Round-one landing rulings (2026-11-15): the `type` keyword solves to a builtin atom every universe declares beside `none`, a type name being a value of it exactly inside a comptime evaluation context. The world fence sits at the evaluator's install: the comptime slice runs in a registry whose platform serves the package's platform name with an empty provides list, so a world-touching call refuses at install as a compile error naming the capability, never a runtime trap. A call's answer embeds at the call site as the literal a user would have written (int, float, bool, string this round), comptime functions never reaching a runtime module. Field records: `name`, the field's `type` as a reflection index, and `tag`, its nominal type name when the type is a bare atom.

Round-two landing rulings (2026-11-15): enum case traversal answers through `fields` itself, one record per declared case in declaration order — `name` the case's name, `type` its payload (its own minted atom, traversable like any struct, or `none` exactly when the case constructs bare), `tag` the constructor tag its values carry, so tag and name agree. A comptime parameter's annotation admits `type` and the four scalar atoms (int, float, bool, string) as one staged literal each, holed or suffixed literals and omitted defaults refusing at the staging, every other annotation, mixed modes, generics and non-free-fn positions refusing. Staging and embed spellings, landed 2026-11-16: every answer embeds gated against the call's own checked type, so a scalar answer arriving through a wider return refuses at the embed naming the checked type.

### G2 — comptime-only reflection over tags-as-data

Reflection exists only at comptime; runtime type questions are answered by the tags data already carries (`is`, match), no type objects or metadata tables existing. Existentials remain the one justified boxing site (`box Json`) for heterogeneous collections and plugin boundaries, signatures defaulting to universals because existentials break affine reasoning.

### H3 — one generic body, evidence words, inline caches, lazy JIT specialization

Every generic function exists once in bytecode with its constraint list. A generic call site emits its callee plus evidence words, each a statically-resolved instance constant or a runtime-resolved tag-keyed slot patched as a small inline cache with a miss falling back to full lookup, so correctness never depends on cache state; evidence words are ordinary register arguments staged after the true arguments, so tail-position generic calls tail-call normally, the tag-dispatched tail form included (H2's 2026-11-12 ruling). The JIT tier lazily materializes per-type specializations keyed by the type vector, with no correctness role. Ruling (anti-specialization invariant, verbatim): "dispatch is determined by types and the set algebra, never by declaration order or priority; the runtime may cache and specialize any dispatch that is already unique." Variance follows set inclusion; no HKT and no GATs in 1.0. Free-generic-fn amendment (2026-11-13): a free generic fn's body binds one Raw word per own type variable and each call site stages demands for its declared bounds.

## 8. Modules, visibility, FFI, ecosystem

### G3 — definition < file < package < module; no import-time execution

Four layers: definitions (visibility and identity), files (namespace spelling), packages/directories (the compilation unit, one namespace per package with zero intra-package imports), and the module (`ds.pkg`: dependency and distribution unit). Intra-package cycles are legal (whole-package fixpoint resolution) while cross-package cycles are a link error suggesting a base package; generated `.dsi` files are the reviewable API surface. Module bodies are pure compile-time declarations with no import-time execution, which buys cycle tolerance, safe hot reload and lazy loading, script mode alone admitting top-level statements in the entry file (2026-11-10). The block separator is a line-initial `##` and `///` the doc-comment prefix. Doc attachment (2026-11-12): consecutive `///` lines immediately preceding a definition attach to it as parse-layer data, a run separated by a blank line staying loose trivia without diagnostic; a run preceding a member `fn`, a struct field or an enum-case field fills that member's doc slot.

**G3.5 — the dsmod bytecode contract (binding).** Fixed-width, position-independent, mmap-able module format whose header carries the dep list, source hash (checked-hash validation, never mtime), the module's own artifact checksum and strippable sections. Loading-round rulings (2026-11-15): the dep list is the link table — deps-first install walk with install-time content-hash validation — and the constants-pool `FuncRef` is dep-position-keyed. The module-id space holds installed module names only, deterministic in dep-walk order and never serialized. Link-resolution ruling (2026-11-15): the author keeps hot reload — A2's game workload stays — so dep content hashes validate at install while resolution reads the name's current slot, letting a hot swap compose with staged words; same-name multi-hash coexistence stays refused this round. Multi-package watch landing (2026-11-20, item 67): a dev-session manifest edit pinning new dep content moves the dep's identity through the per-name two-slot swap — the same semantics a root reload rides, the swap re-checks refusing over a moved name a live frame or staged word still targets, and the walk then validating the moved link against the swapped slot — so the moved identity retires the old version like any swap; same-name multi-hash coexistence keeps its refusal (one module's dep list cannot link one name at two hashes, and the manifest pin stays the only lever that moves dep content, the store serving content-addressed bytes). @std v1 borderline: `bytes` joins the collections-face round, while `max` (with `min`) migrates to @std in the library-boundary round and `die` splits (ruled 2026-11-17): the bare trap primitive stays a builtin native, the message-and-exit convenience and the CLI's top-level failure policy becoming host code. Landing (2026-11-18): the primitive is the builtin `trap` native — the message rides a `Die` trap out to the drive, the engine printing nothing and deciding no exit code — and the spelling is the CLI host's own declaration member registered beside the ambient for its entry sessions (the signature the old ambient extern carried, the spelling's `trap` row riding the session's declared rows), so a compile without the provision — the check driver, `--no-ambient`, an embedder's bare VM — keeps `die` an unknown name; a block-tail `die` against an annotated return keeps the generic-containment refusal, the never-type machinery staying unset.

### G4 — private / `pub(pkg)` / `pub` plus selective imports

Definitions are private by default; `pub(pkg)` opens them package-wide and stays out of the `.dsi`, `pub` opens them to dependents and enters it. Imports are symbol-selective with aliasing, conditional per target and re-exportable via `pub import`, in sigil form, the quoted form retired (2026-11-10). The `.dsi` is the visibility gate, the API-review artifact, the LSP hover source and the incremental-compilation boundary; the `pub(in ...)` ladder is left out to stay under the sugar ceiling.

### H5 — linear C-ABI handles as substrate, platform packages layered on

Foreign resources are opaque linear handles (`~Copyable`): double-free is a compile error, extern borrows are call-scoped raw pointers the type layer forbids from escaping, callbacks run on VM-managed stacks, and `ds bind header.h` generates typed externs. The embedding API is a Lua-shaped handle table where a `Value` indexes the VM's object table, two embedders being two independent VMs. Objects never move, so a blocking foreign call pins its fiber and cancellation is observed only at VM re-entry. Platforms are ordinary packages exporting effect handlers, selected per build target (`platform "std" provides <console, fsys, net, time>` default, `"web"`, `"embed"`), the checker verifying effect usage is inside the declared row.

**H5.5 — the std/builtin/platform layering (binding).** Three layers with membership criteria: (a) VM core natives in the reserved `builtin` module, the irreducible primitives ds source cannot express — pure or error-union-total and never world-touching; (b) `@std`, an ordinary ds-source package holding everything expressible in DreamScript and resolving script mode's bare specifiers; (c) platforms, the world surface as effect handlers per H5/E1. Platform-seam amendment (2026-11-13): the world natives migrated out of the M3 stopgap registry, so the pure `builtin` core is the only native module of record while world ops live in the platform ABI's dense table; a world call addresses the source's `platform "..."` declaration and install-time validation refuses a call site whose capability is unprovided, `https` rejected until the TLS tier lands — ruled 2026-11-17: TLS is a platform capability, the `platform "std"` net face carrying https over rustls, selected or omitted per host, never builtin and never @std. Landing constraint (2026-11-17): the tier serves rustls's ring provider, constructed explicitly per client and never process-installed, over webpki-roots' static Mozilla set — no system store and no client certs this round, a host pinning its own roots per VM through the embedder seam — so a host selecting the capability inherits exactly that trust story. Library-boundary rulings (2026-11-14): the ambient shrinks to the compiler-required face (the atom tags, the derive traits and `Copyable`, the failure taxonomy, the `str`/extraction/`cancel` spellings, one platform declaration) with everything else in a default-installed ds-source `@std`; the combinator surface stays compiler-recognized, D3's cursor contract ruled only when a second fused collection exists; the failure taxonomy stays core-predeclared over the platform discriminant reservation, user and library errors being ordinary declared types. Collection-face ruling (2026-11-17): the taught @std collection surface is method spellings over inherent members and UFCS — `xs.len()`, `m.get(k)`, `list[t]()` the empty constructor — so the `list_*`/`map_*` prefixed externs are native-seam spellings that never appear in the surface; one name serves one function in the flat value namespace, and the type-keyed member surface is the repetition's answer. The json face is @std-owned ds source (ruled 2026-11-17): the value type, the access surface, the parser, and the to_json/from_json targets live in @std, never builtin or platform, the ambient string-channel `parse_json` retiring once the typed face lands. Json rulings (2026-11-17): the value type is a seven-case enum (`json_null`, `json_bool { bool }`, `json_int { int }`, `json_float { float }`, `json_string { string }`, `json_array { list[json] }`, `json_object { map[string, json] }`); number encoding is int-faithful (an in-range integer literal answers `json_int`, everything else `json_float` through the correctly-rounded reader); no derive seams exist this round — `to_json: (json) -> string` is a plain function over the enum, `from_json` (the string to a struct value through the comptime `fields` traversal) waits on the comptime reflection round; the reader constructs through the enum's own cases with a depth budget, never a native seam, and a native fast path is a future separate ruling should the ds-source reader's performance demand it. From_json path ruling (2026-11-18): `from_json` is a derive family — the engine synthesizes a per-target member body over the landed typed readers (`json_member` plus the `json_as_*` family, each field's read answering `parse_err` on a wrong shape), never a comptime extension — the evaluator's embed vocabulary stays fenced small (DS2034) and the constructed-value seam belongs to the derive engine's per-target synthesis alone. The pure builtins admitted under criterion (a) with it: `parse_float: (string) -> float | parse_err`, and the char face `char_of: (int) -> string | none` with `code_of: (string) -> int` (a char rides the string Ref, so the char-of-a-code-point answers the string or none and the code-of-a-char answers one int).

### H6 — hash-store core plus zero-config script mode; five mandatory tooling commitments

**Package stack.** `ds.pkg` manifests declare deps as `name = { ver, hash }`, hash being blake3 over content including dependency hashes, so identity flows transitively and no lockfile exists; MVS picks the max of declared minima. A global content-addressed store keyed by output hash doubles as the bytecode cache. Native members (ruled 2026-11-17): a package ships native code as per-target, content-hashed prebuilt libraries under `[artifacts]`, consumed through H5's C-ABI seam (`ds bind`), externs binding panic=abort and a blocking foreign call pinning its fiber; a `[build]`-driven source-build round stays deferred until a pinned-toolchain reproducibility story exists, never permanently rejected. Artifacts grammar (landed 2026-11-18): entries `name = { ver, target, hash }` in canonical field order after `[deps]`, `target` a two-to-four-segment lowercase triple, `hash` the library bytes' content hash under the artifact's own digest domain; resolution folds one identity per artifact name across the graph (a second identity under one name refusing), each graph run installs every declared library content-addressed into the store's artifact segment with the registry's artifact storage serving misses by content hash, and a missing artifact refuses the run before any compile. The loading layer landed 2026-11-20: the ds-ffi crate binds an installed library over the raw OS loader primitives (dependency-free, dlopen/dlsym and LoadLibraryW/GetProcAddress cfg-split) and enumerates its exported C symbols off the bytes (the PE export directory and the ELF64 dynamic table), `ds bind` reporting each resolved artifact's binding — the extern consumption seam (scalar C-ABI marshaling through the lowerer's extern refusal) still waiting on its round, its clauses (externs binding panic=abort, a blocking foreign call pinning its fiber) holding from the first bound library.

Package-round rulings (2026-11-15): the ds.pkg spelling is the seed corpus's reference text — `name` and `version` top-level keys plus one `[deps]` section of `dep = { ver = "<version>", hash = "blake3:<hex>" }` entries, `ver` a bare minimum of one to three numeric components with no leading zeros. Non-canonical spellings are drift the parser reports, and a canonical serializer makes a manifest's bytes a pure function of its model, so the manifest serves as the lock. Resolution is MVS over a caller-supplied provider answering name@version exactly: the maximum declared minimum wins, the winning declarer's hash pin validating the fetched package hash, and an unknown name, an unoffered version, a pin or content disagreement or a cross-package cycle refusing; one version per name this round. Package content is single-member: the canonical manifest text is the reserved `ds.pkg` member beside the sources, content-addressed with the dep hashes riding inside so identity cascades, installed as a single-file bundle validated by hash.

Registry-round rulings (2026-11-17): the version grammar carries semver-style pre-release and build metadata — `1.2.3-rc.1+build.42`, dot-separated ASCII alphanumerics and hyphens, a numeric pre-release identifier refusing leading zeros — with precedence numeric-then-pre-release (a release outranking its own pre-releases, the identifier comparison numeric-below-alphanumeric and numerics numerically), build metadata riding identity and the lock bytes but never precedence (a bytewise tiebreak for map keys alone), the canonical spelling always three components plus the segments verbatim, and both segments bounded at 64 bytes so a version stays one inline copyable value. The registry's remote client is git-over-https: `$DS_REGISTRY` names either a local index root or a git remote URL (https the production transport, `file://` the local-testing spelling), the client shells out to the system `git` — no vendored git dependency rides the crate, the transport being git's own — and one shallow snapshot clone per resolution serves the same index rows and content-addressed bundles the local index serves, so every verification, taxonomy, and store install holds over the remote's bytes unchanged; a remote the clone cannot land (unreachable, missing, or no git binary) refuses hard with git's own words, never a taxonomy answer.

**Script mode.** `ds run script.ds` with zero config, bare-specifier imports in sigil form (G4), and `ds save` freezing what the script used into a generated `ds.pkg`.

**Five tooling commitments, binding from day one.** (1) Compiler-as-query-library: memoized `ds-check` queries (parse, block_index, resolve, type_of, effects_of, linearity_check, lower) shared by LSP, REPL and hot reload, invalidated at `##` grain plus package grain. (2) `ds fmt` with zero options, whose block-aware formatter also serves the LSP's on-type formatting. (3) Structured two-span linear diagnostics with machine-readable suggestions and `--error-format=json`. (4) Linear-aware REPL reporting inferred type and effect row with `:drop`/`:reset` purging. (5) Erlang two-version code slots from day one, old frames retiring at their next fully qualified cross-module call.

Module-version handle ruling (2026-11-14): a per-VM append-only version table owns every module version's survival and frames carry an index into it — zero per-call refcount traffic (the measured ~5 Arc RMWs per cross-module call cycle retire), the table storing `Arc<ModuleVersion>` so immutable code stays `Send + Sync` for worker sharing; precise retirement rides an install-time sweep over frames, parked fibers and caches. `Vm` itself stays `!Send`, per-fiber state sendability being the parallel tier's separate ruling.

Hot-dev suspension ruling (2026-11-16): the `ds dev --hot` first slice suspends through the fiber substrate's debug yield — `fiber_yield` spellable from source as a user-declared extern, the ambient staying silent so the debug seam is opt-in — and its answer word is raw, a host-resumed root bounce delivering the none tag, never an i64, so a typed answer read traps where a raw word passes. The dev loop's poll read doubles as the parked entry's tick rate: a parked frame re-enters every poll round, a changed round swapping the module first so the frame's next fully-qualified call lands in the new version, and the differential contract pins byte-identical output against a fresh run. Staged-word re-check ruling (2026-11-17, closing the seam this paragraph queued): every slot swap validates the staged callable words the VM owns — heap objects (closure headers, captures, list elements, map words) and parked frames' slot words — against the incoming table by the identity the table already records (name plus frame layout); a surviving identity re-keys transparently, a dropped, retyped, or unknowable one refuses the swap with a structured diagnostic naming the staged value and the function, the installed version keeping running. A lambda's table name embeds its table index, so a reordering reload that moves a staged lambda refused until the position-stable naming ruling below landed. Direct-call re-check ruling (2026-11-17, closing the retired-code seam): every slot swap validates the CALL/CALLT/CALLG/CALLTG sites of every version-table row a runnable frame or parked fiber pins — a dependent module's rows exactly like the swapped module's own — refusing when the incoming table re-keys a site's function index onto a different name; executable code cannot re-key, so a reorder or a moved index-embedded lambda name refuses while an index that keeps its name installs, the site's judge being the name alone (a changed frame layout is the ordinary body edit, the inline cache re-deriving the site's facts, a signature change trapping at the call like a fresh run's) and the staged words keeping their name-plus-layout judge; a row no runnable frame names takes the ordinary redirect, the completed-frame semantics. The same round's value half: a retiring frame's post-swap KCONST mint of its own pool's fn word translates the old index into the current table by the staged judge, a dropped identity refusing at the mint, and a dying frame's teardown hook drives through its owning frame's version row, never the module's current slot. Debug-seam ruling (2026-11-17): the user-spellable `fiber_yield` extern retires with that vocabulary — the dev host injects suspension through its own capability face, the platform `time` op never doubling as the debug seam, so no user source ever spells a raw-word yield. Position-stable lambda naming ruling (2026-11-18, landed the same round): a reordering reload re-keys a moved staged lambda or a moved index-embedded call site exactly when its content identity survives the move — the lambda's body plus its capture set hashing equal, the hash computed per function at table build and compared against exactly one incoming candidate — since identical content means identical behavior and the re-key only preserves identity; a body edit riding the move, a capture-set difference, or a content-ambiguous match (two identical-body identical-capture lambdas) keeps the structured refusal, the re-key never guessing. The landing's mechanics: the staged-word map and the retiring frame's KCONST mint extend their name-plus-layout judge with the content fallback (an index-embedded name alone engages it), the swapped module's own retiring rows' call sites pass the direct-call re-check on the same content judge and translate at dispatch through the identity their row records (the kept-name fast path first), and a dependent module's sites keep the strict name judge — their rows record no linked version, so the cross-module redirect stays the verbatim current-slot read.

## 9. Runtime

### Fixed baseline (BL-1..BL-7, binding on every tier)

- **BL-1 Typed register bytecode.** 32-bit fixed-format instructions with register-index operands and typed opcodes, no dynamic variants since every operand's type is a compile-time fact; biased jump offsets and XOR-negated comparison pairs.
- **BL-2 Unboxed slots.** No NaN-boxing, no per-slot tags, no boxed scalars: scalars raw in frame slots, references raw pointers, ADTs/unions unboxed tag+payload pairs.
- **BL-3 Dispatch.** Computed goto or C tail-call threading, a build-portability choice.
- **BL-4 Superinstructions on profile data.** The assembler composes fusions from measured opcode frequencies.
- **BL-5 Uop decomposition from day one.** The instruction set is micro-ops with explicit slot effects and `pure` annotations, so the copy-and-patch stencils are these uops one-to-one.
- **BL-6 Frames inline in a typed value stack.** A contiguous span of statically-typed slots plus a metadata word per frame, so TCO is a pointer shuffle.
- **BL-7 Position-independent, mmap-able dsmod.** Fixed-width, index-based, relocation-free bytecode with a module header and an IR-version checksum, contracted in G3.5.

### H1 — three tiers over one shared lowering

Tier 1: typed register VM, computed-goto uop loop, unboxed frames, target 3-10x of C. Tier 2: copy-and-patch stencils, one fragment per uop emitted at build time, ~14% faster than LLVM -O0 at ~100x its compile speed, target 1.5-3x. Tier 3: bytecode -> typed SSA -> Cranelift CLIF, or wasm 3.0 (`return_call` carries TCO), target 1-2x native. One uop set and one bytecode-to-SSA lowering is shared by all tiers and built early. No guards exist on any data path — the only exits are debugger breakpoints, the per-entry stack-limit compare, effect-handler entry and B7's cold overflow edge — hence no deopt cliffs, and static typing leaves no hidden classes, type guards, deopt frames or side traces. Short scripts (<0.2s) never pay tiering, and platforms without verified stencil builds ship tier-1 only. Fallback H1b: a single method-JIT tier if the per-arch stencil toolchain proves unacceptable.

### H2 — guaranteed TCO from day one, self and mutual

Frame reuse plus argument slide in tier 1, label loops and slot-overlay `jmp` in JIT tiers, `return_call` on wasm. This ABI and BL-7 are the two decisions to lock before anything else. Guarantee closure ruling (2026-11-12): no callee-class exception — the tag-dispatched tail call is committed, transferring through the same frame-reuse slide with instance/evidence words staged after the exit claims and the tag-keyed inline cache keying it identically; a count-free closure callee word transfers through the plain tail call by maybe-Ref tracking. Landing precedes M8's differential tiers.

Queue-closure rulings (2026-11-12): destructured `const` binders alias the source `var`'s words, so reassignment through the var is observable through the binders; native fn values never mint a callable word in 1.0; the future fetch native answers both ambient `net_err` cases by error class.

### H4 — Perceus RC + reuse + per-frame arenas, collector interface as growth path

Precise non-atomic RC with reuse threading for boxed/shared values, over per-frame bump arenas for non-escaping temporaries: zero pauses, no barriers, no safepoints or GC maps in any tier, deterministic frees feeding deterministic deinits, and per-fiber arena marks making fiber switching free. Honest accounting: all non-moved temporaries are register/arena-resident, the boxed/shared residue keeps paying RC, and the reuse pass is budgeted as optimizer work. The two-hook collector interface (cycle candidates, weak refs) is committed as the growth path.

## 10. Staging (v0 -> 1.0)

Ordered; each step lands on the previous one with no language-change rewrites.

1. Lock the two load-bearing contracts: the slot-overlay call ABI (H2) and the fixed-width mmap-able dsmod format (BL-7, G3.5).
2. Checker core: the B1 set algebra, B2 bidirectional checking plus refinement, B3 products/sums, B4, B7, B8, B9, and the affine checker plus DI (C1, C5).
3. Tier-1 interpreter: uop loop, unboxed slots, tag+payload ADTs, frame-reuse TCO.
4. Memory: Perceus dup/drop placement, reuse threading, per-frame arenas; `rc==1` checks and the borrow counter as the diagnostic layer.
5. Concurrency: fibers, nursery, `cancel`/`discontinue` evidence dispatch, fork-join combinators.
6. Derives; then the comptime evaluator and reflection API (before 1.0).
7. Tooling commitments from day one, sequenced with the query compiler they consume.
8. Tier 2 copy-and-patch (x86-64, then aarch64; tier-1-only elsewhere), bytecode-to-SSA lowering early, tier 3 on demand.
9. Deferred-additive backlog after the core is stable (§11); borrow inference, TRMC and fusion upgrades land as pure optimization.

## 11. Deferred-additive backlog and recorded fallbacks

Deferred additive (in headroom order of likelihood): `|>`, anonymous record literals (the map literal rides this reservation per B3), `@` binders, `??` on `t | none`; then `?.` desugar, `throws(...)` sugar, user-defined handlers, scoped named instances, labeled break/continue, `it` shorthand.
