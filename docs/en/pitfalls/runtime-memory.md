# Runtime: native seam, reentry, memory facts

- Install natives and the platform into the registry before `loader::install`: pool FuncRefs validate at install time. `Vm::with_limit` installs only the builtin core, so the CLI calls `provide_platform` on both run paths.
- World calls address the source's `platform "..."` name (default `std`): a host installing no platform under that name, or one not serving the call site's op capability, fails the install as `UnprovidedPlatformOp`.
- Reserve ids from both ends: union ids allocate upward from 0, the platform reserves the u8 top downward (IO_OK 255, IO_ERR 254, NET_ERR 253, PARSE_ERR 252, NONE 251) with the cross-module none member at MAX-4.
- Never renumber an op table: the platform ABI is its own dense table, the builtin core keeps its historical 0-48 run with the world-surface slots and every generic builtin's monomorphic slot reserved, and pool FuncRefs name positions.
- Fallible natives: the two-word platform span re-spans into the call's failure union over the success-typed ambient, a total spelling extracts the payload, a failure prints `io|net error: <msg>` and halts, and CALLT-to-fallible is Unsupported.
- The ambient `enum net_err { timeout, refused }` pre-commits two case tags against the platform's single NET_ERR discriminant, which the fetch native maps onto both by error class (ruled 2026-11-12); https stays rejected until the M7 platform decision.
- Hosted calls (`Vm::call_hosted`, reachable from generic builtin bodies holding `&mut Vm`) inc each Ref argument, since the callee's placement owns its parameters and borrowed staging double-decs; the channel carries whole word spans each way, and a RET span at the reentry frame skips the caller-area bound.
- A boundary drive answers `DriveOutcome::Frame` keyed on the sentinel reentry frame (u32::MAX return pc), precise across fiber switches; a yield or HALT escaping a hosted drive is `ReentrancyRefused`. Only the root frame's native tail may CALLT with abandoned staged counts.
- Every native call opens one borrow window in the placement pass before its operand evaluation and pops it at the flush, pinning each word its CALL reads, so a death firing inside defers to that flush (the `b + "${b}x"` shape); windows flush LIFO, a flush-dec dedupes against the deferred last-use dec, a local callee handed a window word dups it, and every `native_done` pairs with exactly one window, which its `debug_assert` guards.
- A child's pool slot can be recycled while the nursery's children list still holds the id: re-check `fiber.nursery` before driving and ledger outcomes before recycling.
- A host-delivered word's count never releases (`host_delivery` releases only the ledger row), so an rc-balance pin expects one more count per `vm.run` handing the same word out.
- Keep the spawn seam's two closure forms on separate staging paths: a `spawn {}` block compiles to a child whose declared parameters ARE the captures, while a fork-join closure callable is an ordinary lambda whose parameters are the element's words, so its capture block stages past them into the frame's leading local slots; entering a fork callable with captures-as-args reads the body's locals as parameters.
- The fork-join completion delivery must acquire the receiving fiber's claim row, one per `Ref` word of the answer span, before the joiner's dec: `Heaps::dec`'s exact-ownership gate releases a foreign word only through the dec'ing fiber's own row, so a rowless dec strands the count on the dead child's heap (the one-word `par_map`/`par_reduce` path leaked that way). Read a delivered count through a live holder.
- A count mutation from a dead-context drive routes through the pool, the copy-in helpers following `ctx_live`: a hardcoded live-context assumption reads a just-died child's word through the scratch store as an `UnknownObject`.
- The list copy natives (cons, tail, collect) touch their element words exactly once: memcpy into the one `Vec` the fresh list adopts, then one branchy walk taking `inc_edge` per `Ref` word; a second `Vec` adds an allocation plus a copy pass per call (containers regressed +117%).
- The join/teardown driver's re-entry of a parked child is a preemption point under the nursery's raised cancel flag, its kept-frame deinits firing through the cancel-cut door; an uncancelled yield loop may hang like any infinite loop, and CALLT pc-reset stays outside the observation points, so a self-tail-loop child never observes cancellation.
- A fiber joining another open nursery parks at its join call, and the joined drive runs on the interlock stack (frames pushed and consumed LIFO, each answer delivered onto its parked joiner's call site), so nesting costs heap, never the Rust stack (pinned in `crates/ds-vm/tests/nursery_interlock.rs` and `conformance/nursery_deep.ds`); joining its own nursery, or one whose drive already stands, refuses with the structured nursery trap.
- The fork-join nesting unlock parks the CALLG site through the interlock's frame stack, never nesting drives on the Rust stack: a synchronous unlock holds Rust frames per nested combinator body and aborts at depth ~800 with no structured trap, while the parked seam holds a 2048-level nesting pin. A fork at a tail dispatch site (CALLTG) still refuses, the park needing the CALLG site.
- A teardown hook must return to its driver: one that parks, dies, traps, observes a raised cancel flag at a backward branch, or calls a nursery control seam refuses with `Trap::ReentrancyRefused`, the nursery natives refusing at the dispatch while the drive flag is set. Its effects stand, and never cut the fiber whose death walk is driving the hook.
- The teardown claim directory comes from each body's own drop shape (`MOV overlay(i) <- body(base+i)` run plus `CALL` of the module's `$deinit`), so a hand-assembled fixture staging such a call onto a `$deinit` callee is a claim site whether or not it is reachable.
- The claim establishment band is one Tag body word per claim site with two reserved values, SET at registration and CLEAR at every drop, hand-off, and consuming staging, at or above `FIRST_RESERVED_TAG`, since a user-mintable value lets a recycled frame region's stale word fire a never-established claim at a door. Registration threads the code buffer and band word through the four func.rs call sites, and the firing door clears the band itself.
- A word a borrowed registration names never anchors a deinit claim (the placement's borrowed set): a const alias, a match binder, or a `_` discard over a borrowed deinit-carrying param binds the owner's word without re-establishing the frame's claim, so the owning caller's drop stays the single fire; e2e goldens over deinit scrutinees therefore read through the scrutinee's own name.
- A teardown door can fire while another live fiber is current: the takeover parks that fiber's context before swapping the dying fiber's parked one in and must re-adopt it after the pass, or the caller continues on stale scratch and corrupts (pinned in `crates/ds-vm/tests/teardown_deinit.rs`).
- Every Fn-classified widening proves its word a non-capturing scalar (`scalar_fn_words`): a var's fn slot, a collection element, a tuple element, a union region's fn payload, and every fn-typed answer staging (same-type join arms, `unwrap_or*` fallbacks, `.ok`/`.err` bodies, the fn-typed return), with ok_or's err arm staging directly. An unproven callable word may hold a closure's `Ref`, trapping `SlotTypeMismatch { expected: Fn, actual: Ref }` and stranding the count, so the guard is static and provenance-keyed; the fn-typed return refuses unproven words only, a closure tail keeping the factory boundary (the recorded return-flow seam). A fn-typed struct field never reaches the guard, since the checker's universe drops field types the core cannot express, and refuses at its own span.
- Generic trait bodies lower once per impl under runtime evidence. Refused: a chain past the frame's two follow words, a serving body demanding several or different members, an inner callee whose demand the frame never staged (a coinciding demand rides the shared slot), per-branch evidence over a receiver unioning type variables, and a substituted pair variable spanning more than one word. Per-instantiation frames belong to the JIT specialization tier, never the interpreter.
- Evidence crosses a lambda frame through capture-block words staged from the enclosing frame's evidence slots (transitively), and a spawned child's capture block IS its entry arguments, so the spawn site moves the frame's evidence words beside the captures and they bind as the child's trailing entry parameters. The enclosing demand walk collects every demand inside its lambdas and spawned subtrees, and a missed demand keeps the missing-slot refusal.
- Transitive evidence: a pair's frame area is the slot plus two follow words; the demand walk also collects a constructed receiver's peeled variable (`list[t]` demands on `t`), a nested static site copies the callee's area verbatim, and a nested runtime dispatch slides one level per hop with the last word padded. CALLG/CALLTG riders need exact arity (the target's parameters equal the real arguments plus its own pair areas), so a rider-eaten gap traps as an arity mismatch while the I64 rider read is the defense-in-depth. Refuse at the entering site: a chain past the follow words, an ambiguous link, divergent member demands, and a variable wider than one word.
- The per-call-site check for `Raw`-staged words must admit a `Raw` callee parameter like the native table's and the generic dispatch's kind checks, a Raw parameter being the wildcard: without it the first `Raw`-into-`Raw` staging through CALL/CALLS/CALLT (a directly called evidence-carrying lambda) traps as a call-site layout mismatch while the lowering is fully staged.
- Captures copy by value at CLOSURE_NEW, so mutable-capture shapes stay out of the kernels. Pinned honest refusals: a lambda capturing a closure word, a lambda capturing a callable-defaulted binding, and native or generic fn values minting callable words (never in 1.0, ruled 2026-11-12).
- The module-id space is registry state, not a format fact: ids mint per VM at first install (first-install order, stable across hot-reload swaps, uop modules only, since native names never enter the id space and a KCONST on a native FuncRef traps UnknownCallee). Nothing diagnoses a fn word crossing VMs, so a word minted under one registry silently aliases the same id under another (pinned in `crates/ds-vm/tests/module_ids.rs`); the M7 link-table round moves ids into the format, its ruling landing in design-decisions.md first.
- A cross-heap count op queues only on the store whose own mutation observed the foreign word, and every routed mutation drains to quiescence, so one store's queue length is the whole pending count, which lets `settle` answer a quiet queue without walking the pool; a second queue site that does not end in the drain breaks the shortcut silently.
- A KSTR row slot cached on a frame is a HINT revalidated against the row's own `(pool, fiber)` key, so reclaim may compact rows freely, and a segment chunk stays a fixed-length array (`Box<[Word; CHUNK_WORDS]>`), since a slice reintroduces the fat-pointer load and the second bounds check in the locator.
- A call site's layout facts — the slide plan, its `Raw`-staged word list, and its layout-static refusal — ride the inline-cache entry under the same (caller address, pc, stamp) key as the callee, so they are re-derived exactly when the callee is (a swap bumps the stamp; a freed-and-reused caller address needs an install), never on a hit; a refused pair re-raises at the call seam where the per-call derivation raised it, never as a resolution failure, and the runtime-callee paths (CALLS, the evidence sentinel) derive per call by nature.
- `module.rs`'s body validation proves every pool operand's index and kind at install — CALLTG included — so the dispatch arms index the pool directly and keep only the kind arm as the corrupted-pool tripwire; the pool-index and pool-kind refusals are install's `ModuleBuildError`, and the runtime `Trap::PoolIndex` has no raising site left.
- A chain entry always names its frame's pinned version and holds the frame's one live `ModuleVersion` handle while the frame is suspended: `RET` takes the caller's entry handle back as the restored `Active` and swaps the popped callee entry's handle into the caller's entry when `Arc::ptr_eq` says both name one version (the same-module return — no Arc RMW, no `CallInfo` copy per return), while any other pair (cross-module callee, or a swap between the two entries' mints) keeps the clone-and-drop mint so the caller keeps running the version it was entered under; the still-minting seams are the resolve-side hit clone in `resolve_site` (the cache borrow forces it), every entry push (`call`, `tail_call`'s rewrite, `push_entry_frame`, the hosted reentry — the entry and the dispatcher's `Active` are two homes for one version until the duplicate-handle redesign), and `park_current`'s resume clone; an entry must never be left holding a foreign version, because the backtrace and teardown walks read the innermost entry's module directly.
- The peek-next load-op fusion inside the KIMM/KCONST arms keeps three invariants, each pinned in `crates/ds-vm/tests/load_op_fusion.rs`: a fused arith's traps and slot errors attribute to the arith's own pc (pc+1), never the load's, so a trap is indistinguishable from the unfused run; an intervening RC word fails the opcode-byte match, so the fusion peeks exactly one word and a counted word between a load and its arith never fuses (the census adjacency rule); and a load at the code end peeks nothing (`code.get` on the out-of-bounds index) and takes the plain path. The fused-pair opcode bytes are pinned against ds-abi's own `Uop::opcode()` derivation, never hand-copied hex, and DIVI64 stays outside the fused set until the census measures the pair.
- The peek-next compare-branch fusion inside the LTI64/EQI64/GTF64 arms keeps four invariants, each pinned in `crates/ds-vm/tests/cmp_branch_fusion.rs`: the bool write stays before the branch decision (the compare's dst may be read on either path); the fused branch re-enters the exact JMPIF_NOT arm body with pc bumped onto the branch's word first, so a bounds trap attributes to the branch's own pc and the taken-backward-branch cancel observation fires exactly where the unfused spelling's does — a fused back-edge preempts a parked fiber identically, jump-to-self included, which is the rule any future fused-branch family must preserve; an intervening word fails the opcode-byte match (the census adjacency rule); and a compare at the code end peeks nothing (`code.get` on the out-of-bounds index). The peeked opcode byte is pinned against ds-abi's `Uop::opcode()` derivation, never hand-copied hex, and JMPIF consuming the compare's dst stays outside the fused set until the census measures it.
