# Front end: scanner, grammar, diagnostics, package format

- Visibility is file-grain (G4): every multi-file fixture and ambient stub needs `pub` on what another file uses, or the items it serves fail with DS4017.
- An impl's trait reference resolves through the type namespace, never the value-first bare-use walk: a free `fn` sharing the trait's name can otherwise claim the impl head and mislead the visibility check.
- Client positions convert through `ds-lsp`'s `convert::offset`, never by hand: a hand conversion overflows and `Files::line_span`'s assert kills the session.
- ds-lsp's file walks (completion's type positions, semantic tokens) share one traversal mirroring the resolver's own scope pushes (`walk.rs`): a new item or expression shape threads through the driver's match alone, the walks answering through `Visit` hooks. A hand-mirrored copy drifts silently — the old completion walk had stopped entering match-arm annotations and patterns while the resolver and the token walk entered them.
- An LSP test document URI must spell a host-real path (`Url::from_file_path` over a temp path), or `Url::to_file_path`'s refusal on Windows leaves the harness waiting out its budget as if the server deadlocked.
- The grammar's stack segment belongs to the caller thread, so a thread-local worker serves one job per parse and each job carries its own source copy; an inline fast path for small nesting breaks that contract.
- Never join the grammar worker from a thread-local destructor: joining there aborts the process at exit (status 127).
- An attribute class the derive expansion owns must be named by the per-tree expansion gate (`has_expansion`), or a tree carrying only that attribute passes unexpanded and drops the refusal. The case-attribute vocabulary is `#[default]` alone; any other attribute on a case is a syntax error.
- An analyzer probe over derive-bearing sources runs the expansion first (`ds_meta::analyze` over the parsed trees): `ds_check::analyze` leaves the attribute unconsumed and checks a different program — no synthesized impls, no derive refusals — so a hand-rolled probe answers the wrong question while passing. A hand-written mirror of a synthesized body must also spell the synthesized AST shape: the enum arms are path patterns, and a bare-identifier mirror arm binds a whole-scrutinee catchall where the synthesized arm tests the case — such a mirror once passed clean for that binding alone, proving nothing about the case-resolution door it claimed to mirror. The matching failure class over a generic enum head lives in the checker's resolution doors (case defs collected, unit-case atoms minted, membership and exhaustiveness read off the applied head), never in the derive's span minting — probe the doors before naming a mint seam.
- Keep inline `.ds` sources inside Rust string literals on one line: a backslash continuation strips the next line's indentation, so a split signature parses as a two-slot param list. `format_strings` re-wraps an overlong literal with those continuations anyway — the strip is total, so the seam must not fall where leading whitespace is content, and an exact-equality assert on the joined text gates it.
- `ds_mod::Function` stores the wire words and `code()` is the on-disk form, so a decode is validation and never storage, and the reader's decode pass owns the load path's jump-bound check.
- `loader::install` consumes the module, so a caller retrying after a refusal rebuilds it; the writer and the corpus tests keep the borrowing `code()`/`functions()` accessors.
- New dsmod payload fields go inside the encoders only: the writer runs each encoder twice and asserts the passes byte-identical, so a field written outside one desynchronises the directory silently.
- A per-definition query slice reads the package pass's fact index, since the span containment scan is O(D^2); the index answers a fact to the last block starting at or before it only when that block also ends at or after it.
- A hash-map type in a public field is a cross-crate compile unit of its own (a `FxHashMap` switch broke another crate at merge while each lane was green), so announce it or wrap the field behind an accessor.
- An implicit dispatch site (an interpolation hole's `show`) carries no resolved name, so resolution-keyed passes read the checker's span-keyed `Checked::hole_show_dispatches`; re-deriving from resolutions misses the hole.
- A REPL session cannot ride the script-mode fold, so the REPL owns `fn main` and appends submissions inside it; a `:drop` leaving later references behind breaks the session text until `:reset`.
- The precompiled ambient blob (`crates/ds-stdlib/src/ambient.ast`) addresses the file id it was generated under, so `ambient_blob_matches_a_fresh_expansion` fails on a grammar or conversion change until `cargo run -p ds-stdlib --example gen-ambient` regenerates it.
- The checked-ambient `.dsi`'s universe logs are captured at the declaration-phase boundary, never from a finished analyze, since later mints shift every id; a pre-minted `$t#N` surfaces as a bogus `impl head does not name atoms`. Serve-carried rows address atoms by name (2026-11-24), the raw ids beside them a checked fast path a mismatched walk drifts on — never a remap.
- A served instance head or condition naming a trait-relative set (`TypeExpr::Trait`/`Not`) could re-solve wider once a user impl lands, so the coherence skip refuses such a prefix and the closure pass keeps probing every pair and cycle a fresh row takes part in.
- A stack overflow aborts the process with no unwind, so `catch_unwind` around the parse worker contains parser panics only: every bracket-free recursion class is refused by the lexscan pre-scan instead, and a depth-budget test that aborts the runner is a budget bug. Pest backtracks a near-legal prefix's full depth, so the budget binds illegal prefixes too; the unbracketed operator chain right-recurses per term and is guarded after the grammar at conversion (`MAX_CHAIN_TERMS`).
- A package-level `tag none` claims the name the universe predeclares as the none atom, so every ambient `none` spelling resolves onto the user's file-private def and refuses (DS4017 at the ambient's own signatures); the linked `none`/`type` tier waits on the reserved-atom mapping.
- An import surface keys by the import declaration's whole span, and its link position is the dep-list writer's own first-occurrence index over the same trees: a position walk differing from `dep_list`'s points a linked FuncRef at the wrong dep slot.
- A frozen corpus file's `stage: typecheck` items pin the ambient's name choices, so name ambient declarations apart from every corpus declaration: a redeclare in the same namespace lands in the item as DS2005 and turns run-item noise into an exit-1 gate failure.
- The @std dsmod splice installs function records and member-tag rows seeded into the merged lowering's tag table and validated against the plan, so an artifact without rows, or with a row the plan does not mint, is a `ServedDrift` refusal.
- Never key a store-backed provider by a snapshot of the store's rows: a demand index built by scanning goes stale the moment another process installs, so a provider that had answered once refuses content a later `ds save` landed. The demand's pin routes the read — one file per demand, fresh by construction — and an aggregate over the store belongs on the refusal path alone (the unserved taxonomy), where resolution's terminal answers bound it to one scan.
- A dep bundle whose source members cannot serve (a non-UTF-8 member, an empty set) refuses at the provider seam: the store's row serves no demand and a fetched copy answers `Refused`, so the run path's member refusals are guards no resolution reaches; the root's walked files still fail at their read.
- A query slicing another query's substrate keeps its own identity anchor on the expansion (the `package_linearity` spell): the holder's renewal identity covers its derived payloads, never the substrate's span-keyed side tables, so `analyzed` depending on the checked package alone would serve stale spans through green renewals — the anchor's forced recompute is what slices a fresh bundle every time the trees can move.
- The `DSnnnn` registry is append-only once shipped (the whole table pinned by `code_table_snapshot`): when a refusal narrows, keep the code and scope its trigger — DS2011 stays guarding a written branch that names atoms yet solves empty while the canonical `TypeExpr::Empty` spelling declares — since removing or renumbering a shipped code breaks every reference that names it.
- ds-diag's `render::human` caps the excerpt lines one label may show: a span covering more than the cap renders its head and tail lines around a bare `... N lines skipped` marker, so a golden over a whole-construct span must spell the marker, while spans at or under the cap render byte-identically (the boundary pinned by test, so a moved golden means the cap changed, not renderer drift).
- A new field on a `ds-parse` AST variant is a workspace-wide edit, not a local one: every non-`..` construction and pattern must arm it (a `Delim` on `Type::Path` alone re-arms ~25 sites across ds-check/ds-lower/ds-meta/ds-cli), so representation changes ride a merge window with no parallel worktree touching those crates, never a shared round.
