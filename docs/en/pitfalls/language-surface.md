# Language-surface spellings

- A declared field name may be a keyword (`field_member` parses `field_name`), since the reflection record's `type` member needs it; the declaration side must agree or the record struct cannot be spelled.
- The builtin `type` atom lives in every universe beside `none`, so fixture universes and mint-order pins account for it, and a `type`-annotated parameter outside comptime mode refuses (DS2030). The reflection builtins (`fields`, `type_name`) are wired by name and answer only inside comptime functions, so redeclaring either in the ambient's namespace is the duplicate error.
- The type-value reading of a name is expectation-driven and comptime-gated: a type name where a `type` is expected answers the builtin atom only inside a comptime fn's body or a comptime call's arguments (DS2032 otherwise), and keeps its constructor reading under no such expectation.
- A comptime parameter's scalar annotation is admitted by name (int, float, bool, string) at the declaration gate and staged by the annotation's shape at the call, so a parenthesized literal, a holed string, a suffixed number, or an omitted defaulted parameter refuses at the evaluator's staging.
- A trait or impl member declares its receiver as its first parameter (`self`/`mut self`, typed `Self`) unless it is a receiverless inherent member: DS2021 refuses only trait members, while a receiverless inherent member is the static surface called through its type name. The bare-type-name receiver is tiered: the type's own impl member claims it, a tag or case name naming none of its own type's members keeps its constructor-value reading, and any other type names its members alone.
- Adding a `DotRes` variant fans out beyond ds-check's resolver and `type_of`: effects and linearity route the record's edges, and the lowerer's PairWalk, callee_demands, Field-callee arm, and `is_tail_callee` each need their match, with ds-lsp's goto-definition walking it; a missed arm panics at the first e2e.
- A payloaded enum case named `none` claims no atom of its own, so construction refuses at the call-form seam (DS2022); a construction-site lookup that would fall back to `empty` refuses instead of typing the binding empty.
- A trait impl member carries no parameter defaults of its own, since the trait member's registered signature is the only default source call sites stage: a re-declared trait default refuses (DS2019), an impl-only one refuses (DS2020), and a member with neither an impl body nor a trait default refuses at the impl's own door (DS2023) rather than trapping at the dispatch seam.
- A member signature's generic parameter binds freely to any argument unless the dispatch's substitution binds it first, so before that binding a mistyped argument checks clean and traps at the nested dispatch's ABI slide.
- A lambda literal's own arity must match the expected fn type's exactly, over every expectation source (a direct call's parameter, a solved generic's fn-typed parameter, the trailing block's slot), or a zero-parameter block over a `fn(t) -> r` parameter traps at the hosted per-element arity validation (DS2007).
- An un-annotated `.err` handler under no contextual expectation consumes the whole union, so fallback sites annotate the handler parameter (`(e: net_err) => ...`).
- The extraction family's `ok_or` keys its member entry on the payload side's single atom, so an optional whose payload spans several atoms (`json_member`'s `json | none`) refuses at lowering while `unwrap_or` over the same optional runs; a json decode none-tests the member optional first and lets the scalar reader carry the failure.
- The early-exit decode vocabulary is the statement narrow: bind the union, `if x is parse_err { return parse_err }` as a statement, then read the narrowed binder. A `return` in a value-consumed position refuses at the checker (DS2039), and `let x = e?` over a fully-contained union reports DS2002 by design, since `expected = none` propagates every member so nothing binds.
- Destructured const binders alias a `var`'s words, so a reassignment through the var is observable through the binders.
- The guard quirk's parenthesization is whole-expression: `x > (m)` before `=>` still steals `(m) =>` as a paren-parameter lambda, so only `if (x > m) =>` parses.
- A dot-call's free tier owns the name unconditionally: `x.f()` feeds the free function named `f` before any member candidate, so an inherent member sharing a free function's name never serves a value receiver (`m.len()` answers the free `len`, whose instance table refuses a map receiver at lowering), and the type-keyed member tier answers only names the flat value namespace does not already serve.
- A method call's effect row unions every registered candidate's row, so one trait-member body carrying a trapping op stamps `trap` onto every dispatch of that member name in every session, which is why the ambient's `impl show for bytes` renders through the `concat` extern and a for-in walk instead of string `+`.
- A union value crossing modules carries its producing module's tag id, so the linked module's own tag-table rows ride the import surface and seed the consuming compile's table at lowering: the seed keys only names the consuming compile minted from the linked facts' own installs, drops every other row, and refuses when two linked modules claim one id, since the code immediates are frozen in their artifacts.
- The bound tier's placement mask reads bit i as word i FP, the first word at the low bit: a staging fold that shifts each new word in reverses it, and the symmetric pure-GP and pure-FP legs stay green while every mixed leg calls through the wrong function-pointer type and answers garbage, so each marshaling face's suite pins a mixed placement (2026-11-21).
