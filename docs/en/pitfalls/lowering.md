# Lowering invariants

- Every compile seam refuses on the affine walk's own diagnostics: the run path lowers off the checked bundle, so a seam that skips the walk lets a moved-then-used script check clean and its deinit fire twice.
- The admission pass and the comptime slice split at `plan_item` on the comptime parameter mode; a callee the plan never receives lowers a call the belt refuses with the wrong diagnostic.
- The comptime fence's refusal and its first-hop origin drill read one row predicate (`row_admits`), so a predicate change touches both call sites.
- The reflection table reaches the fenced VM as one snapshot (`set_reflection`, the guard restoring on drop): register every site's arguments, then install, then run — a type registered after the install traps `UnknownInstance` mid-run.
- The world fence is the install seam: the evaluator's registry serves the package's platform name with an empty provides list, so the slice's install refuses a world FuncRef with `UnprovidedPlatformOp` (DS2033); installing no platform or a trapping handler loses that diagnostic.
- A comptime call's embedded answer lowers as the literal a user would write at the call's span, carrying the call's result type (a list's element type included); a `lower` call without the evaluator's map hits the belt refusal there.
- `call_impl`'s `tail` flag is a contract with `tail()`: a tail callee emits its own exit, so every early-returning `call_impl` shape (the comptime embed, the handler and constructor inlines) must be excluded by `is_tail_callee`. A callee-kind tail arm needs its own `tail` guard too, or every cross-module call emits CALL plus RET to a linked callee.
- The frame-reuse tail transfer slides the callee's answer words onto the caller's caller, so a tail call is sound only while its checked answer equals the declared return: a member or strict sub-union answer needs a re-span no position offers, so those tails lower in place. Stage the exit deinit claims before the argument Movs, or the overlay window clobbers the staged span.
- Union payloads share one region per union type: a member claims the lowest free word of its kind and zero-writes its dead payload words with each word's own kind, so a dead `Raw` payload word fails the call slide. A union-typed parameter stages its whole region, its member or sub-union re-spanned through an anonymous temp (a deinit-carrying member refuses there), and a return re-spans.
- float `%` refuses at the lowering boundary (the locked uop set has `ModI64` only), and the checker's [B7] rule refuses float wrap operands before the wrap arms pass `arith_dst` the same `DataOp` for both parameter types, which would mis-lower an f64 word as i64 with no trap. `list_new`'s zero-arg call still needs a one-word overlay area.
- Every place-table write inside a linearity body walk goes through `set_state`, which records the undo entry; a direct `state.insert` rewinds past its own write and branch isolation stops being exact.
- A short-circuit's second test jumps into its own answer block carrying the post-right-operand ownership state, so that exit fires the full arm's dying drops — an answer block the left shortcut also uses frees an object the right operand's call already handed to its callee. Every site emitting sibling frame exits forks the placement map, since `rc.exit` clears the ownership map at the first.
- A construct re-executing its head forks the placement map before the head (`rc.save` plus `loop_enter`), or a Ref-reading head re-fires its read-dec per back edge and frees the object after the first iteration; anonymous carried operands sweep through `drop_unnamed` at the exit.
- Every loop registers exit and backedge labels below its body scope (`LoopCtx`), and `break`/`continue` drop the body scope's binders inward at the jump from a read-only snapshot (`loop_exit_drops`), so each path fires each deinit claim once.
- A bare identifier in a match test position resolves through the type namespace first and binds nothing on a hit, so keep resolve `arm_tag`, type_of `unit_pattern_atom`, and ds-lower `binding_atom` aligned. Such a name needs the foreign-type fallback where it can arrive import-bound, and a miss is silent: a linked case name answering no atom makes the arm a catchall the checker's coverage proof still accepts.
- Never name-find over positional slots: a tuple member's `None`-name fields all compare equal and a `find` answers the first field, so walk `ordered_field_srcs` and resolve per-element binding through `word_addrs`.
- Accept a catchall-free match only when no arm can fail (union tag tests cover the dispatch); a value-level chain with literal tests or guards refuses without one unguarded catchall arm.
- A non-union or-arm lowers as an alternative ladder binding through its last alternative, so its alternatives must bind the same names on the same words; the checker compares name sets only, so a same-name-different-word alternative refuses at lowering.
- A non-union match chain runs every arm's tests and guard in order on the fall-through path and snapshots the post-guard state per arm, its join reconciling heterogeneous states. A guarded arm over a Ref-carrying scrutinee binds an inc'd word-for-word copy at the section top, and a guard taking the scrutinee's own count refuses.
- A union match's slides re-enter shared dispatch code over one base state, so a jumping path must arrive base-equivalent: the guard's failure edge drops the section's transients at its cleanup label, and a guard taking any count the base state holds refuses. Bind every arm's dispatch entry before any slide targets it and let a catchall intercept at its own position, or the slide goes to `usize::MAX`.
- An `is` test over a written type other than a nominal single-segment path lowers through the checker's solved test at the test expression's span (`Checked::is_tests`): a multi-atom solution joins one TAG_TEST per atom, a covering set folds true, a disjoint one false, and a type variable on either side refuses.
- A span claim folds its span's plain count words and decs every `Ref` word behind the hook, so a folded word never dies on its own; a field-read copy of a folded word borrows and the claim keeps its count.
- A lone unit tag or case spells one Tag word in every value position, the field-span walk (`atom_field_span`) and the value walk (`atom_shape`) ruling it together: a field-span arm that spells a different class (the I64 unit word) checks clean and traps at the construction's typed store (`slot n holds Tag where I64 is required`), and the linked fact walk keeps the shape out on the same line, so the two walks must move together.
- The empty tuple `()` stays outside the field-span vocabulary on both spellings — the written tuple (`field_span`) and the aliased tuple atom (`atom_field_span`) refuse the empty case at the declaration through the shared inline-span refusal — while the value vocabulary keeps the bare `()` its one canonical unit word and the `int | ()` member its bare tag: before the doors a `()`-typed field checked clean, trapped the region claim's debug assert inside a union member (a phantom zero-width member in release), and refused only at the literal's width mismatch on the plain struct.
- A written field type that solves to the `none` atom alone refuses at the check (DS2042, the field's own span) while the conversion seam (`path_expr`) carries the predeclared none atom like every other none seam: before the door, `x: none` and `x: t | none` (and a `t | none` case-payload slot) all dropped out of the universe atom silently — none has no def, so both namespace lookups miss — and the miss surfaced as DS4009's callable-or-foreign sentence at lowering; a none-headed type application (`none[int]`) hears the tag's own DS2040 refusal instead of dropping.
- A field-terminated place store releases the replaced leaf's counts ahead of the store threads (`store_over` over the leaf's count words, the compound branch's own included) before the answer widens in, so the incoming count is the slot's only live claim; the plain store spelling missed the rollover and leaked the replaced object through a clean check, the mut-window member call answering the receiver's own word the spelling that surfaced it.
- A field read's place keys on the checked type's shape, never the raw field width: a one-word struct-typed field still reads as its span, so a width-keyed `PlaceShape::Word` mis-addresses its consumers. A struct field's span and its checked reads' shape come from one member walk, the union case from the written union-of-atoms sorted like the interned solved set.
- A list object's element stride is 0 iff the payload is empty while the checker holds one element type per list value, so the lowerer refuses a stride mismatch, a wider-element copy, or a combinator call before the VM sees it; a checked read's span width is bounds-checked at the overlay write.
- An element-slot argument (`list_push`/`map_set`/`chan_send`) must feed the channel's element type to the direct staging paths as the position's parameter type: the fast paths key on a parameter's scalar kind, and a bare scalar literal into a union element otherwise stages one word where the stride needs the member's whole region — the first such send silently fixes a wrong stride and a later wider element traps `ElementStride` behind a clean `ds check`. A list literal feeds its own checked element type the same way: a bare member item re-spans into the union's whole tag-plus-region span before its push, or the first push fixes the stride at one word and the fetch's tag test reads the member's payload word as the tag.
- An equality chain dispatches on the left operand's shape alone, so refuse mixed multi-atom spellings at the chain's top instead of falling through to representation-named mismatches. A membership compare over a multi-word element decs the gathered counts straight-line before the chain's per-word borrows, so a fail-fast mismatch never strands a later field's count.
- A fail-fast region (the equality chain's per-word compares) must not site a dying operand's dec at its own word's compare, since the mismatch jump skips every later compare with its release: the compares borrow, and the release sits where every exit merges.
- An entry frame ending in a native call leaves its staged counts (the root frame's tail-native abandon, an accepted leak class), so a heap-drain assertion needs the entry's final expression pure: a value expression drains and a trailing `println` does not.
- A u8-indexed space caps at 256 (indices 0-255), so a width check spelled `> u8::MAX` refuses a need of 256 under a 256-slot name: frame-width checks read `MAX_FRAME_SLOTS` (the encode/decode authority), while staged-span guards keep `u8::MAX` because nargs and capture counts are u8 counts, not indices.
- A deinit-carrying value stored as a struct field type refuses at the shape layer: the pinned-transfer rule assumes a claimed base word's copy is the consuming move, while a struct-literal field write is a borrow at the checker's facts.
- A `Callee::Evidence` site (a nested runtime-resolved dispatch) has no lowering-time width guard (`expected_param_words` answers None there), so a mis-staged argument span surfaces as a VM slide-validation trap.
- Parameter modes are definition-site facts the calling convention never widens: `mut` stages a borrow plus the var re-store machinery, `move` is the consuming hand-off whose count and deinit claim ride in; `comptime` parameters, `mut` over a type variable, and a mode on an inlined handler refuse.
- A generic callee's demands collect into the calling frame keyed by the variable the site's per-call record names — the same key the staging peels; a solved bound stages constants. A trait default body dispatches over the trait's own `Self`, and its chains key by the called member's own serving body, or a nested call re-serves the entered member and loops.
- A missing per-call bounds entry splits by cause: a `None`-served bound is the runtime form, staged from this frame's own evidence slots, while an entry absent because the entering branch's head never mentions the variable marks dead code, so the site stages a dead sentinel whose read traps loudly.
- The unit value is one canonical frame word whose single `Kimm 0` splices at the frame top in `finalize` and dominates every later read, so no site writes it again: a first use inside a branch arm must not own the only write, and a loop head bound at stream position 0 must not pick it up per back edge.
- The direct scalar store writes the var's own word (a literal init, an assignment, a compound assignment, a computed scalar's data op with the destination as dst), the VM reading both operands before writing; Ref words and concat results stay temp-mediated. The scalar destination offer is taken by the outermost arithmetic binary alone, and the producer gate (`arith_shape`) and the consumer must list one operator set.
- A call's scalar arguments write their overlay words directly only inside the staging contract's bounds: a literal's load emits at the moves position, and a computed scalar needs every later argument to evaluate without touching the overlay.
- A synthesized generic-native CALLG stages one evidence word per `GenericNative::evidence` behind its real arguments and reserves the same count at its overlay site: a hand-staged single instance word under-reserves a two-parameter generic (`map_get`), and the dispatch's riders then overrun every frame whose widest call site is that one, while a wider sibling call in the same function masks it. The place-chain read paid this for the map nesting until a minimal function trapped `StagingTooSmall`.
- A checked read's miss payload is the probe (the index, the key): copy the payload only behind the tag test, or a missing key lands the key's word in the element temp under a count the read never handed out (a silent wrong insert, an over-release) — the miss arm halts instead, a list through its own store's index trap and a map through the bare trap primitive, since its store would insert.
- Every synthesized node of a derive mints its span from the shared per-item Mint, the member fn declaration included — two families named by one attribute once shared its span, so the span-keyed `impl_fn_rets` kept the later family's return alone. The Mint skips the attributed declaration's written identifier and type spans, since the resolver records one name use per span. Pattern paths are name uses too: the `show` family's enum arms were the mint holdout, reusing the written case spans for their patterns; every synthesized pattern path mints now (the `case_pattern` discipline), keeping one span to one semantic role — the reuse checked clean once the checker's case doors landed, so the mint is contract, never the blocker.
- A synthesized bare-`none` match arm must be a binding pattern (the checker's arm tag reads the builtin none from one), never a path pattern: a `Pattern::Path` `none` is an item reference and refuses as an unknown pattern.
- An optional's presence-branch spelling decides lowering: an empty-then `if x is none { } else { <mutate a var> }` followed by a member-tail read of that var refuses at lowering (DS4009, the checked type and runtime word disagree), while the match spelling lowers (`match x { none => { } n => { ...n... } }`, the catchall binder binding the inner type as its own fresh word). The narrow composes at every binder shape: the for-bound element over a union-element list, the optional payload field's binder, a tuple-payload item, and a json decode walk's per-element read. A decode-side optional element read keeps the raw `get` answer: the required element's `unwrap_or(seed)` refinement destroys the `none` side the narrow's bare-none arm tests.
- A staged word's count hand-off must cover the frame's type-variable word, not just Ref words: a type variable stages as `Raw` and may hold a counted Ref at runtime, so CALLS staging it with no hand-off leaks that Ref into a Ref-claiming body's exit dec.
- Every invocation of a lowered ONE body runs its own nursery, so a transitive golden over a spawning body counts the inner invocations' output too.
- A value-position join never widens a diverged arm's handed-back place: the arm's own exit stands in for the join, so the widen (and the fn-word answer check) is skipped at every join site.
- A written generic union head keys its members by the variable's atoms while every entering site carries the substituted concrete value, so a lookup at a widening or staging site resolves through the structural mate (a heap application by constructor, a tuple by arity with recursively matched elements, exactly one match or the honest refusal), and the tag writes the member entry's minted id.
- A claim's establishment band is runtime state the placement must mirror: an intra-frame transfer (a var's slot re-stored by an assignment, a binder's widen) moves the claim while spending the band word, so the moved site's re-registration must re-set it, and a slot already anchoring a claim adopts its own band word back — without the re-set the frame's final content never fires its deinit.
- The plan's function-table order is an append-stability contract for growing modules: each struct's deinit plans right after its own item, so a new declaration appends after every earlier entry and the ambient's records stay the plan's contiguous prefix. A declaration inserted before entries a live frame calls by index still shifts them and the swap refuses; `main` shifts freely.
- A value block's tail read of a local binder answers the binder's own words while the block's scope end runs before any consumer exists, so the tail read stages the answer's words past the scope pop (`const ys = { var xs = [1, 2]; xs }`), or the scope releases the answer's counts before the consumer claims them (`UnknownObject` behind a clean check). A frame tail is safe only because its exit clears the map.
- A checked native answering `t | none` needs the call's union to claim a payload region, and a union member that is a unit tag outside the shared primitive word table claims none, so the two-word span return traps at the caller's one-slot staging behind a clean check. A width-shaped atom a native answers or accepts over therefore names itself in the shared table's rows first (as `u32` did riding the I64 slot like `byte` [F6]).
- The primitive and heap-container word vocabularies live once, in ds-check's linked-surface module (`primitive_word`/`heap_ref`): the linked fact walk and the lowerer's shape layer read the same rows, the shape layer deriving each row's frame slot from its word (an exhaustive match on the word, never a second name table) and the builtin-instance mapping keying on the same words. Before the table a widened primitive updated one side alone — a `u32`-typed exported field refused at the linked fact walk while the shape layer knew the word — so any new word vocabulary lands in one shared table every consumer crate reads, or the drift returns.
- Every link-fact kind that mints an atom must ride the `.dsi` mint log with its own `MintData` form at the log's tail beside the struct and unit-case kinds; the install's fallback (`decls.atoms.get`) takes the replayed atom.
- The lowerer reads every expression's checked type by span (`expr_types`), so a checker seam that answers an operand without walking it (the negated-integer-literal fold) must record the operand's solved type at its own span, or the lowering answers `no checked type` behind a clean check.
- The `.err` handler's checked result is the kept side unioned with the handler's own answer (the `map_err` contract `fn(e) -> e2` answering `t | e2`), never the kept side alone: a handler answering a member the receiver never carried writes its answer word into a result slot the remainder typed, so the firing arm traps at runtime behind a clean check. An answer that never solves at the site (a generic extern whose return variable nothing feeds, the `die` idiom) contributes no member — a minted variable's atom name is the only `$` a solved set can carry, surface names cannot spell it.
- A single-member scrutinee's span holds the member's own words (no tag word exists), so a lone unguarded arm naming the sole member destructures directly: the payload binders bind at the member's own offsets when the span is the member's and at the place union's region offsets when the scrutinee refined out of a wider span, while every other member-test spelling (a later arm, a tested payload sub-pattern) keeps the no-tags refusal.
- An extraction answer that is the result's only writer — an unannotated `.err`/`.ok` handler consuming every receiver member — must survive the branch reconcile as such: the fall-through arm is dead code and joins as diverged, or its result-less state intersects the answer out of the keep set and the join epilogue frees the handler's answer object before any consumer reads it.
- The nursery block's clean-join channel registers its delivered list's ownership only at the join point, after the failure paths' `rc` restore: the boundary's fail arms exit the frame from the pre-channel state, so any word only one branch of a fail/clean fork owns registers after the fork's label, never before the branches.
- A spawned child's plan return is its body's answer type, not the spawn expression's unit: the frame's exit shapes the answer the join collects, and a body that only cancels keeps the unit return (its exit is unreachable). A `~Copyable` answer refuses at the spawn site like a list literal element — the collected list's edge retention owns counts, never claims, so the hook has no drop position inside the channel.
- A per-member dispatch whose arms sit between the dispatch and a shared tail must jump over the arms on the no-match fall-through: the fall-through of a tag-dispatch chain is the LAST arm only when the arms are emitted last-class-first like the classed native re-span, and a shared tail below the arms needs its own landing label.
- A local declaration named `none` (an enum case, a struct) poisons the whole compile unit, not just its own file: every ambient `none` spelling (`t | none` annotations, `is none` tests, bare `none` values) resolves onto the declaration through the package namespace, so a private declaration trips the cross-file visibility refusal and a `pub` one silently re-types every ambient `none` site. The linked surface rides the same rule: a dep member declaring a `none`-cased enum fails its own compile before any consumer sees it.
- A call the checker re-routes at the type layer (the F3 free-tier receiver fallback) keeps its resolve-time `DotRes::Free` record, so the lowerer must consult the call span's dispatch record (`inherent_calls`/`trait_calls`) before feeding the free fn: the record, not the resolution tier, is the lowering's authority, or `xs.concat(ys)` lowers the free string `concat` over two Ref words and traps.
- A migrated face's linked bindings split by return shape: the import validation's @std equivalence arm (`word_shaped_ambient_atom`) admits only bare scalar-word heads with no type arguments, so a member returning `t | none` (a tag seam) or `list[string]` (a generic head) refuses at the linked import with DS4021 while the same name serves bare through every entry face. Pin the bindable subset per shape when a face migrates.
- An ambient-composed body cannot mint lowering-time function records: every `spawn` expression mints a child record (`push_spawn`, named `parent$index` by the plan's own length at the push), and a lambda handed to a CALLG native (`map`/`filter`/`reduce`) mints a walk-time function record, while the dsmod splice byte-pins the ambient's plan-time prefix (items plus deinits) alone — such a body drifts the serve, and the splice silently falls back (`spliced 0`) with every artifact gate green. The bodied members that splice mint nothing at walk time, which is why a lambda-bearing combinator (`take`/`drop`/`flat_map`) runs as a user-file fn but composes into no ambient reading until the lowering-time-ambient-records seam lands (item 74).
- A generic body's element-carrying seams refuse at lowering, three spellings of one fact — the placement needs the runtime word kind the variable hides: a `var` binding over the type variable, a member `push` or `cons` call staging a bare element, and an indexed or `first` read answering a union member over the variable. The composing shapes lower: a tuple over the variable (a static span), the `map`/`filter`/`reduce` natives, and the `concat` member over a one-element literal. An `if` guarding a type-variable-carrying write refuses at the branch reconcile while the catchall-match spelling lowers, so a guarded write inside a generic body is a match arm, never an `if` body.
- A link-fact vocabulary widening mirrors the local spelling's own refusal tiers, never the trap family: a tuple member that is not one plain frame word (a Named struct, a nested tuple, a union or optional element) crosses the encoding for identity with a local declaration and refuses at the consumer's own lowering, while a bare unit-typed member and the empty tuple refuse at the walk itself — the item-103 trap seam (a unit word inside a compound field) never rides a fact.
- The predeclared `none` atom's tag id is the platform's own discriminant, never a module-local first-use id and never a tag-table row: a module-local assignment would make every `t | none` union's absent side carry a different immediate per module, so an optional field crossing a module boundary falls into the present arm behind a clean check. The linked tag-row seeding cannot cover this atom (a row keys only a linked-fact mint, and `none` resolves to the ambient's atom in every compile); any future predeclared atom riding union words follows the same platform-discriminant rule.
- A linked struct's install must declare its atom ahead of resolving its fields, and a Named word's resolution resolves through the link table (the registration's rows), never the consuming namespace: the installs run in def order, so a field naming a later-declared type of the same member (or the struct's own self-reference through a container word) resolves only through the forced install. The producer side co-derives through one shrinking fixpoint over the member's type defs, since eligibility is the referenced declaration's own fact.
- A written field naming a linked type must force the linked install forward at the shape pass, resolving the name through the foreign table (the local type namespace never holds the link pass's registrations): without the force the field drops out of its declaration's universe atom silently, and the module crosses an empty layout the consumer constructs. The first written reference forces the install; the late mint loop re-installs idempotently.
- A union match's catchall binder over a scrutinee whose place is the union's own tag word alone (an enum payload binder, a struct-pattern field over an optional type) binds the union's whole span at that word: the field's span is the union's own words, so the use path's member-fields re-span reads the payload region, while the bare tag word would stage the tag as the member's payload.
- A narrowed binder keeps the wider union's physical layout, so an equal checked type at a call site is not an in-place move: compare the word lists, never the types alone. A multi-word payload interleaving the wider region differently stages the operand's words over a parameter span the callee never laid out — the member-dispatch re-span must fire keyed on the word-list disagreement (keying it on the place's underlying type alone redundantly re-spans the no-words case and drifts the frame-cap pin's measured width).
- A synthesized tree may not clone a written declaration's type nodes with their spans, even for a bound the declaration already spelled: resolution records one name use per span, so the clone trips the sorted-uses duplicate assert — every copied node rides the structure-only minted copy (`minted_type`), which is why `impl_item`'s written-bound intersection mints its left arm.
- A param bound's trait evidence is read at three sites (body generics, the call site's assumption pushes, the call-bound staging records), and each must walk an intersection's arms: a single trait-path read leaves an intersect-bounded variable with no evidence, so the body's dispatch fails DS2013 behind a clean head — `bound_traits` is the shared walk, and any new bound-reading site joins it.
- A dep-side const evaluation site plans a data const's initializer as a module function under the const's own def, so the plan's index answers the def: without an explicit guard the value-use arm mints a FuncRef word for it, and a comptime body naming the const (a use the unplanned spelling always refused at the slice) would silently miscompile — a planned const keeps the top-level value refusal at the FuncRef arm, the guard living beside the mint, never at the plan.

- A link-fact kind the link pass collects per import declaration must dedup on the facts that determine it, never on rebased spans: two surface builds of one package rebase the same impl row differently (each build adds its own member files), so a span-sensitive equality lets the duplicate through and the declaration pass declares the same instance twice — coherence refusing the package against itself. The impl row's identity is the owning module, the trait, the head, and the member rows; the span rides diagnostics alone.
- A consumer's local impl of a minted trait shapes ahead of the trait's late mint loop, and the link pass's foreign defs ride no `type_names` row: the impl's instance declaration must resolve the trait through the link table (`foreign_type_def`) and force the mint forward when the row is missing, or the impl declares no instance and every dispatch fails DS2013 behind a clean import. The trait's own install is idempotent on `decls.traits`, the same replay-convergent rule a forced struct mint takes.
- A linked trait default body is a frame contract, not just a link: the consumer's dispatch must classify the receiver's staged word Raw (the `Self` variable's formal) and keep the local one-word instantiation boundary (a multi-word head into a default body refuses at the site, never traps), and a body the producer's plan gave any evidence demand can never cross — the evidence chains name module-local bodies, so the producer's own walk refuses it (DS2044) before any surface serves a trap.
- A linked member's registered signature rides `decls.members` keyed by its method id, never a def whose fn type the free-fn seam reads, so the call-site staging (the widening re-span, the width guard) reads the checker's per-site solved record (`member_call_params`): before it, a multi-word member parameter staged a bare-member or literal argument as one word behind a clean check and the dispatch trapped at the slide. The direct staging paths must consult the callee's expected word kinds exactly like the moved-word path — a literal or computed scalar whose formal declares Raw (a default body's `Self` receiver) records the wildcard or the ABI slide refuses the pairing in a frame whose overlay slot no other site mixes (the one green default-body site passed only by the accidental I64/Bool mix folding its receiver slot Raw).
- A park's fill needs the served prefix, not the park's presence: a park beside a base-tier package stays unfilled, or the first compile parks its own (empty) prefix once and every later serve installs that empty base — the prefix's names land in neither name tier and the lookups miss.
