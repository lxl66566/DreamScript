# Lowering invariants

- Union payloads share one region per union type: a member claims the lowest free word of its kind, and a constructed member zero-writes its dead payload words. A dead payload word declared `Raw` fails the call slide, which validates staged words against the typed callee parameters.
- A union-typed parameter stages its whole region at the call, its checked member or sub-union re-spanned through an anonymous staging temp; a deinit-carrying member refuses there, the temp carrying no claim contract. Returns re-span per member; never return an operand's raw span directly.
- float `%` refuses at the lowering boundary (the locked uop set has `ModI64` only), and `list_new`'s zero-arg call still needs a one-word overlay area.
- The wrap arms pass `arith_dst` the same `DataOp` as both the int and the float parameter, so a float operand reaching the arm would mis-lower its f64 word as i64 with no trap: the checker's [B7] rule refuses float wrap operands first, and `reject_float_wrap` before `arith_dst` is the lowerer's own guard — a wrap arm added without it turns a checked refusal into silent corruption.
- Scalar `var` places are `PlaceShape::Word`; `u32 + int` surfaces DS2001 because no conversion callable exists yet, and the B7 message's `u32(x)` suggestion is unimplemented.
- A fn-typed struct field never reaches a literal's provenance guard: the checker's universe shape drops field types the core cannot express (`conv_expr` answers None), so the planned struct carries no such field and the literal's field lookup misses, the refusal naming the dropped-field seam at the field's own span; a guard written for the field slot is dead code.
- Every place-table write inside a linearity body walk goes through `set_state`, which records the undo entry: a direct `state.insert` in a new surface form rewinds past its own write and the branch isolation stops being exact, the `item()` entry asserting no open snapshot region.
- Generic callees route through `GENERIC_NATIVES` and CALLG, since name-routing a monomorphic body miscompiles receivers; tail calls to routed generic natives stay CALLTG-reserved.
- A generic inherent impl's member body claims its evidence words as trailing parameters: the entering site stages the per-pair chain words after the arguments and CALL/CALLT names the full staged count, so the trait spelling's CALLG path never applies.
- Stage a tail call's exit deinit claims before its argument Movs, or a claim's overlay window clobbers the staged span: a Ref-expecting callee traps on a staged/expected mismatch, an i64-expecting callee silently receives garbage.
- A construct re-executing its head forks the placement map before the head (`rc.save` plus `loop_enter`); a Ref cond operand born outside the loop is loop-carried, its count dying at the owning scope's end, and anonymous carried operands sweep through `drop_unnamed` at the exit. A Ref-reading head must fork first, or its read-dec re-fires per back edge and frees the object after the first iteration.
- Every loop registers exit and backedge labels below its body scope (`LoopCtx`), and `break`/`continue` drop the body scope's binders inward at the jump from a read-only snapshot (`loop_exit_drops`), so each path fires each deinit claim once while the fall-through keeps its scope-pop drops; an exit inside a lambda or spawned body refuses at the checker's frame boundary.
- A bare identifier in a match test position resolves through the type namespace first, a hit binding nothing; keep it aligned across resolve `arm_tag`, type_of `unit_pattern_atom`, and ds-lower `binding_atom`, tuple elements included.
- Never name-find over positional slots: a tuple member's `None`-name fields all compare equal, so a `find` by name returns the first field. Walk ordered (`ordered_field_srcs`) and resolve per-element binding through `word_addrs`, not `place.base + field.word`.
- Accept a catchall-free match only when no arm can fail (union tag tests cover the dispatch); a value-level chain with literal tests or guards refuses without one unguarded catchall arm.
- A non-union or-arm lowers as an alternative ladder and binds through its last alternative: the alternatives must bind the same names on the same words, so a same-name-different-word alternative refuses at lowering while the checker compares name sets only. A catchall alternative makes the whole arm a catchall.
- A non-union match chain runs every arm's tests and guard in order on the fall-through path, snapshots the post-guard state per arm, and the join's reconcile absorbs the heterogeneous states (a count one guard ate stays eaten on later paths, a count no reached guard ate decs at its own arm's jump).
- A guarded arm over a Ref-carrying scrutinee binds its binder a word-for-word copy inc'd at the section top before its tests, so every path incs what its decs will eat; a guard taking the scrutinee's own Ref count refuses, and a read-only guard runs when the count's death sits past the chain.
- A union match's slides re-enter shared dispatch code emitted over one base state, so a jumping path must arrive base-equivalent: the guard's failure edge drops the section's transients (the binder copy's outstanding words) at its cleanup label before the jump, and a guard taking any count the base state holds refuses. The guard runs after the member tests, whose failure edge is borrow reads; its union form reaches the lowerer only through an aliased binding.
- Bind every union match arm's dispatch entry before any slide targets it, and let a catchall intercept the chain at its own position: an unbound catchall entry sent the slide to `usize::MAX` (an assembler add-overflow panic), and skipping mid-position catchalls let the last one win (`n => 1, _ => 2` ran the second arm). A non-last catchall emits an intercepting jump to its own section, so arm order picks the winner.
- An `is` test over a written type other than a nominal single-segment path lowers through the checker's solved test recorded by the test expression's span (`Checked::is_tests`): a multi-atom solution joins one per-atom TAG_TEST by jumps, a covering set folds true, a disjoint one folds false, and a type variable on either side refuses naming runtime reflection.
- A span claim folds its span's plain count words and decs every `Ref` word behind the hook, so a folded word never dies on its own; a field-read copy of a folded word borrows (an inc), the claim keeping its count.
- An equality chain dispatches on the left operand's shape alone, so a mixed multi-atom spelling falls through to representation-named mismatches ("a tag word read", "a span equality's width"); refuse mixed shapes at the chain's top naming the narrowing seam, and mirror the working mixed form (a unit-tag value, tagged on both sides).
- A list object's element stride is 0 iff the payload is empty while the checker holds one element type per list value: a stride mismatch or wider-element copy or combinator call reaching the VM names hand-assembled code, so the lowerer refuses those shapes first, the generic dispatch's one-word instantiation boundary included. A checked read's span width is bounds-checked at the overlay write.
- A membership compare over a multi-word element decs the gathered element's counts straight-line before the structural equality chain, whose EqStr reads are borrows; a fail-fast field mismatch jumps past later fields' reads, so a later field's death may not ride its read. The one-word spellings keep their exact prior emission (the count dies at the comparison read), since a pre-discard would break the corpus hash gate.
- An entry frame ending in a native call leaves its staged counts (the root frame's tail-native abandon, an accepted leak class), so a heap-drain assertion needs the entry's final expression pure: a value expression drains, a trailing `println` does not.
- A deinit-carrying value stored as a struct field type refuses at the shape layer: the pinned-transfer rule assumes a copy of a claimed base word is the consuming move, but a struct-literal field write is a borrow at the checker's facts, so the transfer steals the claim and the hook later reads a freed object (`reference names no heap object` inside the deinit call). Per-span deinit claims own the seam.
- A `Callee::Evidence` site (a nested runtime-resolved dispatch) has no lowering-time width guard, since `expected_param_words` answers None there, so a mis-staged argument span surfaces as a VM slide-validation trap; an omitted defaulted parameter there staged no word until the trait's declared default began staging (F7).
- Parameter modes are definition-site facts the calling convention never widens: `mut` stages a borrow plus the var re-store machinery, and `move` is the consuming hand-off, so the count and any deinit claim ride in (`staged_move`) and its bind-time claim fires the hook once; a consuming tail transfer never fires the caller's claim, the borrow tail does. Refuse `comptime` parameters, `mut` over a type variable, a deinit-carrying argument behind a callable word, and a mode on an inlined handler parameter; a deinit tail argument refuses unless its parameter consumes.
- A trait's declared default body is a dispatch target over the trait's own `Self`: its `Self`-keyed evidence demand is answered by the entering site's own solved instance (no `Self` entry in the per-call bounds record), the tail chain starts at the receiver's member set rather than through `evidence_step` over the instance's bounds, and the chain's step keys the serving body's own demand variable rather than the entered pair's, which names `Self` and matches no impl's conditions. The `free_generic` plan flag is shared with free fns, so the free-fn evidence branch must exclude dispatch targets.
- A generic callee's own demands collect into the calling frame keyed by the frame variable the site's per-call record names: a `None`-served bound (only an in-scope assumption covers it, so the substitution is the frame's own) peels the free record's solved type or the inherent site's receiver type — the same peel the staging's slot lookup runs, so the walk's key and the lookup's key cannot drift; a solved bound stages constants at the site and collects nothing, a trait dispatch callee collects nothing (its entering site's chain object serves the transitive level), and the package-wide table iterates to a fixpoint because a callee's demands may themselves carry callee demands. A free generic fn's variable parameter stages its argument's word as `Raw` at the site (the wildcard's mirror): the ABI slide admits a Raw staged word against any parameter but rejects a scalar against the Raw parameter, so an overlay index no other type visits must record Raw deliberately, never by the frame's incidental type union.
- The trailing block is pure sugar: it appends to the call's argument expressions at the next open positional slot, so the module is byte-identical to the parenthesized spelling.
- The unit value is one canonical frame word: its single `Kimm 0` splices at the frame top in `finalize`, dominating every later read (a first use inside a branch arm must not own the only write — another arm's path would read the recycled frame's garbage — and a loop head bound at stream position 0 must not pick the store up per back edge), and no site writes the word afterwards. A unit-typed value join (`if`/`match` over `()`) takes the canonical word as its result place, so each arm's widen degenerates to the in-place no-op; never re-materialize a fresh unit temp per use.
- The direct scalar store writes the var's own word: a scalar (I64/F64) var's literal init, a literal assignment, a compound assignment, and a plain assignment of a computed scalar emit the constant load or the data op with the destination word as dst — the VM reads both operands before writing dst, so the word safely aliases its own read, and the store-over ordering is untouched because scalar words carry no counts. Ref words and concat results must stay temp-mediated: a Ref's replaced count decs before the re-store's Mov overwrites the word.
- The scalar destination offer is taken by the outermost arithmetic binary alone, never by an operand, a branch arm, or a nested call: `binary_value` takes the offer before operand evaluation and restores it on decline, so the offering site (the assignment store or a call's argument staging) reads consumption back as the field clearing, and an expression whose top node is not an arithmetic binary keeps the temp. A data op consumes the offer only when its result slot matches the destination's own kind, and `emit_data`'s fresh temp is the single-use proof: the offered word is born at the consuming op with exactly one consumer. The producer gate (`arith_shape`) and the consumer match must list the same operator set: the wrap trio reached the consumer but not the gate, so a plain wrap assignment silently kept the temp + re-store while the round's claim said the offer worked — a direct-write claim needs its plan-level pin (the aliased op over the var word, no re-store Mov), never a value assertion alone.
- A call's scalar arguments write their overlay words directly only inside the staging contract's bounds: a literal scalar's constant load emits at the moves position (after every argument's evaluation, so a later argument's nested call cannot clobber it), a computed scalar needs every later argument to evaluate without touching the overlay (plain paths, literals, projections — a later argument's nested call stages over the word first), and a tail transfer keeps the evaluated temp plus its Mov because the exit claims stage through the overlay over the arguments. The frame's layout still types each overlay word from the staged list, and the VM's slot-kind check reads that type, so a directly written word stages its own kind like the Mov spelling did.
- Every synthesized node of a derive mints its span from the shared per-item Mint, the member fn declaration and its name included: two implemented families named by one attribute each synthesize a member fn, and before the fn declarations minted, both carried the attribute's own span, so the span-keyed `impl_fn_rets` kept only the later family's return — the earlier body planned with the wrong return and trapped at runtime behind a clean check (a per-family green test and the two-attribute spelling never see the collision, which is why it survived the family pinning). The Mint's budget grows with the square of the attributed item's length while a derivation mints only a few spans per part, so minting the fn declarations never exhausts it; any span-keyed table a future synthesized node feeds must draw its key from the same mint.
- A struct field's span and its checked reads' shape must come from the same member walk: a union-typed field's words are built from a read-only evaluation of the written union-of-atoms (sorted like the interned solved set, `None` for sides needing solving), and the literal store re-spans a member value into the field's region through tag/zero/write — a layout keyed by any other order or any solving-time mint would misplace the member's claimed payload words while still checking clean. The union arm threads the depth budget through `union_shape` (a struct nesting through a union back into itself would otherwise pin the depth and recurse forever), and a wider union value refuses at the field (narrow first) where the annotated-binding widen still tag-dispatches.
- A staged word's count hand-off must cover the frame's own type-variable word, not just Ref words: a type variable stages its single word as `Raw` (the wildcard ABI), and at runtime it may hold a counted Ref — CALLS staging it with no hand-off let the runtime Ref leak into a Ref-claiming body's exit dec and free a live object. The rc inc/dec pair over such words checks the runtime kind, so recording the hand-off blind is safe — a scalar instantiation is a no-op.
- Every invocation of a lowered ONE body runs its own nursery: a transitive golden over a spawning body counts the inner invocations' spawned output too (the `[[1]].show()` run prints one spawn line per nested invocation before the outer answer), so a golden written from the outer spelling alone mis-pins.
- The dsmod blocks payload version gates the chain table: version 2 appends the module-level evidence-chain table after the function records, so a hand-assembled corruption fixture must carry the bumped version byte or the reader rejects the bytes as a version mismatch before the fixture's own corruption is exercised.
- A missing per-call bounds entry splits by cause: a `None`-served bound is the runtime form (this frame's own substitution, staged from its evidence slots), while an entry absent because the entering branch's head never mentions the variable marks dead code — the demanding site sits under a narrowing that branch cannot satisfy (per-branch solving kept no condition for it), so the site stages the dead sentinel, a chain word naming no object whose read traps loudly. Staging a slot word there reads a slot no one filled; refusing there keeps valid int sites out of one-body-per-impl programs; the sentinel word must stay outside the chain table's index space (a negative word, not a reserved entry), or the loader's table validation owns a dead row.
- A default body's demand chains key by the called member's own serving body, never by the entered entry: a `Self`-keyed pair tails into `chain_for` for the member it calls (the memo closing a self-recursive demand onto its own entry), because pointing every tail at the entered chain re-serves the entered member's body for a different member's call — a silent wrong call when the signatures agree, an infinite loop when they nest. A demand over the trait's own generic resolves through the impl behind the entering instance: its trait reference's argument substitutes the variable (concrete arguments name the type and resolve their serving instance directly, impl-variable arguments ride the receiver's binding with the impl's own declared bound as the step — the trait declaring a bound its impl never covers surfaces here as the chain-build refusal, since no other pass checks it), and an argument compound over the impl's variables refuses, the seam resolving per variable alone.
- A written generic union head keys its members by the variable's atom (`int | list[$t]`) while every entering site carries the substituted concrete value, so a member lookup at a widening or staging site resolves through the constructor mate — and only for heap applications, whose one Ref word is argument-independent; the TagNew writes the member entry's own minted tag, never a re-mint of the source atom (a fresh tag would name a member the body's tag tests never dispatch on, a silent wrong dispatch), while a tuple or struct member over the variable keeps its refusal: its claimed word kinds depend on the substitution.
