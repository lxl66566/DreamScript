# Lowering invariants

- A static pass beside the bidirectional check does not run on a compile path because the check does: the run path lowered off the checked bundle, so a moved-then-used script ran behind a clean check and its deinit fired twice. Every compile seam refuses on the affine walk's diagnostics.
- The comptime slice and the runtime module split at `plan_item` on the comptime parameter mode, and the admission pass must agree with the slice's plan: a callee the plan never receives lowers a call the belt refuses with the wrong diagnostic.
- The comptime fence's refusal and its first-hop origin drill read one row predicate (`row_admits`): a drill left on the older pure-only test names a callee the fence itself admits (a trap-only helper) as `the row's first refusing hop`, so every predicate change touches both call sites.
- The reflection table reaches the fenced VM as one snapshot (`set_reflection` before the runs, the guard restoring on drop), so registering a type after the install traps `UnknownInstance` mid-run: register every site's arguments, then install, then run.
- The world fence is the install seam, not a trap: the evaluator's registry serves the package's platform name with an empty provides list, so the slice's install refuses a world FuncRef with `UnprovidedPlatformOp` (DS2033); installing no platform at all or a trapping handler loses that diagnostic.
- A comptime call's embedded answer lowers as the literal a user would write at the call's span, whose checked fact is the call's result type; a `lower` call without the evaluator's map hits the belt refusal there. A list answer's element type comes from the call's fact.
- Union payloads share one region per union type: a member claims the lowest free word of its kind and zero-writes its dead payload words, and a dead payload word declared `Raw` fails the call slide against the typed callee parameters.
- A union-typed parameter stages its whole region at the call, its member or sub-union re-spanned through an anonymous staging temp (a deinit-carrying member refuses there); returns re-span per member, never returning an operand's raw span.
- float `%` refuses at the lowering boundary (the locked uop set has `ModI64` only), and `list_new`'s zero-arg call still needs a one-word overlay area.
- The wrap arms pass `arith_dst` the same `DataOp` for the int and the float parameter, so a float operand would mis-lower its f64 word as i64 with no trap: the checker's [B7] rule refuses float wrap operands first and `reject_float_wrap` before `arith_dst` is the lowerer's own guard.
- Every place-table write inside a linearity body walk goes through `set_state`, which records the undo entry: a direct `state.insert` rewinds past its own write and branch isolation stops being exact.
- A generic inherent impl's member body claims its evidence words as trailing parameters (the entering site stages the per-pair chain words after the arguments and CALL/CALLT names the full count), so the trait spelling's CALLG path never applies.
- Stage a tail call's exit deinit claims before its argument Movs, or the claim's overlay window clobbers the staged span: a Ref-expecting callee traps on a staged/expected mismatch, an i64-expecting one silently receives garbage.
- A short-circuit's second test jumps into its own answer block carrying the post-right-operand ownership state, so that exit carries the full arm's dying drops at its own position: an answer block shared with the left shortcut's decs words the right operand's call already handed to its callee and frees a live object mid-run.
- The frame-reuse tail transfer slides the callee's own answer words onto the caller's caller, so a tail call is sound only while its checked answer equals the declared return: a member or strict sub-union answer needs the return's re-span after the transfer, and no position exists there, so such tails lower in place (value plus return) — a slid member lands its payload word on the union's tag position.
- A construct re-executing its head forks the placement map before the head (`rc.save` plus `loop_enter`), or a Ref-reading head re-fires its read-dec per back edge and frees the object after the first iteration; anonymous carried operands sweep through `drop_unnamed` at the exit.
- Every loop registers exit and backedge labels below its body scope (`LoopCtx`), and `break`/`continue` drop the body scope's binders inward at the jump from a read-only snapshot (`loop_exit_drops`), so each path fires each deinit claim once.
- A bare identifier in a match test position resolves through the type namespace first, a hit binding nothing; keep resolve `arm_tag`, type_of `unit_pattern_atom`, and ds-lower `binding_atom` aligned, tuple elements included.
- Never name-find over positional slots: a tuple member's `None`-name fields all compare equal, so a `find` returns the first field. Walk `ordered_field_srcs` and resolve per-element binding through `word_addrs`.
- Accept a catchall-free match only when no arm can fail (union tag tests cover the dispatch); a value-level chain with literal tests or guards refuses without one unguarded catchall arm.
- A non-union or-arm lowers as an alternative ladder binding through its last alternative, so alternatives must bind the same names on the same words: a same-name-different-word alternative refuses at lowering while the checker compares name sets only.
- A non-union match chain runs every arm's tests and guard in order on the fall-through path and snapshots the post-guard state per arm, its join reconciling heterogeneous states (a count one guard ate stays eaten later, a count no reached guard ate decs at its own arm's jump).
- A guarded arm over a Ref-carrying scrutinee binds a word-for-word copy inc'd at the section top before its tests, so every path incs what its decs will eat; a guard taking the scrutinee's own count refuses, and a read-only guard runs when the count's death sits past the chain.
- A union match's slides re-enter shared dispatch code emitted over one base state, so a jumping path must arrive base-equivalent: the guard's failure edge drops the section's transients at its cleanup label before the jump, and a guard taking any count the base state holds refuses.
- Bind every union match arm's dispatch entry before any slide targets it, and let a catchall intercept at its own position: an unbound catchall entry sent the slide to `usize::MAX` and skipping mid-position catchalls let the last one win (`n => 1, _ => 2` ran the second arm).
- An `is` test over a written type other than a nominal single-segment path lowers through the checker's solved test at the test expression's span (`Checked::is_tests`): a multi-atom solution joins one TAG_TEST per atom, a covering set folds true, a disjoint one false, and a type variable on either side refuses.
- A span claim folds its span's plain count words and decs every `Ref` word behind the hook, so a folded word never dies on its own; a field-read copy of a folded word borrows, the claim keeping its count.
- An equality chain dispatches on the left operand's shape alone, so a mixed multi-atom spelling falls through to representation-named mismatches; refuse mixed shapes at the chain's top and mirror the working mixed form (a unit-tag value, tagged on both sides).
- A field read's place keys on the checked type's shape, never the raw field width: a one-word struct-typed field still reads as its span, so a width-keyed `PlaceShape::Word` mis-addresses every consumer.
- A list object's element stride is 0 iff the payload is empty while the checker holds one element type per list value, so the lowerer refuses a stride mismatch, a wider-element copy, or a combinator call before the VM sees it; a checked read's span width is bounds-checked at the overlay write.
- A membership compare over a multi-word element decs the gathered element's counts straight-line before the structural equality chain, whose per-word reads are borrows, so a fail-fast field mismatch never strands a later field's count.
- A fail-fast region (the equality chain's per-word compares) must not site a dying operand's dec at its own word's compare: the mismatch jump skips every later compare along with its release, leaking the skipped Ref-carrying fields' staged counts. The region's compares borrow and the release sits where every exit of the region merges (the chain's answer join; a union member's payload fail exit re-drops from the fork's own map, since the shared false path also serves tag mismatches that never read the payload).
- An entry frame ending in a native call leaves its staged counts (the root frame's tail-native abandon, an accepted leak class), so a heap-drain assertion needs the entry's final expression pure: a value expression drains, a trailing `println` does not.
- A deinit-carrying value stored as a struct field type refuses at the shape layer: the pinned-transfer rule assumes a copy of a claimed base word is the consuming move, but a struct-literal field write is a borrow at the checker's facts, so the transfer steals the claim and the hook reads a freed object.
- A `Callee::Evidence` site (a nested runtime-resolved dispatch) has no lowering-time width guard, since `expected_param_words` answers None there, so a mis-staged argument span surfaces as a VM slide-validation trap.
- Parameter modes are definition-site facts the calling convention never widens: `mut` stages a borrow plus the var re-store machinery, `move` is the consuming hand-off whose count and deinit claim ride in. Refuse `comptime` parameters, `mut` over a type variable, and a mode on an inlined handler.
- A trait default body is a dispatch target over the trait's own `Self`: the entering site's solved instance answers its `Self`-keyed evidence demand, the tail chain starts at the receiver's member set, and the step keys the serving body's own demand variable; the `free_generic` flag is shared with free fns.
- A generic callee's demands collect into the calling frame keyed by the variable the site's per-call record names, the same key the staging's slot lookup peels, so the two cannot drift; a solved bound stages constants, a trait dispatch collects nothing, and the table iterates to a fixpoint.
- The unit value is one canonical frame word whose single `Kimm 0` splices at the frame top in `finalize` and dominates every later read, so no site writes it again: a first use inside a branch arm must not own the only write, a loop head bound at stream position 0 must not pick it up per back edge.
- The direct scalar store writes the var's own word (a literal init, an assignment, a compound assignment, a computed scalar's data op with the destination as dst), the VM reading both operands before writing; Ref words and concat results stay temp-mediated.
- The scalar destination offer is taken by the outermost arithmetic binary alone, never by an operand, a branch arm, or a nested call, and `emit_data`'s fresh temp proves single use. The producer gate (`arith_shape`) and the consumer match must list the same operator set, which the wrap trio did not: it reached the consumer but not the gate, silently keeping the temp and the re-store.
- A call's scalar arguments write their overlay words directly only inside the staging contract's bounds: a literal's constant load emits at the moves position, and a computed scalar needs every later argument to evaluate without touching the overlay.
- Every synthesized node of a derive mints its span from the shared per-item Mint, the member fn declaration included: two families named by one attribute once shared its span, so the span-keyed `impl_fn_rets` kept only the later family's return and the earlier body trapped at runtime behind a clean check. A type a synthesized expression carries (a fn-type carrier's payload) takes the minted structure-only copy too — the resolver records one name use per span and debug-asserts uniqueness, so a written-span clone panics resolution. The declaration's own bytes are not span-free either: a written type name records a use at its identifier's span, so a minted span equal to a written one keys two resolutions into one span (the debug build asserts, a release build cross-wires them) — the from_json walk minted enough spans inside one declaration to make the collision real, and the Mint now skips the attributed declaration's written identifier and type spans. A synthesized bare-`none` match arm must be a binding pattern (the checker's arm tag reads the builtin none from one), never a path pattern — a `Pattern::Path` `none` is an item reference and refuses as an unknown pattern.
- An optional's presence-branch spelling decides lowering, not just checking: an empty-then `if x is none { } else { <mutate a var> }` followed by a member-tail expression reading that var checks clean but refuses at lowering (DS4009, the value's checked type and runtime word disagree), while the match spelling — `match x { none => { } n => { ...n... } }`, the catchall binder binding the inner type as its own fresh word — lowers. Even the match spelling traps at two pre-existing seams: an optional field inside an enum struct payload (the payload-bound member dispatch reads the word as Tag) and a word-union list element (`list[int?]`'s element stride holds the raw payload), so a derived encode refuses both at the attribute.
- A struct field's span and its checked reads' shape must come from the same member walk, the union case from a read-only evaluation of the written union-of-atoms sorted like the interned solved set: a layout keyed otherwise misplaces the payload words while still checking clean.
- A staged word's count hand-off must cover the frame's type-variable word, not just Ref words: a type variable stages as `Raw` and may hold a counted Ref at runtime, so CALLS staging it with no hand-off let the Ref leak into a Ref-claiming body's exit dec.
- Every invocation of a lowered ONE body runs its own nursery, so a transitive golden over a spawning body counts the inner invocations' spawned output too; a golden written from the outer spelling alone mis-pins.
- A missing per-call bounds entry splits by cause: a `None`-served bound is the runtime form (this frame's own substitution, staged from its evidence slots), while an entry absent because the entering branch's head never mentions the variable marks dead code, so the site stages a dead sentinel whose read traps loudly.
- A default body's demand chains key by the called member's own serving body, never the entered entry: pointing every tail at the entered chain re-serves the entered member's body for a different member's call, a silent wrong call when the signatures agree and an infinite loop when they nest.
- A value-position join (an if/match arm writing its result span) never widens a diverged arm's handed-back place: an arm that exited the frame answers with the exit's dead answer, and widening it emitted unreachable code over a mismatched shape — a statement if's early-exit arm beside a struct-valued sibling once refused the whole lowering with a representation mismatch. The arm's own exit stands in for the join; skip the widen (and the fn-word answer check) for a diverged arm at every join site.
- A written generic union head keys its members by the variable's atoms while every entering site carries the substituted concrete value, so a lookup at a widening or staging site resolves through the structural mate (a heap application by constructor alone, a tuple by arity with recursively matched elements, exactly one match or the honest refusal), and the tag writes the member entry's own minted id.
- A union's dead payload words zero-init per word with each word's own kind, the widened field vocabulary putting Tag words inside the region: a dead Tag word zero-inits kind-true because RETSPAN hands the whole span to a caller whose layout types every word.
- A claim's establishment band is runtime state the placement must mirror: an intra-frame transfer (a var's slot re-stored by an assignment or a binder's widen) moves the claim but spends the band word, so the re-registration at the moved site has to re-set it — and a slot already anchoring a claim adopts its own band word back, keeping one band per anchor slot (the directory's drop sites name it). Without the re-set the teardown doors read the claim dead and the frame's final content never fires its deinit, while `ds run` keeps firing it through the ordinary exit drops.
- A callee-kind tail arm must carry its own `tail` guard: a linked package's callee joined the in-place-tail set without one, so every cross-module call emitted CALL plus RET and the body's remainder scrambled to dead code after the first foreign call.
- The plan's function-table order is an append-stability contract for growing modules: the deinit pass once ran before the items, so the REPL's second round (a struct with a deinit after an extern round) head-inserted `file$deinit` and re-keyed every ambient function's index, which the direct-call valve correctly refused once the json face gave the ambient's own bodies intra-module calls. The first fix planned each file's own deinit section after its items, but a per-file section still shifts behind every new item of a growing file — the REPL's declaration round over a deinit-carrying binding refused the swap, the parked row's drop sites naming the moved section by stale index. Each struct's deinit now plans right after its own item: the ambient's records stay the plan's contiguous prefix the splice serves, and a growing file's new declaration appends after every earlier entry (item and deinit alike) instead of shifting them. Residual: a declaration inserted before entries a live frame already calls by index still shifts those entries and the swap refuses; `main` shifts freely since no call site targets it by index.
- A value block's tail read of a local binder answers the binder's own words, and the block's scope end runs before any consumer exists, so the leaving scope once released the answer's counts — and fired a deinit value's claim — before the consumer claimed them, trapping `UnknownObject` at the consumer behind a clean check (`const ys = { var xs = [1, 2]; xs }`, the const alias spelling the same seam); a frame tail is safe only because its exit clears the map first. The tail read now stages the answer's words (tracked words plus the deinit claim's base) past the scope pop, and the consumer's own claim — a binding's alias and its use's death, a call's staging, a join's widen, a frame exit's transfer, an assignment's re-store — releases exactly once. The root-tail generic native call over a Ref word stays the documented abandonment (the count dies with the program), so a heap-drain pin keeps its Ref consumer off the root tail.
- A checked native answering `t | none` needs the call's union to claim a payload region, and a union member that is a unit tag outside `PRIMITIVES` claims none (`payload_fields` answers empty for it), so the two-word span return traps at the caller's one-slot staging behind a clean check — the width readers' `u32_of` hit exactly this until `u32` joined `PRIMITIVES` riding the I64 slot like `byte` [F6]. A width-shaped atom a native must answer or accept over therefore names itself in `PRIMITIVES` first, and the value's number rides the word with the checker still keeping it outside the int conversion family.
- Every consumer of a type-namespace name that can arrive import-bound needs the foreign-type fallback at its own site, and a miss can be silent rather than a refusal: the lowerer's bare match-arm case test resolves through `binding_atom` (not `path_atom`, which the struct round already patched), and a linked case name there answered no atom — an empty member-atom set makes the arm a catchall while the checker's coverage proof still holds, so the dispatch chain fell through to the first arm and answered wrong values at runtime behind a clean check. The resolver's arm-tag walk decides test-vs-bind, so the lowerer must mirror it through the same name index.
