# Lowering invariants

- Every compile seam refuses on the affine walk's own diagnostics: the run path lowers off the checked bundle, so a moved-then-used script checked clean and its deinit fired twice.
- The admission pass and the comptime slice split at `plan_item` on the comptime parameter mode; a callee the plan never receives lowers a call the belt refuses with the wrong diagnostic.
- The comptime fence's refusal and its first-hop origin drill read one row predicate (`row_admits`), so a predicate change touches both call sites; a drill on the older pure-only test names an admitted trap-only helper as the first refusing hop.
- The reflection table reaches the fenced VM as one snapshot (`set_reflection`, the guard restoring on drop), so register every site's arguments, then install, then run: a type registered after the install traps `UnknownInstance` mid-run.
- The world fence is the install seam: the evaluator's registry serves the package's platform name with an empty provides list, so the slice's install refuses a world FuncRef with `UnprovidedPlatformOp` (DS2033); installing no platform or a trapping handler loses that diagnostic.
- A comptime call's embedded answer lowers as the literal a user would write at the call's span, carrying the call's result type (a list's element type included); a `lower` call without the evaluator's map hits the belt refusal there.
- `call_impl`'s `tail` flag is a contract with `tail()`: a tail callee emits its own exit, so every early-returning `call_impl` shape (the comptime embed, the handler and constructor inlines) must be excluded by `is_tail_callee`. A callee-kind tail arm needs its own `tail` guard too, or every cross-module call emits CALL plus RET to a linked callee.
- The frame-reuse tail transfer slides the callee's answer words onto the caller's caller, so a tail call is sound only while its checked answer equals the declared return: a member or strict sub-union answer needs a re-span no position offers, so those tails lower in place. Stage the exit deinit claims before the argument Movs, or the overlay window clobbers the staged span.
- Union payloads share one region per union type: a member claims the lowest free word of its kind and zero-writes its dead payload words with each word's own kind, so a dead `Raw` payload word fails the call slide. A union-typed parameter stages its whole region, its member or sub-union re-spanned through an anonymous temp (a deinit-carrying member refuses there), and a return re-spans.
- float `%` refuses at the lowering boundary (the locked uop set has `ModI64` only), and the checker's [B7] rule refuses float wrap operands before the wrap arms pass `arith_dst` the same `DataOp` for both parameter types, which would mis-lower an f64 word as i64 with no trap. `list_new`'s zero-arg call still needs a one-word overlay area.
- Every place-table write inside a linearity body walk goes through `set_state`, which records the undo entry; a direct `state.insert` rewinds past its own write and branch isolation stops being exact.
- A short-circuit's second test jumps into its own answer block carrying the post-right-operand ownership state, so that exit fires the full arm's dying drops and an answer block the left shortcut also uses frees an object the right operand's call already handed to its callee. Every site emitting sibling frame exits forks the placement map, since `rc.exit` clears the ownership map at the first.
- A construct re-executing its head forks the placement map before the head (`rc.save` plus `loop_enter`), or a Ref-reading head re-fires its read-dec per back edge and frees the object after the first iteration; anonymous carried operands sweep through `drop_unnamed` at the exit.
- Every loop registers exit and backedge labels below its body scope (`LoopCtx`), and `break`/`continue` drop the body scope's binders inward at the jump from a read-only snapshot (`loop_exit_drops`), so each path fires each deinit claim once.
- A bare identifier in a match test position resolves through the type namespace first and binds nothing on a hit, so keep resolve `arm_tag`, type_of `unit_pattern_atom`, and ds-lower `binding_atom` aligned. Such a name needs the foreign-type fallback where it can arrive import-bound, and a miss is silent: a linked case name answering no atom makes the arm a catchall the checker's coverage proof still accepts.
- Never name-find over positional slots: a tuple member's `None`-name fields all compare equal and a `find` answers the first field, so walk `ordered_field_srcs` and resolve per-element binding through `word_addrs`.
- Accept a catchall-free match only when no arm can fail (union tag tests cover the dispatch); a value-level chain with literal tests or guards refuses without one unguarded catchall arm.
- A non-union or-arm lowers as an alternative ladder binding through its last alternative, so its alternatives must bind the same names on the same words: a same-name-different-word alternative refuses at lowering while the checker compares name sets only.
- A non-union match chain runs every arm's tests and guard in order on the fall-through path and snapshots the post-guard state per arm, its join reconciling heterogeneous states (a count one guard ate stays eaten later). A guarded arm over a Ref-carrying scrutinee binds an inc'd word-for-word copy at the section top, and a guard taking the scrutinee's own count refuses.
- A union match's slides re-enter shared dispatch code over one base state, so a jumping path must arrive base-equivalent: the guard's failure edge drops the section's transients at its cleanup label, and a guard taking any count the base state holds refuses. Bind every arm's dispatch entry before any slide targets it and let a catchall intercept at its own position, or the slide goes to `usize::MAX`.
- An `is` test over a written type other than a nominal single-segment path lowers through the checker's solved test at the test expression's span (`Checked::is_tests`): a multi-atom solution joins one TAG_TEST per atom, a covering set folds true, a disjoint one false, and a type variable on either side refuses.
- A span claim folds its span's plain count words and decs every `Ref` word behind the hook, so a folded word never dies on its own; a field-read copy of a folded word borrows and the claim keeps its count.
- A field read's place keys on the checked type's shape, never the raw field width: a one-word struct-typed field still reads as its span, so a width-keyed `PlaceShape::Word` mis-addresses its consumers. A struct field's span and its checked reads' shape come from one member walk, the union case from the written union-of-atoms sorted like the interned solved set.
- A list object's element stride is 0 iff the payload is empty while the checker holds one element type per list value, so the lowerer refuses a stride mismatch, a wider-element copy, or a combinator call before the VM sees it; a checked read's span width is bounds-checked at the overlay write.
- An equality chain dispatches on the left operand's shape alone, so refuse mixed multi-atom spellings at the chain's top instead of falling through to representation-named mismatches. A membership compare over a multi-word element decs the gathered counts straight-line before the chain's per-word borrows, so a fail-fast mismatch never strands a later field's count.
- A fail-fast region (the equality chain's per-word compares) must not site a dying operand's dec at its own word's compare, since the mismatch jump skips every later compare with its release: the compares borrow, and the release sits where every exit merges.
- An entry frame ending in a native call leaves its staged counts (the root frame's tail-native abandon, an accepted leak class), so a heap-drain assertion needs the entry's final expression pure: a value expression drains and a trailing `println` does not.
- A deinit-carrying value stored as a struct field type refuses at the shape layer: the pinned-transfer rule assumes a claimed base word's copy is the consuming move, while a struct-literal field write is a borrow at the checker's facts, so the transfer steals the claim and the hook reads a freed object.
- A `Callee::Evidence` site (a nested runtime-resolved dispatch) has no lowering-time width guard, since `expected_param_words` answers None there, so a mis-staged argument span surfaces as a VM slide-validation trap.
- Parameter modes are definition-site facts the calling convention never widens: `mut` stages a borrow plus the var re-store machinery, `move` is the consuming hand-off whose count and deinit claim ride in; `comptime` parameters, `mut` over a type variable, and a mode on an inlined handler refuse.
- A generic callee's demands collect into the calling frame keyed by the variable the site's per-call record names, the same key the staging peels; a solved bound stages constants. A trait default body dispatches over the trait's own `Self`, and its chains key by the called member's own serving body, or a nested call re-serves the entered member and loops.
- A missing per-call bounds entry splits by cause: a `None`-served bound is the runtime form, staged from this frame's own evidence slots, while an entry absent because the entering branch's head never mentions the variable marks dead code, so the site stages a dead sentinel whose read traps loudly.
- The unit value is one canonical frame word whose single `Kimm 0` splices at the frame top in `finalize` and dominates every later read, so no site writes it again: a first use inside a branch arm must not own the only write, and a loop head bound at stream position 0 must not pick it up per back edge.
- The direct scalar store writes the var's own word (a literal init, an assignment, a compound assignment, a computed scalar's data op with the destination as dst), the VM reading both operands before writing; Ref words and concat results stay temp-mediated. The scalar destination offer is taken by the outermost arithmetic binary alone, and the producer gate (`arith_shape`) and the consumer must list one operator set.
- A call's scalar arguments write their overlay words directly only inside the staging contract's bounds: a literal's load emits at the moves position, and a computed scalar needs every later argument to evaluate without touching the overlay.
- Every synthesized node of a derive mints its span from the shared per-item Mint, the member fn declaration included: two families named by one attribute once shared its span, so the span-keyed `impl_fn_rets` kept the later family's return alone. The Mint also skips the attributed declaration's written identifier and type spans, since the resolver records one name use per span.
- A synthesized bare-`none` match arm must be a binding pattern (the checker's arm tag reads the builtin none from one), never a path pattern, since a `Pattern::Path` `none` is an item reference and refuses as an unknown pattern.
- An optional's presence-branch spelling decides lowering: an empty-then `if x is none { } else { <mutate a var> }` followed by a member-tail read of that var refuses at lowering (DS4009, the checked type and runtime word disagree), while the match spelling lowers (`match x { none => { } n => { ...n... } }`, the catchall binder binding the inner type as its own fresh word). An optional field inside an enum struct payload and a word-union list element (`list[int?]`) trap either spelling.
- A staged word's count hand-off must cover the frame's type-variable word, not just Ref words: a type variable stages as `Raw` and may hold a counted Ref at runtime, so CALLS staging it with no hand-off leaks that Ref into a Ref-claiming body's exit dec.
- Every invocation of a lowered ONE body runs its own nursery, so a transitive golden over a spawning body counts the inner invocations' output too and a golden written from the outer spelling alone mis-pins.
- A value-position join never widens a diverged arm's handed-back place: the arm's own exit stands in for the join, so the widen (and the fn-word answer check) is skipped at every join site; widening it emitted unreachable code over a mismatched shape.
- A written generic union head keys its members by the variable's atoms while every entering site carries the substituted concrete value, so a lookup at a widening or staging site resolves through the structural mate (a heap application by constructor, a tuple by arity with recursively matched elements, exactly one match or the honest refusal), and the tag writes the member entry's minted id.
- A claim's establishment band is runtime state the placement must mirror: an intra-frame transfer (a var's slot re-stored by an assignment, a binder's widen) moves the claim while spending the band word, so the moved site's re-registration must re-set it, and a slot already anchoring a claim adopts its own band word back. Without the re-set the frame's final content never fires its deinit.
- The plan's function-table order is an append-stability contract for growing modules: each struct's deinit plans right after its own item, so a new declaration appends after every earlier entry and the ambient's records stay the plan's contiguous prefix. A declaration inserted before entries a live frame calls by index still shifts them and the swap refuses; `main` shifts freely.
- A value block's tail read of a local binder answers the binder's own words while the block's scope end runs before any consumer exists, so the tail read stages the answer's words past the scope pop; without it the scope released the answer's counts before the consumer claimed them (`UnknownObject` behind a clean check, `const ys = { var xs = [1, 2]; xs }`). A frame tail is safe only because its exit clears the map.
- A checked native answering `t | none` needs the call's union to claim a payload region, and a union member that is a unit tag outside `PRIMITIVES` claims none, so the two-word span return traps at the caller's one-slot staging behind a clean check. A width-shaped atom a native answers or accepts over therefore names itself in `PRIMITIVES` first (as `u32` did riding the I64 slot like `byte` [F6]).
- Every link-fact kind that mints an atom must ride the `.dsi` mint log with its own replay form (`MintData` beside `ReplayMint`) at the log's tail beside the struct and unit-case kinds: the opaque identity's reserved atom hit the extract's linked-atom arm, a shape the mint walk never carried, and the first run-path prefix store panicked at a real two-package run. The install's fallback (`decls.atoms.get`) takes the replayed atom.
- The lowerer reads every expression's checked type by span (`expr_types`), so a checker seam that answers an operand without walking it (the negated-integer-literal fold) must record the operand's solved type at its own span, or the lowering answers `no checked type` at the operand behind a clean check.
- The `.err` handler's checked result is the kept side unioned with the handler's own answer (the `map_err` contract `fn(e) -> e2` answering `t | e2`), never the kept side alone: a handler answering a member the receiver never carried writes its answer word into a result slot the remainder typed, so the firing arm traps at runtime (`slot N holds Ref where I64 is required`) behind a clean check — every committed kernel's handler answered inside the remainder, which kept the class green. An answer that never solves at the site (a generic extern whose return variable nothing feeds, the `die` idiom) contributes no member — a minted variable's atom name is the only `$` a solved set can carry, surface names cannot spell it.
- A single-member scrutinee's span holds the member's own words (no tag word exists), so a lone unguarded arm naming the sole member destructures directly: the payload binders bind at the member's own offsets when the span is the member's and at the place union's region offsets when the scrutinee refined out of a wider span, while every other member-test spelling (a later arm, a tested payload sub-pattern) keeps the no-tags refusal.
- An extraction answer that is the result's only writer — an unannotated `.err`/`.ok` handler consuming every receiver member — must survive the branch reconcile as such: the fall-through arm is dead code and joins as diverged, or its result-less state intersects the answer out of the keep set and the join epilogue frees the handler's answer object (the construction forwarded the caller's count) before any consumer reads it.
- The nursery block's clean-join channel registers its delivered list's ownership only at the join point, after the failure paths' `rc` restore: the boundary's fail arms exit the frame from the pre-channel state, so producing the answers word before them makes every fail exit dec an unwritten Ref slot (`SlotTypeMismatch` at the payloaded cancel behind a clean check). Any word only one branch of a fail/clean fork owns registers after the fork's label, never before the branches.
- A spawned child's plan return is its body's answer type, not the spawn expression's unit: the frame's exit shapes the answer the join collects, and a body that only cancels keeps the unit return (its exit is unreachable, the empty type shapes nothing). A `~Copyable` answer refuses at the spawn site like a list literal element — the collected list's edge retention owns counts, never claims, so the hook has no drop position inside the channel.
