The named-instances residual `#[sealed]` (the core landed 2026-11-26; the attribute landed 2026-11-27): the origin attribute on a trait declaration bans every impl outside the trait's declaring file (DS2055 at the local impl-admission door — a linked trait's declaring file is the producer's own, so a consumer's impl refuses, the root package's own included and the link layering never reached; the origin's own impls stay legal beside the declaration and cross as its own link rows), and the linked install admits rows over a sealed trait from the trait's own link position alone (the extending package's compile refusing its own third-party impls first). Residual: the seal rides no served-ambient row, so a sealed @std trait reads unsealed through a served compile until the checked-ambient tables carry it.
