Since 2026-11-28 (item 140 slice 5) an enum application keys as the union over its own case atoms, so a payloaded generic enum's applications take one body each whatever the body names: the sharing the shape-key ruling promises for equal layouts holds only while the case atoms agree (bare-only enums across every argument). The one route back to sharing across distinct tags is the entering site staging the application's case tags as hidden words the body reads in place of immediates, the evidence words' shape: it needs a tag-test and a tag-construction operand over a slot, the instance call ABI reserving the words, and every nested site staging its callee's tags. Open: whether the body-count saving on payloaded-enum generic code pays the ABI and VM cost, or the per-application instances stand as the ruled cost. Reopens on a measured body-count pain on corpus or library code.
